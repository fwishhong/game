# 条件触发事件表

**文档版本**: v1.0
**最后更新**: 2025-11-05
**条件事件总数**: 25+个条件触发事件

---

## 概述

条件触发事件是基于特定游戏状态（关系、资源、技能、时间等）才会触发的事件。与随机事件不同，这些事件一旦满足条件就必然或高概率触发，不依赖随机数。

---

## 触发机制分类

### 1. 关系触发事件（Relationship-Gated）
- 基于NPC好感度阈值
- 通常在特定章节检查
- 一次性或有限次数

### 2. 资源触发事件（Resource-Gated）
- 基于资源数量阈值
- 持续监测
- 可能是危机预警

### 3. 技能触发事件（Skill-Gated）
- 基于技能等级
- 解锁新选项或剧情
- 展现成长效果

### 4. 时间触发事件（Time-Gated）
- 基于特定日期
- 历史事件重现
- 节日或纪念日

### 5. 状态触发事件（State-Gated）
- 基于游戏状态标记
- 前置事件完成
- 分支剧情触发

### CE016: 饥荒危机
**事件类型**: 资源阈值

|------|-----|


```
     人们开始出现营养不良症状。
     孩子们虚弱地躺着，老人们已经放弃进食。
```

**强制选项**:

**失败后果**: 每天死亡1-2人，直到食物恢复
