# 事件链序列表

**文档版本**: v1.0
**最后更新**: 2025-11-05
**事件链总数**: 18条主要事件链

---

## 概述

事件链是相互关联的事件序列，前一个事件的结果会影响后续事件的触发、内容或结果。事件链体现了游戏的"蝴蝶效应"和长期后果机制。

---

## 事件链类型

### 1. 线性事件链
前置事件 → 中间事件 → 结果事件
单一路径，顺序触发

### 2. 分支事件链
前置事件 → 选择分支A/B/C → 不同结果事件
根据选择产生不同后果

### 3. 累积事件链
多个小决策 → 累积影响 → 触发重大事件
量变引起质变

### 4. 长期后果链
早期决策 → 中期铺垫 → 后期爆发
跨越多个章节的影响

### 5. 循环事件链
事件A → 事件B → 事件C → 返回影响A
形成反馈循环

- 多数玩家会尝试多种方法

## 事件链设计原则

### 1. 因果逻辑
每个后果都有明确的原因，玩家可以理解为何发生

### 2. 时间延迟
重要决策的后果不会立即显现，增加深度

### 3. 多重影响
一个决策可能影响多个方面（关系、资源、士气等）

### 4. 不可预测性
部分后果超出玩家预期，制造惊喜或遗憾

### 5. 道德模糊
没有绝对正确的选择，每个选择都有代价

### 6. 历史真实
尊重历史事实，大事件不可改变

### 7. 情感共鸣
事件链要触动玩家情感，让选择有重量
