# 第5-9章：安全区生存前期 流程图

**章节代号**: CH05-09
**游戏时长**: 5-6小时
**日期跨度**: 1937年12月16日-1938年1月3日（19天）
**玩法类型**: 日循环生存管理（核心玩法建立）

---

## 一、章节总览

```
[第5章：适应] → [第6章：生存] → [第7章：困境] → [第8章：抽签] → [第9章：冬日]
  12.16-12.20     12.21-12.25    12.26-12.28     12.29-1.2     1.3
   (1小时)         (1小时)        (1小时)       (1.5小时)     (1小时)
   生存教学        日循环深化      紧张升级      道德抉择      温度系统
```

**核心玩法**：建立日循环 → 资源管理 → 随机事件 → 道德困境 → 系统深化
