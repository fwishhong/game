### 场景5：穿越过场CG

**场景代码**: `CIN_CH00_TimeTravel`

**时长**: 15秒（不可跳过）

**分镜脚本**:

```
[0-2秒]
画面：白光从触碰点爆发
音效：震动+时空扭曲
陈默：(惊呼) "这是...什么——！"

[2-4秒]
画面：周围场景开始扭曲
特效：类似黑洞引力效果
音效：低频轰鸣

[4-6秒]
画面：陈默身体被拉入时空隧道
特效：粒子化效果
音效：风声呼啸

[6-10秒]
画面：时空隧道中坠落
闪回：1937年历史画面快速闪过
· 南京城门
· 难民队伍
· 日军坦克
· 安全区旗帜
音乐：主题曲高潮（快速版）

[10-12秒]
画面：色彩变化
彩色 → 褪色 → 黑白（象征回到过去）
音效：现代城市声 → 渐弱 → 炮火声

[12-15秒]
画面：陈默坠落，即将落地
镜头：俯视视角，加速下降
音效：风声+心跳+坠落破空声

[15秒]
画面：转黑
字幕：第一章 初遇
音效：沉重落地声（画外）
```

**技术实现标记**:
- 引擎：建议用引擎内实时渲染（便于修改）
- 特效：时空扭曲Shader、粒子系统
- 后处理：色彩分离、畸变、色调映射
- 过渡：与第1章场景无缝衔接

## 五、教学系统

### 操作教学序列

```
教学1：移动控制
├─ 触发：获得控制权后
├─ 提示：UI显示"WASD移动"
├─ 完成条件：移动5米
└─ 奖励：无

教学2：视角控制
├─ 触发：移动教学完成后
├─ 提示：UI显示"鼠标控制视角"
├─ 完成条件：旋转视角180度
└─ 奖励：无

教学3：互动系统
├─ 触发：靠近第一个互动对象
├─ 提示：UI显示"E键互动"
├─ 完成条件：完成一次互动
└─ 奖励：解锁教学成就

教学4：对话系统
├─ 触发：第一次对话出现
├─ 提示：对话框使用说明
├─ 完成条件：阅读完一段对话
└─ 奖励：无

教学5：自由探索
├─ 触发：进入主展厅
├─ 提示：小地图使用，可互动提示
├─ 完成条件：自动完成
└─ 奖励：无
```

**教学设计原则**:
- 非侵入式：不打断沉浸感
- 循序渐进：一次一个概念
- 可跳过：老玩家可在设置中关闭
- 情境化：融入场景，不突兀
