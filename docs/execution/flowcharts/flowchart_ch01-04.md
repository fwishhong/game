# 第1-4章：初遇与逃亡 流程图

**章节代号**: CH01-04
**游戏时长**: 3.5-4.5小时
**日期跨度**: 1937年12月1日-15日
**玩法类型**: 教学关卡 + 护送任务 + QTE + 线性叙事

---

## 一、章节总览

```
[第1章：初遇] → [第2章：沦陷] → [第3章：目击] → [第4章：抵达]
  12.1-12.5      12.13         12.14        12.15
   (1小时)       (40分钟)      (40分钟)     (30分钟)
    教学关卡       护送+QTE      强制剧情      剧情结算
```

**关键目标**: 建立基础联系 → 逃离危险 → 见证历史 → 到达安全区
