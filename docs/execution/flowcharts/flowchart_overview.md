
## 五、选择与分支系统

### 分支类型分类

#### 1. 即时选择（Immediate Choice）
- **定义**: 影响当前场景结果
- **示例**:
  - 逃亡路线选择（第2-4章）
  - 对话选择（全章节）
  - 资源分配（第5-15章）

#### 2. 延迟影响选择（Delayed Impact Choice）
- **定义**: 影响后续章节剧情
- **示例**:
  - 救/不救李文斌（第5章 → 影响第14章）
  - 王掌柜求药（第11章 → 影响第15-18章）
  - 高桥觉醒对话（第16-17章 → 影响结局）

#### 3. 累积型选择（Cumulative Choice）
- **定义**: 多次选择累积影响
- **示例**:
  - 道德评价累积
  - NPC关系值累积
  - 文化传承度累积
  - 历史记录完整度

#### 4. 互斥选择（Exclusive Choice）
- **定义**: 不可兼得，改变剧情走向
- **示例**:
  - 抽签处决方案（第8章）
  - 另一陈默命运（第12章）
  - 主角牺牲（特殊结局）

### 分支收束机制

```
[起始点]
    ↓
    ├→ [分支A] ─┐
    ├→ [分支B] ─┼→ [收束点] → [继续主线]
    └→ [分支C] ─┘
```

**设计原则**:
- 每个章节结束时分支收束
- 关键差异体现在：对话内容、NPC状态、资源量、关系值
- 主线剧情不因分支完全断裂

## 七、时间线管理

### 游戏内时间流逝

#### 序章 & 第18章（2024年）
```
实时制：玩家操作时间 = 游戏时间
场景切换：淡入淡出
```

#### 第1章（教学期）
```
半线性：关键事件按日期推进
日期切换：睡觉/场景转换自动推进
```

#### 第2-4章（逃亡期）
```
实时制：紧张节奏，连续发生
时间跨度：3天浓缩为2.5小时体验
```

#### 第5-17章（生存期）
```
日循环制：
06:00 起床 → 08:00 工作分配 → 12:00 午间事件 →
18:00 晚餐 → 20:00 自由活动 → 22:00 写日记 →
23:00 睡觉（日期+1）

玩家可控：
· 快速推进（跳过日常）
· 详细管理（每个时段操作）
```

### 时间跳跃机制

```
[正常日] → (无特殊事件) → {玩家选择：详细/快速}
                               ↓
                           [快速推进]
                          （跳过动画）
                               ↓
                       [次日06:00直达]
```

## 八、失败与重试机制

### 失败类型

#### 1. 立即Game Over
```
· 主角死亡（QTE失败、特定选择）
· 关键NPC全灭（极端情况）
```
**处理**: 回到最近存档点

#### 2. 任务失败（非致命）
```
· NPC死亡（非主角）
· 资源耗尽（触发替代剧情）
· 选择导致负面结果
```
**处理**: 继续游戏，影响后续剧情

#### 3. 隐形失败
```
· 错过隐藏事件
· 关系值不足无法解锁支线
· 文化传承度过低
```
**处理**: 不提示，影响结局评价

### 提示系统

```
[难度等级]
├─ 简单：自动成功QTE，资源充足
├─ 普通：标准体验
└─ 困难：资源稀缺，QTE严格
```

## 十一、开发优先级

### Phase 1：核心路径（垂直切片）
```
序章 → 第1章 → 第2-4章（简化版）→ 第5章 → 第18章
预计开发时间: 3-4个月
```

```
第6-9章完整实现

预计开发时间: 3-4个月
```

```
第8章（抽签）、第11章（王掌柜）、第12章（另一陈默）
```
