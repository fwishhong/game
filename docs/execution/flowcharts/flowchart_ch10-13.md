**章节代号**: CH10-13
**游戏时长**: 5-6小时
**日期跨度**: 1938年1月4日-22日（19天）
**玩法类型**: 生存管理 + 支线任务 + 剧情体验

---

## 一、章节总览

```
[第10章：疾病] → [第11章：危机] → [第12章：宿命] → [第13章：坚持]
   1.4-1.8        1.9-1.12       1.13-1.16      1.17-1.22
   (1小时)        (1.5小时)      (1.5小时)      (1小时)
   疾病高发       王掌柜生死      历史宿命       漫长等待
```

**关键主题**: 冬季严酷 → 生死抉择 → 无法改变历史 → 意志坚持
