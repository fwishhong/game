```

```

**等级影响公式**:
```
预警天数 = 1 + FLOOR(历史知识等级 / 2)
准确率 = 60% + (历史知识等级 × 4%)
特殊选项解锁概率 = 历史知识等级 × 10%
```

**治疗成功率公式**:
```
最终成功率 = 基础成功率(50%) +
             医疗等级加成(等级×5%) +
             药品质量加成(0-20%) +
             护理加成(0-15%) +
             病人体质加成(-10~+10%)

最高成功率: 95%(永远有5%失败风险)
最低成功率: 20%
```

**药品节约机制**:
```
每次治疗检定: RANDOM(1-100)
如果 ≤ 节约率:
  - 治疗成功但药品不消耗
  - 显示:"陈默运用现代医学知识,节约了药品"
  - 额外获得医疗经验+2
```

```
隐藏物品检定:
  - 每个搜集点有1-3个隐藏物品
  - 检定成功率 = 搜集等级 × 5%

  - 基础时间 - (搜集等级 × 10分钟)
  - 最快可达原时间的60%
  - 同样时间可多搜集1-2个地点
```

```
  - 有互动: +0
  - 无互动超过3天: -1/天
  - 一起工作: +1

关系<20(陌生):
  - 无互动: -1/天
  - 有基础互动: +0.5/天

特殊情况:
  - 群体危机(饥饿/寒冷/疾病): 所有关系-2/天(互相埋怨)
  - 节日/庆祝: 所有关系+3
  - 有人死亡: 相关NPC关系-5~-15
```

### 3.4 关系影响游戏机制

| 关系等级 | 资源分享 | 工作配合 | 危机支援 | 信息获取 | 特殊事件 |

**实际影响案例**:

| 危机中抛弃对方 | -60 | 无 | 信任破裂 |

### 4.3 关系值vs信任度矩阵

| 状态 | 关系值 | 信任度 | 描述 | 游戏表现 |
|-----|-------|--------|------|---------|
| 理想状态 | 80+ | 80+ | 生死之交+完全信任 | 完美同伴 |

**机制说明**:
```

案例:

   - 需要用行动证明

2. 低关系高信任(30/80):
   - 魏特琳对你不是很亲近,但信任你的能力
   - 专业关系

3. 都高(80/80):
   - 王掌柜后期,完全依赖你
   - 最稳定的盟友

4. 都低(20/20):
   - 陌生人或关系破裂
   - 可能离开安全区
```
