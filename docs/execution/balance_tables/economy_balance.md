**价值计算公式**:
```
实际价值 = 基准价值 × 稀缺系数 × 季节修正 × 需求修正

稀缺系数:
  - 当前库存 < 10单位: ×1.5
  - 当前库存 < 5单位: ×2.0
  - 当前库存 = 0: ×3.0

季节修正:
  - 燃料(冬季): ×1.5
  - 水(夏季): ×1.3
  - 食物(春秋丰收): ×0.8

需求修正:
  - 有病人: 药品价值×1.5
  - 有孕妇: 食物价值×1.2
  - 寒冬: 燃料价值×1.5
```

**魏特琳交易特点**:
```
优势:
  + 稳定可靠
  + 汇率公平
  + 无安全风险
  + 可建立长期关系

劣势:
  - 产出有限
  - 需要时间(劳动8小时)
  - 无法获得药品(除紧急)
  - 过度依赖影响独立性

最佳策略:
  - 每日派1-2人劳动(稳定收入)
  - 不要过度求助(保持尊严)
  - 捐赠用于提升信任(长期投资)
```

```
  4. 翻译工作(技能要求)

风险平衡:
  资源获取 vs 道德压力 vs 被怀疑风险

建议策略:
  - 人情债控制在30以下
  - 优先用时间而非情报还债
  - 紧急情况才使用
  - 建立高关系降低风险
```

**风险成本计算公式**:
```
风险成本 = Σ(负面结果概率 × 负面结果价值)

示例: 日占区边缘搜集
基础产出: 8单位食物(价值8)

风险成本:
- 50%概率受伤(-10健康) = 0.5×5 = 2.5
- 5%概率死亡(-100健康) = 0.05×50 = 2.5
- 10%概率被抓(-所有资源) = 0.1×10 = 1
- 总风险成本 = 6

期望收益:
- 50%成功: 8×0.5 = 4
- 净收益 = 4 - 6 = -2 (负收益!)

结论: 不推荐,除非绝境
```

- 每日小盈余(+2~+5食物)
- 定期资源紧张(制造压力)
- 危机有多种解决方案
- 长期投资(技能/工具)回报明显
- 风险与收益成正比
