```
低: 20

高: 75
```

**关键QTE事件表**:

| QTE事件 | 触发条件 | 难度 | 时间窗口 | 成功 | 失败 | 失败后果 |
|---------|---------|-----|---------|-----|-----|---------|
| 躲避日军巡逻 | 大路选项 | 普通 | 1.0秒 | 安全通过 | 被发现 | 交出食物×5或QTE×2 |

| 抢夺木船 | 水路选项 | 困难 | 0.7秒 | 顺利上船 | 落水 | 浪费2小时,资源-2 |

**资源流预测(3天)**:
| 日期 | 人数 | 食物 | 水 | 事件 |
|-----|-----|-----|----|----|
| 第1天 | 2→3 | 8→4 | 10→6 | 逃亡开始,收留小梅 |
| 第2天 | 3→5 | 4→2 | 6→3 | 收留李文斌和老人 |
| 第3天 | 5 | 2→-1 | 3→0 | 到达安全区(临界状态) |

**难度分析**:
```
资源压力: 中(人数增加,消耗翻倍)
事件压力: 高(见证历史暴行,情感冲击)

设计意图:
- 第一个真正的挑战
- 引入QTE机制
- 体验资源短缺的压力
- 情感冲击(见证暴行)
```

### 2.5 第8章: 抽签处决 (难度: 70/100) ⭐情感高峰

| 指标 | 数值 | 说明 |
|-----|-----|------|
| 难度类型 | 道德困境 | 非战斗难度 |
| 资源压力 | 高 | 但非重点 |
| 情感压力 | 极高 | 核心体验 |
| 必须死亡 | 1人 | 无法避免 |
| 玩家影响 | 中 | 可影响"谁"和"如何" |

**抽签事件决策树**:

```
日军要求: 交出5人处决,或抽签1人

选择A: 让年轻人抽签
  ├─ 抽中年轻人(40%): 劳动力损失,效率-15%
  │   └─ 后果: 家属关系-30, 群体士气-15
  ├─ 抽中老人(40%): 老人牺牲
  │   └─ 后果: 部分人不满"不公平", 关系-10
  └─ 抽中主要NPC(20%): 读档重来或接受牺牲
      └─ 后果: 剧情重大改变

选择B: 让老人抽签
  ├─ 抽中老人(70%): 老人牺牲(预期结果)
  │   └─ 后果: 年轻人愧疚, 士气-10, 但理性
  └─ 老人自愿(30%, 关系>60): 感人剧情
      └─ 后果: 士气-20但精神升华, 特殊成就

选择C: 按小说剧情,老人自愿
  └─ 老孙先生自愿: 壮士暮年
      ├─ 后果: 士气-20, 但获得"精神遗产"
      ├─ 其儿子成为关键角色
      └─ 解锁成就"壮士暮年"

选择D: 主角自己抽签(解锁条件:关系>60×3人)
  ├─ 抽到死签(10%): Game Over
  │   └─ 特殊结局"牺牲者",最高道德评价
  └─ 未抽到(90%): 获得最高尊敬
      └─ 所有关系+20, 士气+10(英勇)
```

**难度分析**:
```
战斗难度: 0 (无战斗)
道德难度: 100 (必须选择让人死)
情感难度: 95 (目睹执行过程)
后续影响: 深远(影响后续关系和士气)

设计意图:
- 体验历史真实的残酷选择
- 没有"正确答案"
- 所有选择都有代价
- 情感冲击强,记忆深刻
- 测试玩家价值观

平衡要点:
- 不能让玩家觉得"选错了"
- 每个选择都有其合理性
- 后续有情感缓解机制
- 可以读档重来,但记忆保留
```

### 2.6 第11-12章: 最高难度峰值 (难度: 85-95/100)

**第11章: 王掌柜病危 (难度: 85)**

| 压力源 | 数值 | 说明 |
|-------|-----|------|
| 资源压力 | 95/100 | 食物/药品几乎耗尽 |
| 医疗压力 | 100/100 | 需高级药品×2 |
| 时间压力 | 高 | 3天内必须获得药品 |
| 道德压力 | 90/100 | 用仅有资源救谁? |

**获得药品途径对比**:

| 途径 | 成功率 | 成本 | 风险 | 时间 | 后果 |
|-----|-------|-----|-----|------|------|
| 向高桥请求 | 70% | 人情债+20 | 被怀疑 | 0.5天 | 关系复杂化 |
| 黑市购买 | 50% | 贵重品×3 | 被骗30% | 1天 | 资源耗尽 |
| 冒险去医院废墟 | 40% | 健康-20 | 死亡20% | 2天 | 可能白跑 |
| 用其他病人的药 | 100% | 道德 | 其他人死 | 0天 | 关系-50, 负罪感 |
| 求魏特琳 | 30% | 无 | 无 | 0.5天 | 她也没有 |

**多重压力叠加**:
```
同时发生:
1. 王掌柜病危(3天倒计时)
2. 冬季燃料耗尽(温暖度<20)
3. 食物仅剩5单位(8人×3天=24需求)
4. 另有2人发烧(需药品×2)
5. 日军突击搜查(随时可能)

玩家必须:
- 优先级排序(谁更重要?)
- 冒险决策(去危险区搜集?)
- 道德抉择(牺牲其他人救王掌柜?)
- 时间管理(3天内完成多任务)

设计意图:
- 游戏难度的顶峰之一
- 考验玩家综合能力
- 强迫做出痛苦选择
- 体验战时极限压力
```

**第12章: 另一个陈默 (难度: 95)**

| 指标 | 数值 | 说明 |
|-----|-----|------|
| 难度类型 | 情感+叙事 | 宿命主题 |
| 资源压力 | 75/100 | 仍然紧张 |
| 事件压力 | 100/100 | 必然的死亡 |
| QTE难度 | 困难 | 时间窗口0.5秒 |
| 道德压力 | 100/100 | 无法改变历史 |

**宿命事件流程**:

```
第1天: 发现另一个陈默
  - 玩家可以警告他危险
  - 他不相信或无法避免

第2天: 玩家尝试改变
  选择A: 阻止他离开
    → 他晚上偷偷跑掉
    → 第3天被抓

  选择B: 陪他一起去(保护他)
    → 两人都被抓
    → 触发QTE(困难):
      - 成功: 玩家逃脱, 陈默被射杀
      - 失败: 两人都死, Game Over

  选择C: 替他去
    → 被识破(他还是去了)
    → 可能两人都死, Game Over

第3天: 无论如何
  → 陈默被枪杀(历史宿命)
  → 玩家目睹(可选)
  → 触发"无法改变历史"主题

后续:
  - 主角陷入深思
  - 士气-30(无力感)
  - 解锁日记特殊条目
  - 可选: 找到陈默遗物(现代线索)
```

**难度分析**:
```
战斗难度: 80 (困难QTE)
情感难度: 100 (目睹同名者死亡)
挫折感: 100 (无论如何都无法救下)
叙事强度: 100 (宿命主题核心)

设计意图:
- 强化"宿命"主题
- 体验"无能为力"
- 理解历史的必然性
- 为现代线铺垫(记录重要性)

平衡要点:
- 挫折感高,但有叙事意义
- 失败不是玩家的错
- 提供情感缓解(日记书写)
- 为后续铺垫希望
```

### 2.7 第13-15章: 希望曙光 (难度: 65-75/100)

**第13章: 高桥线 (难度: 75)**

| 指标 | 数值 | 说明 |
|-----|-----|------|
| 难度类型 | 对话+探索 | 叙事为主 |
| 资源压力 | 50/100 | 略有缓解 |
| 道德压力 | 85/100 | 与"敌人"合作 |
| 觉醒度挑战 | 高 | 对话选择复杂 |

**高桥对话挑战**:

| 对话场景 | 难度 | 目标 | 错误后果 |
|---------|-----|------|---------|
| "你怎么看这场战争?" | 高 | 引导觉醒+15 | 关系-10或觉醒-5 |
| "这些平民是无辜的" | 中 | 建立同理心 | 他防御心理 |
| "日本文化vs侵略行为" | 高 | 最佳觉醒路径 | 需日语LV5 |

### 4.2 难度模式推荐人群

**故事模式**:
```
适合人群:
- 首次体验游戏
- 重视剧情而非挑战
- 不擅长资源管理类游戏
- 想轻松完成故事

特点:
- 几乎不会卡关
- 专注剧情和情感体验
- 所有关键NPC存活
- 可以尝试所有选择

缺点:
- 缺乏紧张感
- 生存压力不足
- 可能降低情感冲击
```

**历史模式(推荐)**:
```
适合人群:
- 想体验真实历史难度
- 有一定游戏经验
- 追求平衡体验
- 能接受部分NPC死亡

特点:
- 平衡的挑战性
- 真实的资源压力
- 有意义的选择
- 部分NPC可能牺牲(符合历史)

优势:
- 开发者的设计意图
- 最完整的情感体验
- 真实的历史压力
```

**困难模式**:
```
适合人群:
- 二周目玩家
- 硬核生存游戏爱好者
- 追求极限挑战
- 想测试策略极限

特点:
- 极端资源短缺
- 大量NPC会死亡
- 主角可能Game Over
- 必须精打细算

警告:
- 可能引发挫败感
- 需要多次读档
- 残酷的选择
- 不适合首次游玩
```

### 5.3 失败级联示例: "死亡螺旋"

```
触发点: 资源管理失误

第1周:
食物不足 → 分配不均 → 关系-10(全体)
                    ↓
第2周:            士气-15
冲突增加 → 工作效率-20% → 资源获取减少
                    ↓
第3周:           资源更短缺
有人饥饿>80 → 健康-10/日 → 生病
                    ↓
第4周:          需要药品×2
药品短缺 → 治疗失败 → NPC死亡
                    ↓
第5周:        士气崩溃
群体士气<20 → 拒绝工作 → 无法获取资源
                    ↓
第6周:          Game Over
或多人死亡 → 剧情失败

预防机制:
- 第2周: 警告提示"士气过低"
- 第3周: 触发剧情补给(故事模式)
- 第4周: 提供"求助高桥"选项
- 第5周: 魏特琳鼓励演讲+20士气
- 第6周: 强制剧情介入(历史模式)
```

### 7.3 平衡性红线(不可跨越)

```
红线1: 教学阶段失败率
- 任何玩家都不应在教学阶段失败
- 失败率>10% → 立即降低难度

红线2: 非剧情死亡
- 关键NPC不应在非剧情情况下随机死亡(历史模式)
- 出现率>20% → 增加保护机制

红线3: 资源螺旋
- 不应出现"无解"的资源短缺
- 出现"死亡螺旋"必定有挽回机制
- 触发率>30% → 增加安全网

红线4: 挫败感过载
- 连续失败不超过3次
- 超过3次 → 触发难度自适应降低

红线5: 中途放弃率
- 整体放弃率<20%
- 超过 → 全面难度审查

红线6: 道德选择
- 没有"明显错误"的道德选择
- 所有选择都有合理性
- 不应让玩家觉得"选错了"

红线7: 通关时间
- 首次通关: 12-18小时
- <12小时 → 内容不足
- >20小时 → 拖沓,需删减
```

## 八、难度自适应系统(Dynamic Difficulty Adjustment)

### 8.1 DDA触发条件

| 触发条件 | DDA响应 | 调整幅度 | 持续时间 | 玩家可见性 |
|---------|---------|---------|---------|-----------|
| 连续失败QTE×3 | 时间窗口+0.2秒 | +20% | 5次QTE | 不可见 |
| 资源耗尽持续5天 | 触发剧情补给 | 食物+10 | 1次性 | 可见(剧情) |
| NPC死亡>4人 | 降低死亡率 | -30% | 1章 | 不可见 |
| 士气<15持续7天 | 触发鼓舞事件 | +30士气 | 1次性 | 可见(剧情) |
| 玩家卡关同一点>5次 | 提供额外提示 | 明显提示 | 直到通过 | 可见 |
| 通关时间过快(<8小时) | 隐藏难度提升 | 全局+10% | 二周目 | 不可见 |

### 8.2 难度自适应哲学

```
设计原则:
1. 隐形调整: 玩家不应察觉被"照顾"
2. 保留挑战: 不能让游戏变得毫无挑战
3. 尊重玩家: 硬核玩家可以关闭DDA
4. 符合叙事: 调整通过剧情事件实现

禁止:
× 明显降低难度(玩家会觉得被侮辱)
× 移除所有挑战(失去游戏性)
× 强制保护(历史真实性)

允许:
√ 微调数值(±10-20%)
√ 剧情式补给(符合叙事)
√ 额外提示(可选)
√ 时间延长(QTE)
```
