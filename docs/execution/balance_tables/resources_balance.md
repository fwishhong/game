**风险等级说明**:
- 无: 100%安全
- 低(X%): X%概率遭遇危险事件(盘查、抢劫)
- 中(X%): X%概率遭遇危险,可能受伤/损失资源
- 高(X%): X%概率遭遇危险,可能死亡

**成功率修正**:
```
最终成功率 = 基础成功率 × (1 + 搜集技能×0.05) × 天气修正 × 时段修正

天气修正:
  - 晴天: ×1.0
  - 阴天: ×1.0
  - 小雨: ×0.9
  - 大雨: ×0.7
  - 大雾: ×1.1 (掩护,降低遭遇风险)
  - 下雪: ×0.8

时段修正:
  - 清晨(5-7点): ×1.1 (人少)
  - 白天(8-17点): ×1.0
  - 傍晚(18-19点): ×0.9
  - 夜间(20-4点): ×0.7 (危险但隐蔽)
```

## 五、难度模式资源修正

### 5.1 三种难度对比

| 难度 | 资源产出倍率 | 资源消耗倍率 | 腐坏速度 | 疾病率 | 死亡率 | 推荐人群 |
|-----|------------|------------|---------|--------|--------|---------|
| 故事模式 | ×1.5 | ×0.7 | ×0.5 | -50% | 0% | 首次体验,重剧情 |
| 历史模式 | ×1.0 | ×1.0 | ×1.0 | 基准 | 15-25% | 推荐,平衡 |
| 困难模式 | ×0.7 | ×1.3 | ×1.5 | +50% | 30-50% | 挑战玩家 |
| 地狱模式(隐藏) | ×0.5 | ×1.5 | ×2.0 | +100% | 50-70% | 极限挑战 |

### 5.2 难度特殊规则

**故事模式**:
```
- 主角不会死亡(重伤后自动恢复)
- 关键NPC(魏特琳/小梅/李文斌)不会在随机事件中死亡
- 资源短缺时会有"剧情补给"
- QTE失败只会受伤,不会死亡
- 可无限回溯到章节开始
```

**历史模式**:
```
- 真实历史难度
- 部分NPC可能死亡(非关键剧情)
- 资源紧张但合理规划可通过
- QTE失败可能导致角色死亡
- 每章可回溯1次
```

**困难模式**:
```
- 大量NPC会死亡
- 资源极度匮乏,必须做出残酷选择
- QTE失败=死亡
- 随机事件更频繁更危险
- 每章不可回溯,只能从存档重来
```

**地狱模式**:
```
- 主角可能死亡(Game Over)
- 几乎所有NPC都会死
- 资源获取减半,消耗翻倍
- 新增"绝望机制":士气<10持续3天=群体崩溃
- 死亡后从第一章重新开始(有记忆但无资源)
- 成就"历史的重量"
```

## 八、资源优化策略(供测试用)

### 8.1 最优资源管理策略

**初期(章节1-4)**:
```
优先级: 水 > 食物 > 燃料 > 药品

策略:
1. 每日必做:秦淮河取水(1小时,低风险)
2. 搜集侧重:安全区周边(效率最高)
3. 避免:黑市交易(初期无多余物资)
4. 关系重点:魏特琳(获得稳定食物来源)
```

**中期(章节5-10)**:
```
优先级: 药品 > 食物 > 水 > 燃料

策略:
1. 建立轮班搜集制度
2. 优先升级搜集技能
3. 接受红十字会配给
4. 适度向高桥请求(人情债<30)
5. 开始储存过冬资源
```

**后期(章节11-15)**:
```
优先级: 药品 > 燃料(冬季) > 食物 > 水

策略:
1. 冒险去高收益区域
2. 使用储备贵重品交易
3. 可以承担更高风险
4. 为关键剧情储备资源
```

### 8.2 资源平衡红线

**设计红线(保证游戏可玩)**:
```
1. 食物红线: 连续饥饿不超过3天
   - 触发剧情补给或强制获得食物事件

2. 水红线: 连续缺水不超过2天
   - 秦淮河永远可取水(最低保障)

3. 药品红线: 关键NPC不会因缺药死亡
   - 剧情需要时会有特殊获取途径

4. 死亡红线: 主线NPC不会在非剧情时死亡
   - 故事模式: 任何NPC不会随机死
   - 历史模式: 最多30%NPC死亡
   - 困难模式: 最多60%NPC死亡

5. 士气红线: 群体士气<15持续5天
   - 触发"集体打气"事件,士气+20
```

### 9.1 资源短缺触发事件

|---------|---------|-----|---------|
