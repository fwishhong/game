## 一、教学系统总览

### 设计哲学

```
核心原则:
1. 情境化教学 - 融入剧情，不打断沉浸感
2. 渐进式引导 - 逐章解锁新系统
3. 可跳过设计 - 老玩家可关闭教学
4. 实践优先 - 做中学，避免长篇文字
5. 非强制提示 - 允许玩家自行探索
```

### 教学时机分布

```
序章（第0章）: 基础操作（5分钟）
第1章: 移动与互动（2分钟）
第2-3章: 生存基础（10分钟）
第4-5章: 资源管理（15分钟）
第6章: 关系系统（5分钟）
第8章: 对话选择（3分钟）
第9章: 日记系统（8分钟）
第10章+: 高级策略（可选提示）

总教学时长: 约45-50分钟（分散在游戏中）
```

## 二、序章：基础操作教学（第0章）

### 教学目标
让玩家掌握移动、视角、互动的基础操作

### 场景：纪念馆广场（2024年）

#### 教学1：移动控制

**触发时机**: 玩家获得控制权后立即触发

```
UI显示:
┌─────────────────────────┐
│ 教学提示                │
│ 使用 [WASD] 键移动      │
│ 向前走几步试试          │
└─────────────────────────┘

位置: 屏幕上方中央
样式: 半透明黑色背景，白色文字
动画: 淡入2秒，停留直到完成
```

**完成条件**: 玩家移动距离>5米

**反馈**: UI淡出，轻微音效"叮"

**技术实现**:
```javascript
Tutorial_Movement = {
    触发条件: PlayerInputEnabled == true,
    检测: CalculateDistanceMoved(),
    完成阈值: 5.0米,
    超时: 60秒后自动完成,
    跳过: 按F1跳过所有教学
}
```

## 十四、技术实现建议

### 教学系统架构

```javascript
TutorialManager = {
    // 核心数据
    tutorials: [
        {id: "movement", completed: false, priority: 1},
        {id: "camera", completed: false, priority: 1},
        {id: "interaction", completed: false, priority: 1},
        // ... 更多教学
    ],

    // 当前激活的教学
    activeTutorial: null,

    // 教学队列
    tutorialQueue: [],

    // 检查是否应触发教学
    checkTrigger: function(triggerCondition) {
        if (this.isDisabled || this.isCompleted(triggerCondition.id)) {
            return false;
        }
        return triggerCondition.condition();
    },

    // 显示教学
    showTutorial: function(tutorialId) {
        let tutorial = this.getTutorial(tutorialId);
        if (tutorial) {
            this.activeTutorial = tutorial;
            UI.showTutorialPopup(tutorial);
            this.trackStart(tutorialId);
        }
    },

    // 完成教学
    completeTutorial: function(tutorialId) {
        let tutorial = this.getTutorial(tutorialId);
        tutorial.completed = true;
        this.trackComplete(tutorialId);
        this.saveProgress();
    },

    // 跳过功能
    skipTutorial: function(tutorialId) {
        this.completeTutorial(tutorialId);
        this.trackSkip(tutorialId);
    },

    // 全局禁用
    isDisabled: false,
    disableAll: function() {
        this.isDisabled = true;
    }
}
```

教学UI规范:

· 距离淡化（太远时提示靠近）

## 十六、教学系统总结

### 设计要点回顾

```
✓ 渐进式：逐步解锁，不一次性灌输
✓ 情境化：融入剧情，不突兀
✓ 可跳过：尊重老玩家
✓ 有反馈：完成教学立即给予反馈
✓ 灵活性：可在设置中调整
✓ 数据驱动：追踪数据，持续优化

教学时长: 总计45-50分钟（分散）
强制教学: 仅QTE预警和日记系统
可选教学: 大部分高级功能

玩家自由度: 高
学习曲线: 平缓
上手难度: 低
```
