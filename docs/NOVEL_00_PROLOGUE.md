# 序章：那个名字

**时间**：2024年12月13日上午
**地点**：南京大屠杀遇难同胞纪念馆
**字数**：12,000字
**核心主题**：穿越的开始，历史与现实的交织
**情感基调**：沉重、神秘、命运感

---

## 一、开场场景（2000字）

### 场景1：纪念馆入口（600字）

**时间**：2024年12月13日，上午9:00

**环境描写重点**：
- 冬日的南京，天空灰白，细雨蒙蒙
- 纪念馆前的广场上，人群默默排队
- 黑色大理石墙上刻着"遇难者300000"
- 空气中弥漫着肃穆的气氛
- 远处传来低沉的警报声（纪念日）

**人物状态**：
- 陈默站在队伍中，手里拿着一束白菊花
- 35岁，南京大学历史系副教授
- 穿着深色大衣，表情严肃
- 这是他第十二次来这里（每年12月13日必来）

**心理描写方向**：
- 陈默内心平静而沉重
- 想起自己研究南京大屠杀已经十年
- 读过无数史料，采访过许多幸存者
- 但总觉得隔着一层无法穿透的屏障
- "我真的理解那段历史吗？"

**关键细节**：
- 陈默的背包里装着笔记本和录音笔（职业习惯）
- 他注意到队伍中有几位白发苍苍的老人（幸存者）
- 其中一位老人的眼神让他心头一震（为后续伏笔）

**对话要点**：
- 陈默与身边的学生简短交谈：
  - 学生："陈老师，您每年都来吗？"
  - 陈默："是的。有些事情，不能忘记。"
  - 学生："您研究了这么多年，有什么感受？"
  - 陈默沉默片刻："越研究，越觉得自己懂得太少。"

### 场景2：进入纪念馆（800字）

**环境描写重点**：
- 穿过黑色大理石的通道，光线逐渐暗下来
- 墙上是巨大的黑白照片：残垣断壁，尸体堆积
- 玻璃柜中陈列着遇难者的遗物：破碎的碗、烧焦的衣服、弹片
- 空气仿佛凝固了，每个人都放轻了脚步
- 耳边是低沉的背景音乐，混合着低语的解说

**人物状态**：
- 陈默放慢脚步，仔细观看每一张照片
- 他的手指在玻璃柜前停留，似乎想要触摸那些遗物
- 表情越来越凝重

**心理描写方向**：
- 陈默想：这些照片我都见过，有些甚至能背出拍摄者和时间
- 但今天，不知为何，它们看起来格外真实
- 那些面孔不再是模糊的"受害者"，而是活生生的人
- "他们有名字吗？他们在想什么？"

**关键细节**：
- 陈默在一张照片前停留特别久
- 照片内容：1937年12月，安全区的难民
- 人群中有一个模糊的侧影，年轻男子，穿着长衫
- 陈默觉得这个侧影有些眼熟，但说不上来（重要伏笔）

**视觉与听觉交织**：
- 展厅中播放的证言录音："他们杀了我的父亲...我躲在尸体下面..."
- 陈默闭上眼睛，试图想象那个场景
- 突然感到一阵眩晕

### 场景3："哭墙"前（600字）

**环境描写重点**：
- 巨大的黑色墙面，密密麻麻刻满了名字
- 每个名字都代表一个逝去的生命
- 墙面延伸，似乎没有尽头
- 昏暗的灯光打在墙上，名字像在流泪

**人物行为**：
- 陈默走到墙前，抬头仰望
- 他开始一个一个地读名字
- 手指轻轻划过墙面（不触碰，保持几厘米距离）

**心理描写方向**：
- 三十万个名字，但墙上只有一小部分有名有姓
- 更多的人，连名字都没有留下
- 他们是谁？他们的故事是什么？
- 陈默感到深深的无力："历史学家的工作，就是让他们不被遗忘。但我做得够吗？"

**关键台词**：
- 陈默轻声说："对不起，我不知道你们的名字。"
- 这句话只有他自己听到

**氛围营造**：
- 周围的参观者也在默默流泪
- 整个空间充满了悲伤和沉默
- 时间仿佛停止了

## 二、核心情节：触发穿越（4000字）

### 场景4："万人坑"遗址（1200字）

**环境描写重点**：
- 下沉式展厅，玻璃地板下是真实的遗骨
- 成千上万的骸骨层层叠叠
- 灯光很暗，只有微弱的光线照亮遗骨
- 空气中似乎有一种说不出的寒意

**人物状态**：
- 陈默走到玻璃地板边缘，低头凝视
- 他的手紧紧握着栏杆
- 呼吸变得急促

**心理描写方向**：
- 陈默想起自己读过的史料
- 1937年12月，日军在这里屠杀了数千人
- 他们被赶到江边，被机枪扫射，尸体被推入坑中
- 他试图想象那个场景：惨叫、哭泣、绝望
- 但他只能想象，无法真正理解

**关键心理转折**：
- 陈默突然意识到一个问题：
- "我研究了十年，写了无数论文，但我真的理解他们的痛苦吗？"
- "我只是在用数据、档案、照片来构建一个遥远的历史"
- "但历史不是数据，是活生生的人"
- "如果我能回到那个时代，哪怕只有一天..."

**关键台词**：
- 陈默喃喃自语："如果能回去，我会做什么？"
- 这句话成为穿越的触发

**超自然元素初现**：
- 陈默说完这句话，突然感到一阵强烈的眩晕
- 耳边似乎响起了奇怪的声音：风声、水声、哭泣声
- 他用手扶住栏杆，试图稳住身体
- 眼前的遗骨似乎在微微发光（主观感受）

### 场景5："陈默"这个名字（1500字）

**环境描写重点**：
- 陈默离开万人坑展厅，走向出口
- 经过最后一个展厅：幸存者证言厅
- 墙上有几十个幸存者的照片和简介

**关键情节点**：
- 陈默随意扫视着墙上的照片
- 突然，他的脚步停住了
- 他看到了一个名字：**王梅**
- 照片中是一位107岁的老人（2024年拍摄）
- 简介写着："1937年12月，18岁，在安全区避难..."

**证言内容**（关键）：
```
王梅（1919-2024.12.28）：
"那年我十八岁。我父亲是做棺材的，叫王福生。
12月1日，我们家来了一个年轻人，他说他叫陈默。
他会说日语、英语，还会一些奇怪的话。
我父亲收留了他。
后来南京城破了，我们躲进了金陵女子大学的安全区。
陈默在那里当翻译，救了很多人。
我们以为他会一直在，但是...
1938年2月26日，他突然不见了。
就像从来没有存在过一样。
我等了他八十七年，想问他一句话：
'你为什么不告别就走了？'"
```

**人物反应**：
- 陈默站在照片前，完全僵住了
- 他的大脑一片空白
- "陈默？她说的陈默...是我的名字？"
- "但这不可能，1937年，我还没出生..."

**心理描写方向**：
- 陈默的理性和直觉在激烈冲突
- 理性说：这只是巧合，同名同姓很正常
- 但直觉告诉他：不是巧合
- 那个模糊的照片侧影（场景2）
- 如果把那个侧影的脸换成自己的脸...

**关键细节**：
- 陈默掏出手机，拍下这段证言
- 他的手在颤抖
- 他又读了一遍，逐字逐句
- "王福生...安全区...陈默...1938年2月26日..."
- 所有的细节都清晰可查，不像是虚构

**对话**：
- 一位纪念馆工作人员走过来：
  - 工作人员："先生，您还好吗？"
  - 陈默回过神："这位王梅老人...她还在吗？"
  - 工作人员叹气："很遗憾，她在几天前刚刚去世。12月28日。"
  - 陈默："什么？"
  - 工作人员："是的。她是最后一批幸存者之一。葬礼已经办过了。"
  - 陈默感到一种巨大的失落："她...等了八十七年..."

### 场景6：穿越发生（1300字）

**环境描写重点**：
- 陈默走出证言厅，来到纪念馆的冥思厅
- 这是一个圆形的空间,中央是一个巨大的圆形水池
- 水池底部用灯光投射出"和平"二字
- 四周是黑色大理石墙,墙上刻着和平诗句
- 厅内很安静,只有水滴声

**人物状态**：
- 陈默坐在水池边的长椅上
- 他的脑海中反复回响着那段证言
- "我等了他八十七年..."
- 他掏出手机,再次查看拍下的照片

**心理描写方向**（关键）：
- 陈默想：如果那个"陈默"真的是我...
- 那意味着我会穿越到1937年
- 意味着我会遇见王福生、王梅
- 意味着我会在安全区救人
- 意味着我会突然消失，让她等八十七年
- "但她已经去世了。我来晚了。"
- 巨大的遗憾和悲伤涌上心头

**关键台词**（触发穿越）：
- 陈默喃喃自语："对不起，王梅。我来晚了。"
- 停顿
- "如果能回去...如果能回到那时候..."
- "我一定会告诉你，我会回来。"
- "我一定会回来。"

**穿越开始**：
- 陈默说完这句话，突然感到强烈的眩晕
- 比之前在万人坑时强烈百倍
- 耳边响起巨大的轰鸣声，像是炮火，像是哭喊
- 眼前的水池开始旋转
- 墙上的文字变得模糊
- 他想站起来，但双腿发软
- 他想呼救，但发不出声音

**感官描写**：
- 视觉：眼前一片白光，然后是黑暗，然后是闪烁的画面
- 听觉：轰鸣、爆炸、哭喊、风声、水声
- 触觉：身体像是被撕裂，又像是被挤压
- 嗅觉：硝烟味、血腥味、焦味
- 时间感：一秒像是一年，一年像是一秒

**最后的意识**：
- 陈默的最后一个念头：
- "这是幻觉吗？还是...我真的要回去了？"
- "如果是真的...我该怎么办？"
- 然后，一切归于黑暗

## 三、降落1937（3500字）

### 场景7：苏醒（1000字）

**环境描写重点**：
- 陈默感到有人在摇晃他
- 耳边传来焦急的声音："小伙子！小伙子！醒醒！"
- 睁开眼睛，看到的是灰蒙蒙的天空
- 周围是石板路、老式房屋、木头门窗
- 空气中有一种奇怪的味道：炊烟、柴火、还有...恐惧

**人物状态**：
- 陈默躺在地上，身体疼痛
- 他试图坐起来，头晕目眩
- 眼前是一个五十多岁的男人，穿着深蓝色长衫，满脸皱纹
- 男人的眼神里有担忧、善良，还有警惕

**对话**（第一次交流）：
- 男人："小伙子，你没事吧？怎么晕倒在我家门口？"
- 陈默迷茫地看着他，声音沙哑："这...这是哪里？"
- 男人："哪里？这是南京啊。你不是南京人？"
- 陈默："南京...现在是什么时候？"
- 男人觉得奇怪："什么时候？今天是腊月初一，民国二十六年。"
- 陈默脑中计算：腊月初一...民国二十六年...1937年12月1日！

**心理描写方向**：
- 陈默的大脑一片混乱
- 我真的穿越了？这不可能！
- 但眼前的一切都那么真实
- 这个男人...这个地方...这个时间...
- 等等，男人说这是他家门口...
- 王梅的证言：12月1日，我们家来了一个年轻人...

**关键认知**：
- 陈默突然意识到：眼前这个人就是王福生
- 这就是证言中的那一天
- 历史正在发生
- 而他，成为了历史的一部分

### 场景8：王福生的善良（1200字）

**环境描写重点**：
- 王福生扶起陈默，带他进屋
- 这是一个简陋的棺材铺
- 院子里堆着几口半成品的棺材
- 木屑、工具、墨线散落在地
- 屋内有一张木桌、几个板凳、一个土灶

**人物互动**：
- 王福生让陈默坐下，倒了一碗热水
- 王福生："你看起来不太好。生病了？"
- 陈默接过碗，双手颤抖："我...我不知道。"
- 王福生："口音不像南京人。你是哪里来的？"
- 陈默犹豫："很远的地方。"

**陈默的观察**：
- 他仔细观察着房间里的每一个细节
- 墙上贴着民国时期的日历：民国二十六年
- 桌上放着一份报纸：《中央日报》，日期是11月30日
- 头版新闻：国民政府准备撤离南京
- 陈默的心一沉：这是真的，一切都是真的

**王福生的善良**：
- 王福生："这年头，到处打仗。你是逃难来的吧？"
- 陈默点头："算是吧。"
- 王福生叹气："南京也不太平了。日本人快打来了。"
- 停顿："不过既然你来了，就先住下吧。多一个人多一双筷子。"
- 陈默震惊："你...你愿意收留我？"
- 王福生笑笑："都是中国人，这种时候还能把人赶出去？"

**小梅登场**：
- 这时，一个年轻女孩走进来
- 十八岁，穿着粗布衣服，扎着两条辫子
- 脸上还有些婴儿肥，眼睛很大
- 她看到陈默，有些好奇
- 王福生："小梅，这位小伙子晕倒在咱家门口，先让他住几天。"
- 小梅点头："好。我去烧水做饭。"

**陈默的情感冲击**：
- 看着眼前这个十八岁的女孩
- 陈默想起纪念馆里那张107岁老人的照片
- 眼前的少女和照片中的老人，是同一个人
- 她还不知道，十二天后，南京会变成地狱
- 她还不知道，她会等他八十七年
- 陈默感到一种难以言说的悲伤

**关键台词**：
- 王福生："对了，小伙子，你叫什么名字？"
- 陈默犹豫片刻："陈默。"
- 王福生："陈默？好名字。默默无闻，大智若愚。"
- 陈默苦笑：默默无闻...或许是在历史中默默无闻

### 场景9：1937年的南京（1300字）

**环境描写重点**：
- 傍晚，陈默和王福生走在南京的街道上
- 王福生要去买粮食（预感到战争，开始囤积）
- 陈默第一次真正看到1937年的南京

**街道景象**（详细描写）：
- 石板路，青砖黛瓦的房屋
- 商铺大多关门了，只有少数还在营业
- 街上的人神色匆匆，脸上带着焦虑
- 有人在搬运家具，准备逃离
- 有人在抢购粮食、食盐、煤炭
- 墙上贴着国民政府的告示：呼吁市民保持冷静

**陈默的感受**：
- 这就是1937年的南京
- 不是教科书里的文字
- 不是档案馆里的照片
- 而是活生生的、即将毁灭的城市
- 他知道接下来会发生什么，但这些人不知道

**人物对话**：
- 王福生："听说日本人很快就要打过来了。政府都要撤走。"
- 陈默："那你为什么不走？"
- 王福生："走？往哪儿走？我就这么个棺材铺，离开南京还能干什么？"
- 停顿："再说了，不是还有安全区吗？洋人办的，日本人应该会给面子。"
- 陈默心里一沉：安全区确实救了很多人，但也发生了很多悲剧

**粮店场景**：
- 粮店门口排着长队
- 有人在争吵："为什么涨价？这是发国难财！"
- 店主："不买拉倒！再过几天粮食只会更贵！"
- 王福生排队买了一袋米、一袋面粉
- 花了他大半的积蓄

**陈默的内心挣扎**：
- 他想告诉王福生：多买点粮食，买越多越好
- 他想告诉街上的人：快逃，逃得越远越好
- 但他不能说
- 因为说了也没人会信
- 因为他也不确定自己是否应该改变历史

**夕阳景象**：
- 回家的路上，夕阳西下
- 秦淮河畔，河水泛着金光
- 远处的紫金山轮廓清晰
- 南京城在夕阳下显得格外美丽
- 但陈默知道，这可能是这座城市最后的平静

**关键台词**：
- 王福生看着夕阳："真美啊。希望战争快点结束。"
- 陈默轻声："会结束的。"（他知道战争会结束，但代价惨重）
- 王福生："你说话总是怪怪的，好像知道很多事情。"
- 陈默沉默

## 四、序章收尾：两个时空（2500字）

### 场景10：晚饭（1000字）

**环境描写重点**：
- 回到王家，小梅已经做好了晚饭
- 简单的饭菜：小米粥、咸菜、一碟炒青菜
- 三个人围坐在木桌前
- 昏黄的油灯照亮小小的房间
- 窗外天色渐暗

**人物互动**：
- 小梅给陈默盛粥："陈大哥，多吃点。"
- 陈默："谢谢。"
- 王福生："小梅，多给陈先生夹点菜。"
- 小梅害羞地笑笑

**对话（了解背景）**：
- 王福生："陈先生，你说你是从很远的地方来的，是哪里？"
- 陈默："北方。"（模糊回答）
- 王福生："哦，难怪口音不太一样。你读过书吧？看起来斯斯文文的。"
- 陈默："读过一些。"
- 王福生："那太好了。小梅也读过几年书，她聪明，就是家里穷，供不起她继续读。"
- 小梅："爹，吃饭呢，说这些干什么。"

**陈默的观察**：
- 他看着眼前的父女俩
- 王福生：善良、淳朴、勤劳
- 小梅：聪明、害羞、乖巧
- 在和平年代，他们会过着平凡而幸福的生活
- 但十二天后...

**关键情节点**：
- 小梅突然问："陈大哥，你会说日本话吗？"
- 陈默一愣："为什么这么问？"

- 陈默沉默片刻："我会一些。"
- 王福生眼睛一亮："真的？那太好了！有你在，我们可能真的会安全一点。"
- 陈默心想：会日语确实会有用，但也可能带来危险

**温暖的瞬间**：
- 饭后,小梅给陈默铺床
- 在院子里的一个小耳房
- 虽然简陋，但干净整洁
- 小梅："陈大哥，这里有点简陋，你别嫌弃。"
- 陈默："已经很好了。谢谢你们。"
- 小梅笑笑，转身离开

### 场景11：第一个夜晚（1000字）

**环境描写重点**：
- 深夜，陈默躺在硬板床上
- 耳房里只有一盏小油灯
- 窗外传来风声，偶尔有狗叫声
- 远处似乎有炮火的声音（淞沪会战的余波）

**心理描写方向**（核心）：
- 陈默无法入睡
- 他的大脑在疯狂运转
- 我真的穿越了
- 我现在在1937年12月1日的南京
- 距离南京陷落还有12天
- 我该做什么？

**内心独白**：
```
我是历史学家，我知道接下来会发生什么：
- 12月8日，日军逼近南京
- 12月12日，守军决定撤退
- 12月13日，南京陷落
- 接下来的六周，三十万人死亡

我能改变这些吗？
不能。我只是一个人。
我能阻止日军吗？不能。
我能阻止屠杀吗？不能。
我能拯救三十万人吗？不能。

那我能做什么？
我能拯救王福生和小梅吗？
我能保护这个善良的家庭吗？
我应该劝他们逃走吗？
但王福生说了，他无处可去。
而且，根据王梅的证言，他们最终去了安全区。
那里相对安全...相对。

但我知道，安全区也不是绝对安全。
日军士兵会闯进来抓人。
会有强奸、屠杀、抢劫。
我能保护他们吗？

还有，我为什么会穿越？
为什么是我？
为什么是这个时间点？
我能回去吗？
王梅说，1938年2月26日，我突然消失了。
那意味着我只有三个月的时间。

三个月...
我该怎么度过这三个月？
```

**关键认知**：
- 陈默突然明白了：
- 他不是来改变历史的
- 他是来见证历史的
- 他是来理解那些数据背后的生命的
- 他是来完成王梅未完的等待的

**决心**：
- 陈默对自己说：
- 既来之，则安之
- 我会尽我所能，保护王福生和小梅
- 我会记录我所看到的一切
- 我会告诉小梅，我会回来
- 即使要等八十七年，我也会回来

## 五、写作注意事项

### 1. 语言风格
- **2024年段落**：现代汉语，简洁、冷静、学术气息
- **1937年段落**：略带民国气息，但不过度古化
- **对话**：符合时代特征，王福生用"小伙子"、"先生"等称呼

### 2. 细节真实性
- **历史细节必须准确**：日期、地点、事件
- **物品细节**：1937年的物品（油灯、石板路、长衫）
- **价格细节**：粮食价格、物价上涨
- **心理细节**：1937年普通人对战争的认知

### 3. 情感基调
- **压抑而不绝望**：知道悲剧将至，但还有温暖
- **悲伤而不煽情**：克制的笔触
- **神秘而不离奇**：穿越是工具，不是重点

### 4. 伏笔设置

**序章埋下的伏笔**：
- ✅ 王梅的证言（贯穿全书）
- ✅ 陈默会日语（后续在安全区有用）
- ✅ 2月26日突然消失（全书高潮）
- ✅ "我会回来"（与结局呼应）
- ✅ 模糊的照片侧影（后续会清晰）

### 5. 与后续章节的联系

**与第1章的衔接**：
- 序章结束于第一个夜晚
- 第1章从12月2日清晨开始
- 无缝连接

**与第8章（重逢）的呼应**：
- 序章中107岁的王梅已去世
- 第8章中陈默回到2024年，错过了她
- 巨大的遗憾感

**与第18章（消失）的呼应**：
- 序章中提到"2月26日突然消失"
- 第18章详细展现消失过程
- 形成完整闭环

### 6. 关键意象

**贯穿全书的意象**：
- **梅花**：小梅的名字，冬天开放，坚韧
- **秦淮河**：见证历史，从繁华到毁灭
- **名字**：三十万人，有些有名，有些无名
- **等待**：八十七年的等待

### 7. 章节功能

序章的三大功能：
1. **建立双时空结构**：2024 ↔ 1937
2. **提出核心悬念**：陈默为什么会穿越？
3. **奠定情感基调**：遗憾、悲伤、使命感

## 六、关键场景的文学技巧

### 场景2：看到照片中的侧影
**技巧**：视觉暗示 + 读者优势视角
- 读者知道那是陈默，但陈默还不确定
- 制造悬念和期待

### 场景5：读到证言
**技巧**：信息冲击 + 时间悖论
- 用完整的证言文本（视觉冲击）
- "等了八十七年"（情感冲击）

### 场景6：穿越发生
**技巧**：感官超载 + 意识流
- 五感描写到极致
- 时间感错乱

### 场景8：见到年轻的小梅
**技巧**：时间叠影
- 十八岁的少女 vs 107岁的老人
- 同一个人，相隔八十七年

### 场景11：第一个夜晚
**技巧**：内心独白 + 理性分析
- 体现陈默的历史学家身份
- 建立"无力改变大历史，但可以保护小人物"的主题

## 八、序章的节奏控制

**总体节奏**：慢-快-慢

1. **慢**（场景1-3，2000字）：纪念馆参观，沉重而平缓
2. **快**（场景4-6，4000字）：情绪积累，触发穿越，快速转换
3. **慢**（场景7-12，6000字）：降落1937年，建立新环境，为第1章铺垫

**情绪曲线**：
```
沉重 → 震惊（看到证言）→ 眩晕（穿越）→ 迷茫（初到）→ 悲伤（认识到现实）→ 决心（第一夜）
```
