# 第2章：回归

**时间**：2024年12月13日下午
**地点**：南京鼓楼医院
**字数**：10,000字
**核心主题**：从1937年回到2024年，记得一切但无法证明
**情感基调**：震撼、失落、坚定

---

## 一、醒来（3000字）

### 场景1：睁开眼睛（1000字）

**时间**：2024年12月13日，下午2:30

**环境描写重点**：
- 白色的天花板
- 刺鼻的消毒水味
- 仪器的滴滴声
- 明亮的灯光
- 现代化的医疗设备

**醒来**：
- 陈默缓缓睁开眼睛
- 眼前一片白
- 太亮了
- 和1937年昏暗的安全区完全不同

**意识到**：
- 陈默看着白色的天花板
- 听着仪器的声音
- 闻着消毒水的味道
- 他知道：我回来了
- 回到2024年了

**身体感觉**：
- 陈默试图坐起来
- 胸口一阵疼痛
- 是伤口
- 2月24日营救任务时受的伤
- 他记得，被日军的刺刀划伤
- 现在还疼

### 场景2：检查身体（1000字）

**时间**：下午2:35

**环境描写重点**：
- 病房里只有陈默一个人
- 护士刚离开
- 说要去叫医生

**陈默检查自己**：
- 他掀开病号服
- 胸口有纱布
- 他小心地揭开一点
- 看到伤口
- 一道长长的疤痕，缝了针
- 是真的
- 不是梦

**其他伤痕**：
- 手臂上有淤青（搬木头时磕的）
- 手掌有茧（做棺材时磨的）
- 小腿有擦伤（逃跑时摔的）
- 都在
- 87天的痕迹都在

**震撼**：
- 所以...是真的
- 我真的去了1937年
- 真的在那里待了87天
- 真的经历了那一切
- 王福生、小梅、李文斌、高桥...
- 都是真的

**时间差**：
- 陈默看向墙上的时钟
- 下午2:30
- 他记得，穿越时是上午9:30
- 5个小时
- 但他在1937年待了87天
- 2月26日早上消失的
- 时间...完全不对等

### 场景3：医生检查（1000字）

**时间**：下午2:40

**医生进来**：
- 一个四十多岁的男医生
- 戴着眼镜
- "陈先生，你醒了。感觉怎么样？"

**陈默的回答**：
- "我...还好。"
- 医生："你在纪念馆晕倒了，我们把你送来医院"
- 陈默："我昏迷了多久？"
- 医生："大约5小时"

**检查**：
- 医生检查瞳孔、血压、心跳
- "生命体征正常"
- "但你胸口的伤...很奇怪"
- 陈默一惊："什么意思？"

**关于伤口**：
- 医生："这个伤口，看起来像刀伤"
- "而且已经有几天了，开始愈合"
- "但你是今天早上才来医院的"
- "这很不合理"
- 陈默沉默

**医生的疑惑**：
- "陈先生，你这个伤是什么时候受的？"
- 陈默："我...我记不清了"
- 医生："需要报警吗？这看起来像被人袭击"
- 陈默："不用。这是...意外"

---

## 二、警察询问（3000字）

### 场景4：警察到来（1500字）

**时间**：下午3:00

**环境描写重点**：
- 两个警察进入病房
- 一男一女，都穿着制服
- 表情严肃

**警察介绍**：
- 男警察："陈默先生，我是李警官，这是我同事王警官"
- "我们接到医院报告，您有可疑伤口"
- "需要了解一些情况"

**询问**：
- 李警官："陈先生，能说说今天上午发生了什么吗？"
- 陈默深吸一口气："我去了纪念馆"
- "然后...我晕倒了"
- 王警官："就这样？"
- 陈默点头

**关于伤口**：
- 李警官："那这个伤口呢？"
- "医生说，这是刀伤，而且有几天了"
- 陈默："我...我不记得了"
- 李警官皱眉："不记得？"

**陈默的困境**：
- 陈默不能说真话
- 他不能说："我去了1937年，被日军刺刀划伤"
- 没人会信
- 他们会以为他疯了

**僵持**：
- 李警官："陈先生，如果有人伤害你，请告诉我们"
- 陈默："没有。这真的是意外"
- 王警官："什么样的意外？"
- 陈默："我...我摔倒了，被玻璃割伤"
- 李警官明显不信："玻璃？这明显是刀伤"

### 场景5：监控录像（1500字）

**时间**：下午3:15

**环境描写重点**：
- 李警官拿出平板
- 打开一个视频文件

**监控画面**：
- "这是纪念馆的监控"
- 画面显示：
  - 上午9:28，陈默走进展厅
  - 9:29，他站在王梅的视频前
  - 9:30，他突然倒下
  - 工作人员跑过来
  - 画面结束

**关键证据**：
- 李警官："你进去的时候，没有伤口"
- "你穿的白衬衫很干净"
- 画面中，陈默的衬衫确实是白色干净的
- 李警官："但你昏迷后，衬衫上有血迹"
- "这血是从哪来的？"

**陈默无法解释**：
- 陈默看着监控
- 他记得，2月24日受伤后
- 小梅帮他包扎
- 衬衫确实染了血
- 但那是在1937年
- 怎么解释？

**李警官的推测**：
- "陈先生，你是不是被人下药了？"
- "然后在昏迷中被人伤害？"
- 陈默摇头："不是"
- 王警官："那你倒是解释一下"

**僵局**：
- 陈默沉默
- 他不能说真话
- 但也找不到合理的解释
- 最后他说："我真的不记得了"
- 李警官叹气："好吧。如果你想起什么，请联系我们"
- 递给陈默一张名片

## 三、决定（4000字）

### 场景6：独自思考（2000字）

**时间**：下午4:00

**环境描写重点**：
- 警察离开了
- 病房里只剩陈默
- 窗外是南京的天际线
- 高楼、车流、和平

**陈默看着窗外**：
- 这是2024年的南京
- 繁华、和平、现代化
- 87年前的废墟
- 现在成了这样
- 他想起2月26日消失前
- 最后看到的南京
- 废墟、烟火、哭声

**对比**：
- 87年
- 从地狱到天堂
- 从死亡到重生
- 这座城市
- 这些人
- 都活过来了

**陈默的思考**：
- 我为什么会穿越？
- 为什么是我？
- 为什么是1937年12月1日到1938年2月26日？
- 87天
- 我看到了什么？
- 大屠杀、守门人、王福生的死、记录真相...
- 这一切...有什么意义？

**一个想法涌现**：
- 也许
- 我回来
- 不是偶然
- 我经历了那些
- 见证了历史
- 认识了那些人
- 记录了真相
- 我应该...把它们讲出来

### 场景7：笔记本（1000字）

**时间**：下午4:30

**环境描写重点**：
- 护士送来了陈默的随身物品
- 一个背包
- 里面是他去纪念馆时带的东西

**检查物品**：
- 陈默打开背包
- 钱包、手机、钥匙
- 还有一个笔记本
- 他穿越前随身带的笔记本

**翻开笔记本**：
- 前几页是空白的
- 然后...
- 陈默愣住了
- 笔记本上有字
- 他的笔迹
- 但他不记得写过

**内容**：
```
1937年12月1日
今天，我来到了一个陌生的地方。
一个叫王福生的人收留了我。
他有个女儿，叫小梅，18岁。
南京即将沦陷。
我必须帮助他们。

1937年12月2日
...
```

**震撼**：
- 这是...日记？
- 陈默继续翻
- 一页页的日记
- 从12月1日到2月25日
- 每一天都有
- 详细记录了他在1937年的经历

**最后一页**：
```
1938年2月25日
明天，我可能会离开。
我感觉到了。
不知道会以什么方式，但我知道时间到了。

小梅，李文斌，如果有一天你们看到这些...
对不起，我不能陪你们走到最后。
但请相信，我做的一切都是真的。

如果我能回到2024年...
我会把这些都写下来。
让世界知道你们。
让世界记住那段历史。

这是我的使命。
```

**陈默的眼泪**：
- 陈默看着这段话
- 这是他昨晚写的
- 2月25日的晚上
- 他预感到会离开
- 所以写下了这些
- 现在，他回来了
- 带着这些记忆
- 带着这个使命

### 场景8：决心（1000字）

**时间**：下午5:00

**环境描写重点**：
- 夕阳西下
- 橙红色的光照进病房
- 陈默坐在床上
- 手里握着笔记本

**陈默的决定**：
- 我要写下来
- 把那87天的经历
- 写成一本书
- 不是为了证明什么
- 不是为了让人相信穿越
- 而是为了记录

**为了什么**：
- 为了王福生
- 为了小梅
- 为了李文斌
- 为了高桥
- 为了魏特琳、拉贝
- 为了所有那些在安全区的人
- 为了那些死去的人
- 为了那段不应该被遗忘的历史

**第一步**：
- 陈默拿起手机
- 搜索："王梅 南京大屠杀幸存者"
- 他要找到小梅
- 找到她的后代
- 了解她后来的人生
- 了解那些人后来怎么样了

**搜索结果**：
- 屏幕上出现一条新闻
- "南京大屠杀幸存者王梅老人病危，享年107岁"
- 日期：2024年12月20日
- 陈默的心一紧
- 小梅...还活着
- 但病危了

**第二个决定**：
- 陈默立即按铃叫护士
- "我要出院"
- 护士："但是您的伤..."
- 陈默："我没事。我必须出院"
- 他要去见小梅
- 在她离开之前
- 他要告诉她：我回来了

**第2章结尾**：
- "2024年12月13日下午5点，陈默做了两个决定："
- "第一，去见小梅，告诉她：你等的人回来了。"
- "第二，把那87天的经历写成书，让世界记住那段历史。"
- "这是他穿越归来后，给自己的使命。"

## 四、写作注意事项

### 1. 删除所有"失忆"内容

**关键**：
- 陈默记得所有87天
- 不是只记得前7天
- 不需要探索失忆原因
- 不需要找回记忆

### 2. 身体证据

**真实的痕迹**：
- 伤口（2月24日受的）
- 茧子（做棺材）
- 淤青（搬东西）
- 血迹（衬衫上）
- 这些都证明不是梦

### 3. 笔记本的发现

**关键道具**：
- 陈默在1937年写的日记
- 随身带回来了
- 成为唯一的物理证据
- 也是写书的素材

### 4. 警察询问场景

**制造冲突**：
- 陈默无法解释伤口
- 监控录像的矛盾
- 警察的怀疑
- 但陈默不能说真话
- 这增加戏剧性

### 5. 两个决定

**推动情节**：
- 决定一：去见小梅（引出第4章）
- 决定二：写成书（全书主线）

### 6. 情感克制

**不要过度**：
- 陈默的震撼和失落要真实
- 但不要过度煽情
- 重点在于他的决心和使命感

### 7. 时间差的处理

**科幻设定**：
- 2024年5小时 = 1937年87天
- 时间流速不同
- 不需要解释原理
- 只需要陈默发现这个事实

### 8. 金句设计

**第2章应包含的金句**：

1. "我回来了。回到2024年。但我记得所有的87天。"
2. "87年，从地狱到天堂。这座城市，这些人，都活过来了。"
3. "这是我的使命：把那87天写下来，让世界记住。"
4. "不是为了证明穿越，而是为了记录历史。"

### 9. 与其他章节的联系

**承上启下**：
- 承接序章：穿越后醒来
- 引出第4章：搜索小梅
- 引出第8章：见小梅
- 引出最后一章：开始写书
