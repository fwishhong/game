# 物品描述文本库

## 文档说明

本文档包含游戏《秦淮旧梦》中所有物品的描述文本。每个物品包含：
- **名称**：物品的显示名称
- **简短描述**：鼠标悬停时显示的一句话描述
- **详细描述**：查看物品时显示的完整描述
- **历史注释**：（如有）与该物品相关的历史背景
- **稀有度**：1-5星，影响获取难度

- **稀有度**：⭐
- **容量**：10 L
- **清洁度**：20%（需过滤+煮沸）

- **稀有度**：⭐⭐⭐
- **容量**：2 L
- **清洁度**：100%（已消毒）
