## 叙事结构总览

```
序幕（2024）→ 第一幕（初遇与逃亡）→ 第二幕（生存与见证）→ 第三幕（离别与传承）→ 尾声（2024）
```

## 序章：穿越（2024年12月13日）

### 叙事目标
- 建立主角背景
- 铺垫穿越动机
- 设置历史背景

### 关键场景

**场景1：纪念馆外景**
```
陈默（旁白）:
"2024年12月13日，南京。第87个国家公祭日。
我作为历史学者，每年都会来这里。
但今年……有些不一样。"
```

**场景2：遇难者名字墙**
```
（镜头推进，三十万个名字密密麻麻）
陈默（旁白）:
"三十万。一个冰冷的数字。
但每个数字背后，都是一个人，都有名字……
陈默……又是一个陈默……"
（手触碰名字，白光闪烁）
```

**场景3：穿越**
```
（时空扭曲特效）
（画面从彩色→黑白）
（声音从现代都市→炮火声）
（陈默坠落）
```

## 第一章：初遇（1937年12月1-5日）

### 叙事目标
- 主角适应时代
- 与王掌柜建立联系
- 历史知识发挥作用

### 关键剧情节点

**12月1日：降落**
```
陈默内心独白:
"这是……1937年？
我真的穿越了？还是在做梦？"

（尝试求证：看报纸日期、周围建筑）
```

**12月2日：遇王掌柜**
```
王掌柜:
"哎呦，小兄弟这是怎么了？迷路啦？"

陈默:
"我……我找不到家了……"

王掌柜:
"这年头，找不到家的人多了去了。
来，先到我这儿歇歇脚吧。"

（建立第一个人际联系）
```

**12月5日：预警**
```
（远处传来隆隆炮声）

陈默（内心）:
"开始了……南京保卫战已经打响……
历史告诉我，12月13日，这座城市将会……"

（意识到即将到来的浩劫）
```

## 第二至四章：逃亡（12月13-15日）

### 第二章：沦陷

**12月13日上午：进城**
```
（镜头：日军坦克碾过城墙）
（音效：炮火、惨叫）

王掌柜（惊慌）:
"快！快收拾东西！日本人进城了！"

陈默:
"往金陵女子学院！那里有美国人办的安全区！"

王掌柜:
"你怎么知道？"

陈默:
"我……我听说的！快走！"
```

### 第三章：目睹

**12月14日：街道**
```
（强制剧情，玩家无法阻止）

（目击场景：日本兵暴行）
（陈默想上前，被王掌柜拉住）

王掌柜（压低声音）:
"不能去！去了咱们也得死！"

陈默（颤抖）:
"我知道……我知道历史……
但亲眼看到……
我真的……无能为力……"

（建立核心主题：见证 vs 无力）
```

### 第四章：抵达

**12月15日：安全区大门**
```
（人群涌动，哭喊声）

魏特琳（站在门口）:
"所有妇女儿童都可以进来！
我们会保护你们！"

（第一次见到历史人物，震撼）

陈默（内心）:
"魏特琳……我在书里读过你无数次……
现在……你就站在我面前……"
```

## 第五至九章：生存前期（12月16日-1月3日）

### 核心叙事：建立秩序 → 适应绝境

**关键时刻1：第一次搜查**
```
日本军官:
"交出中国士兵！"

魏特琳（挡在门口）:
"This is American property!
You have no right!"

（玩家选择：帮忙翻译/保持沉默/藏人）
```

**关键时刻2：除夕夜（12月31日）**
```
孙老先生（带着孩子们）:
"虽然我们身处苦难，但不能忘了文化。
来，大家一起读：
'岁寒，然后知松柏之后凋也。'"

（众人齐声朗读）
（陈默流泪）

陈默（独白）:
"这才是真正的不屈……"
```

## 第十至十二章：冬季与宿命（1月4-16日）

### 第十一章：王掌柜生死

**分支叙事**

**路线A：王掌柜存活**
```
（玩家成功获得药品并治疗）

王掌柜（虚弱）:
"小陈……你救了我一命……
从今往后，你就是我亲儿子……"

小梅（哭着笑）:
"爹！你终于醒了！"

（后续：王掌柜成为重要助力）
```

**路线B：王掌柜去世**
```
（音乐：《离别》）

小梅（趴在父亲身上）:
"爹……爹你别走……
你说过要看我嫁人的……
你说过……"

陈默（握着王掌柜的手）:
"掌柜大哥……我答应你……
我会照顾小梅……"

（葬礼场景，众人哀悼）
（触发小梅托付支线）
```

### 第十二章：另一个陈默（历史宿命）

```
（遇到同名者）

另一个陈默:
"我要去城外找我娘……"

陈默:
"不能去！外面太危险了！"

另一个陈默:
"我娘一个人在那边……我必须去……"

（无论玩家如何选择，他都会死）

陈默（对着尸体）:
"对不起……我救不了你……
我什么都改变不了……"

（主题深化：个人 vs 历史洪流）
```

## 第十三至十五章：坚持（1月17日-2月2日）

### 核心叙事：在绝境中寻找希望

**第十四章：小梅怀孕**
```
（如果李文斌存活）

小梅（羞涩）:
"陈大哥……我……我有了……"

陈默:
"这是……好事啊！
在这样的时候，新生命代表希望！"

李文斌（感激）:
"多亏了你当时救了我……
我才能……"

（希望的象征）
```

**第十五章：春节**
```
（除夕夜，大家围坐）

孙老先生:
"虽然是苦日子，但该过的节还是要过。
这是我们的传统，我们的根。"

（分享仅有的食物）
（孩子们表演节目）
（短暂的温暖时刻）

陈默（日记）:
"今夜，我看到了人性的光辉……"
```

## 第十六至十七章：高桥线（2月15-20日）

### 叙事目标：人性复杂性

**第十六章：邀请**
```
高桥:
"陈桑，我想请你帮个忙……
我想去城外拍照……记录真相……"

陈默:
"你……为什么要这么做？"

高桥:
"因为……我看到的和他们告诉我的不一样……
我需要知道真相……"

（开始质疑）
```

**第十七章：觉醒对话**
```
（在废墟中）

陈默:
"你知道吗，几十年后，
你们国家的教科书会说这些都不存在……"

高桥（震惊）:
"不……不可能……这么多人……
这么多证据……"

陈默:
"但就是会被掩盖。
所以……你要做什么？"

高桥（沉默良久）:
"我会写下真相……即使没人愿意看……
即使我会被当成叛徒……
但……至少我的良心不会死……"

（觉醒度>80时的对话）
```

## 终章：传承（2024年12月14-16日）

### 叙事高潮：历史与现实的交汇

**12月14日：苏醒**
```
（陈默在纪念馆醒来）
（发现日记变成了真实的手稿）

陈默:
"是梦吗？
不……这些文字……这些记忆……
都太真实了……"
```

**12月15日：寻找小梅**
```
（根据日记线索，找到养老院）

（见到90岁的小梅老人）

小梅（看到陈默，眼神一亮）:
"你……你是……"

陈默:
"您认识一个叫陈默的人吗？"

小梅（流泪）:
"认识……那是我的救命恩人……
他在1937年帮了我们……
然后就消失了……

我一直在等他……
等了87年……"

（两人对视，跨越时空的联系）
```

**12月16日：演讲**
```
（纪念馆大厅，陈默站在讲台）

陈默:
"我站在这里，不是作为一个历史学者，
而是作为一个见证者。

我见过王掌柜的笑容，
听过小梅的哭泣，
目睹过魏特琳的坚强，
也看到过高桥的觉醒。

他们不是数字，不是符号，
他们是人，有名字，有故事。

今天，我在这里，
是要告诉大家——

记住他们。"

（全场肃静）
（镜头拉远，纪念馆全景）
（音乐：《传承》）
```

## 多重结局

### 结局评判维度

1. **存活率**：救下多少人
2. **历史完整度**：日记记录了多少真相
3. **文化传承度**：保存了多少文化
4. **关系深度**：与NPC的羁绊
5. **道德评价**：选择倾向

### 结局类型

**A级结局：完美传承**
- 主要角色大部分存活
- 历史记录>90%
- 文化传承>90%
- 终章见到小梅，讲述完整故事

**B级结局：不完美的见证**
- 部分角色死亡
- 历史记录60-90%
- 有遗憾，但记住了重要的人

**C级结局：残缺的记忆**
- 大量角色死亡
- 历史记录<60%
- 许多故事永远消失

**特殊结局：主角牺牲**
- 在某个道德选择中主角死亡
- 以第三视角结束
- 陈默的名字出现在墙上
