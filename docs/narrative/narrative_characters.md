## 主角：陈默

**基本信息**:
- 年龄：35岁
- 职业：历史学者（2024年）
- 性格：理性、善良、有历史使命感

**背景故事**:
2024年的陈默是一位研究南京大屠杀的历史学者，每年国家公祭日都会来纪念馆。因研究过深，产生了"如果能回到过去"的想法。触碰名字墙后穿越到1937年。

**角色弧光**:
```
初期：震惊、不知所措
     ↓
中期：试图改变历史 → 发现无力
     ↓
后期：接受宿命 → 专注于见证和记录
     ↓
终章：成为历史的传承者
```

**关键特质**:
- 历史知识丰富（优势+负担）
- 现代价值观与民国时代冲突
- 逐渐学会接受"无法改变大历史"

## 王福生（王掌柜）

**基本信息**:
- 年龄：50岁
- 职业：棺材铺老板
- 性格：憨厚、仁义、父爱深沉

**背景故事**:
南京本地人，开棺材铺养活女儿。妻子早逝，独自抚养小梅长大。乱世中坚持做人底线，帮助过许多穷人义葬。

**角色弧光**:
```
房东 → 朋友 → 如同父子
     ↓
生病危机（玩家决定生死）
     ↓
路线A：存活，成为精神支柱
路线B：去世，托付女儿
```

**象征意义**:
代表普通百姓的善良与坚韧，即使在绝境中也保持人性光辉。

## 小梅（王掌柜女儿）

**基本信息**:
- 年龄：18岁
- 职业：无（帮助父亲）
- 性格：柔弱外表下的坚强

**背景故事**:
从小失去母亲，由父亲抚养长大。未受过正规教育但善良懂事。在安全区与李文斌相识相爱。

**角色弧光**:
```
害羞少女 → 经历浩劫 → 成长为坚强女性
     ↓
与李文斌相爱
     ↓
可能怀孕（希望象征）
     ↓
终章：90岁老人，最后的见证者
```

**特殊地位**:
- 唯一活到2024年的角色（如果玩家保护成功）
- 连接双时间线的关键

## 李文斌

**基本信息**:
- 年龄：25岁
- 职业：小学教师
- 性格：斯文、胆怯 → 勇敢

**背景故事**:
知识分子，曾在南京某小学教书。战争爆发后逃难，在逃难途中被日本兵怀疑是败兵。

**角色弧光**:
```
第5章：被救（QTE成功）→ 感恩
     ↓
关系发展：胆怯 → 在陈默鼓励下变勇敢
     ↓
与小梅相爱结婚
     ↓
可能的命运分支：
A. 存活 → 成为小梅的依靠
B. 死亡 → 小梅守寡（历史线）
```

## 魏特琳（Minnie Vautrin）

**基本信息**:
- 年龄：49岁（1937年）
- 职业：金陵女子学院教育系主任
- 国籍：美国

**历史真实人物**:
在南京大屠杀期间保护了上万名中国妇女。战后因创伤后应激障碍，1941年自杀。

**游戏中定位**:
- 精神支柱
- 玩家无法改变她的最终命运（历史宿命主题）
- 但可以减轻她的负担

**角色弧光**:
```
初见：坚强、充满使命感
     ↓
中期：疲惫但坚持
     ↓
后期：精神崩溃边缘
     ↓
离开时：感谢玩家，但历史无法改变
     ↓
终章：玩家在纪念馆看到她的展览
```

## 高桥（虚构角色，代表觉醒者）

**基本信息**:
- 年龄：35岁
- 职业：随军记者（日本）
- 性格：矛盾、痛苦

**背景故事**:
日本知识分子，起初相信战争宣传，但逐渐目睹真相后开始质疑。

**角色弧光**:
```
初期：敌对阵营，但不是恶人
     ↓
中期：与陈默对话（如果日语技能足够）
     ↓
觉醒过程：
- 目睹同僚暴行 → 震惊
- 与陈默深度交流 → 反思
- 拍摄真相照片 → 冒险
     ↓
结局（根据觉醒度）:
高觉醒：决心写真相书，战后忏悔
低觉醒：选择遗忘，后半生痛苦
```

**象征意义**:
- 侵略者阵营中的良心
- 人性复杂性
- 反战主题
