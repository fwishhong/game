## 场景1：序章 - 纪念馆（2024年）

### INT. 南京大屠杀纪念馆 - 白天

```
【陈默独白/旁白】
"2024年12月13日，南京。
第87个国家公祭日。

作为一名历史学者，我每年都会来到这里。
不是为了工作，而是为了铭记。"

【镜头：陈默走过展厅，看着照片和文物】

【陈默独白】
"每一张照片，每一件文物，
背后都是一个鲜活的生命。

但……他们只能是照片和文物了。"

【镜头：遇难者名字墙】

【陈默独白】
"三十万。
一个让人窒息的数字。

但每个数字背后，都是一个人。
都有名字。"

【陈默走近名字墙，手触碰】

陈默（自言自语）:
"陈默……
又是一个陈默……
和我同名……"

【白光闪烁】

陈默:
"这是……什么——"

【画面扭曲，音效：时空穿越】
```

## 场景2：第一章 - 初遇王掌柜（1937年）

### EXT. 南京街道 - 黄昏

```
【陈默从空中坠落，摔在石板路上】

陈默（痛苦）:
"嘶……"

【环顾四周：民国建筑，穿长衫的行人】

陈默（震惊）:
"这是……哪里？
我……穿越了？"

【远处，王福生提着木料走来】

王福生（关切）:
"哎呦！小兄弟这是怎么了？
摔得不轻啊！"

【扶起陈默】

陈默（迷茫）:
"我……我是……"

王福生:
"是不是迷路啦？
这年头，到处都乱糟糟的，
很多人都找不着家了。"

陈默:
"我……找不到家……"

王福生（拍拍陈默肩膀）:
"唉，都不容易。
来，先到我那儿歇歇脚，
喝口热茶，慢慢想。"

陈默（感动）:
"谢谢……谢谢您……"

王福生（憨笑）:
"客气啥！乱世里大家互相帮衬，
才能活下去嘛。

我姓王，王福生，
大家都叫我王掌柜。
开棺材铺的。"

陈默:
"我……我叫陈默。"

王福生:
"好名字！来，跟我走。"
```

## 场景7：第十七章 - 高桥觉醒对话

### EXT. 城外废墟 - 白天

```
【高桥和陈默站在废墟中】

【长时间沉默】

高桥:
"陈桑……
我一直在想……
这真的是……解放吗？"

陈默:
"你觉得呢？"

高桥（痛苦）:
"他们告诉我，我们是在帮助中国，
建立大东亚共荣圈……

但我看到的……
是死亡，是痛苦，是毁灭……"

陈默:
"那你会怎么做？"

高桥:
"我……我不知道……
如果我说出真相，
我会被当成叛徒……"

【如果关系度>80，解锁深度对话】

陈默:
"高桥，我告诉你一个秘密。
几十年后，你们国家的教科书，
会把这段历史……抹去。"

高桥（震惊）:
"什么……？不可能……
这么多人……这么多证据……"

陈默:
"但就是会被掩盖。
所以……记录很重要。
你的照片，你的文字，
都是未来的证据。"

高桥（长时间沉默）:
"……我明白了。
即使没人愿意看，
即使我会被唾骂，
我也要写下真相。

至少……我的良心不会死。"

【获得成就"觉醒者"】
【高桥结局：写下真相之书】
```
