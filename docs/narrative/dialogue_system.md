# 对话系统设计文档

**文档版本**: v1.0
**最后更新**: 2025-11-05

---

## 一、对话系统架构

### 对话类型

1. **线性对话**：剧情推进，无选项
2. **分支对话**：玩家选择影响后续
3. **技能对话**：需要特定技能解锁
4. **关系对话**：基于好感度触发
5. **历史注释对话**：科普历史知识

---

## 二、对话树结构

### 示例：王掌柜第一次对话

```
[ROOT] 王掌柜见到陈默
    │
    ├─> [王掌柜]"哎呦，您就是那位要租房的先生吧？"
    │       │
    │       ├─> [选项A] "是的，麻烦您了。" (+关系2)
    │       │       └─> [王掌柜]"客气啥，乱世里互相帮衬嘛。"
    │       │
    │       ├─> [选项B] "能便宜点吗？" (+关系0)
    │       │       └─> [王掌柜]"这个……行吧，都不容易。"
    │       │
    │       └─> [选项C] [沉默] (-关系1)
    │               └─> [王掌柜]"呃……那……进来坐吧。"
    │
    └─> [NEXT] 进入租房流程
```

## 三、选项标签系统

### 选项类型标识

| 标签 | 说明 | 示例 |
|------|------|------|
| [日语] | 需要日语技能 | [日语]"私はあなたを助けたい" |
| [历史知识] | 需要历史知识 | [历史知识]"12月13日会有危险" |
| [医疗] | 需要医疗技能 | [医疗]"这是伤寒，需要隔离" |
| [谎言] | 说谎（有风险） | [谎言]"我什么都不知道" |
| [勇敢] | 冒险选项 | [勇敢]"让我去！" |
| [道德] | 道德高地 | [道德]"我不能袖手旁观" |

### 选项结果预览

```
[选项A] "帮助他们"
影响: 关系+10, 消耗食物×3, 风险: 中
```

玩家可以看到大致影响（不会完全剧透）

## 四、历史注释系统

### 触发机制

```
         ↑ [H] 查看历史资料

```

## 五、动态对话系统

### 基于关系值

```
王掌柜关系 < 40:
"陈先生，有件事想请你帮忙……"

王掌柜关系 ≥ 40:
"小陈啊，有件事想麻烦你……"

王掌柜关系 ≥ 70:
"陈默，我有话想跟你说……"
（称呼变化反映关系深化）
```

### 基于游戏状态

```
if (食物 < 5):
    NPC对话提及饥饿
if (冬季 and 燃料 < 3):
    NPC对话提及寒冷
if (有人刚死亡):
    NPC对话低落、哀伤
```

## 七、重要对话片段示例

### 抽签处决前的讨论

```
[场景：众人围坐，气氛沉重]

NPC_A:"谁去抽签？"
NPC_B:"公平点，大家一起抽。"
老人C:"让我去吧，我这把老骨头……"

[玩家选择]：
├─ "让老人自愿"（符合原著）
├─ "所有人平等抽签"（公平）
├─ "我也参加抽签"（自我牺牲）
└─ "贿赂日本兵"（消耗资源）

（每个选择有长篇后续对话）
```

### 魏特琳深夜长谈

```
[场景：深夜，办公室]

魏特琳:"陈默，有时候我真的很累……"

陈默:"魏特琳女士……"

魏特琳:"每天看到那么多苦难，那么多人需要帮助……
        但我只有两只手……我救不了所有人……
        有时候我会想，这一切有意义吗？"

[玩家选择]：
├─ [沉默] 默默陪伴
├─ [鼓励]"您已经做得够多了"
├─ [真相] 告诉她未来（如果关系够高）
└─ [拥抱] 给予安慰

（不同选择影响她的疲惫度和后续剧情）
```

## 八、对话实现要点

### 分支追踪

游戏记录所有对话选择，影响：
- 关系值变化
- 剧情分支
- 成就解锁
- 终章内容

### 对话跳过

- 已看过的对话可快速跳过
- 重要选择强制停止
- 支持自动播放模式
