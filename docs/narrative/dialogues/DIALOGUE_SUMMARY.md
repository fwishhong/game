## 👥 NPC深度对话系统

每个主要NPC都有多段深度对话，需要通过建立关系解锁：

### 王掌柜（11段对话）
- **主题**: 生死哲学、家庭、旧南京回忆
- **关系门槛**: 30-90点
- **特色**: 朴实的智慧，民间哲学
- **核心台词**: "人哪，命贱，就像街上的蚂蚁。可是蚂蚁也得活着不是？"

### 小梅（9段对话）
- **主题**: 梦想、爱情、恐惧、成长
- **关系门槛**: 25-60点
- **特色**: 温柔坚韧，战乱中的希望
- **核心台词**: "我想学字，想做个先生，教孩子们读书。"

### 李文斌（10段对话）
- **主题**: 教育理想、愧疚感、未来希望
- **关系门槛**: 30-70点
- **特色**: 书生气质，理想主义
- **核心台词**: "只有教育，才能让中国真正站起来。"

### 魏特琳（11段对话）
- **主题**: 信仰、坚守、人性、疲惫
- **关系门槛**: 30-70点
- **特色**: 西方人道主义，母性光辉
- **核心台词**: "这些孩子，就是中国的未来。"

### 高桥（11段对话）
- **主题**: 家庭、职业道德、觉醒、赎罪
- **关系门槛**: 30-70点
- **特色**: 日本视角，道德挣扎
- **核心台词**: "我杀的人，不比士兵少。我的笔，也是凶器。"

### 赵护士（6段对话）
- **主题**: 失去、坚强、医者仁心
- **关系门槛**: 30-60点
- **特色**: 专业素养，隐藏的脆弱

### 孙老师（6段对话）
- **主题**: 文化传承、牺牲精神、古典文学
- **关系门槛**: 30-65点
- **特色**: 文人风骨，视死如归

## ✨ 技术特性

### Yarn Spinner格式
```yarn
title: 节点ID
tags: 标签1, 标签2
---
<<set $变量 = 值>>

角色名: {情绪} 对话内容 [动作]
    -> 选项1
        <<set $变量 += 10>>
        <<jump 节点A>>
    -> 选项2
        <<jump 节点B>>

<<if $条件>>
    // 条件分支
<<endif>>

===
```

### 情绪标记系统
使用中文情绪标记，便于：
- 配音演员理解情感
- 角色表情动画
- 音调变化

常用标记：
`{平静}` `{高兴}` `{悲伤}` `{愤怒}` `{恐惧}` `{焦虑}` `{无奈}` `{坚定}` `{犹豫}` `{惊讶}` `{绝望}` `{希望}` `{温柔}` `{严肃}` `{讽刺}`

### 动作标记系统
```
[动作] - 简短的舞台指示
[沉默] [叹气] [哭泣] [握手] [拥抱] [鞠躬] [跪下] [摇头] [点头] [推眼镜]
```

### 历史注释系统
```
*注释内容* - 可点击查看历史背景
*唐生智 - 南京保卫战指挥官*
*安全区 - 国际委员会设立的难民保护区*
```
