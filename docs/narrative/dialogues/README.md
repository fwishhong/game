### 对话格式规范

我们使用 **Yarn Spinner** 格式，这是游戏开发中标准的对话树格式。

#### 基础格式

```yarn
title: 对话节点ID
tags: 章节标签, 角色标签
---
<<set $变量名 = 值>>  // 设置变量

角色名: 对话内容
    -> 选项1
        角色名: 回应1
        <<jump 下一个节点>>
    -> 选项2
        角色名: 回应2
        <<jump 另一个节点>>

<<if $条件>>
    // 条件对话
<<endif>>

===
```

#### 特殊标记

```
[动作] - 角色动作描述
{情绪} - 情感标注（用于配音指导和表情）
*历史注释* - 可点击的历史背景说明
```

## 对话写作原则

### 1. 角色声音一致性

**王掌柜**：
- 口语化，带苏北口音的语气词
- 多用"哎呦""嗯呐""可不是"
- 朴实，接地气
- 示例："哎呦，这位先生，您这是怎么了？"

**小梅**：
- 温柔、有礼貌
- 称呼尊重（"陈先生""爹""相公"）
- 情绪外露（容易哭泣）
- 示例："陈先生，您喝点热水吧。"

**李文斌**：
- 书面语较多，文绉绉
- 语气温和但有书生气
- 多引用文言
- 示例："陈兄，此诚危急存亡之秋也。"

**魏特琳**：
- 中式英语语序（翻译腔）
- 坚定、简洁
- 充满责任感
- 示例："这里都是平民。我会保护他们。"

**高桥**：
- 礼貌、客气（日式礼节）
- 内心矛盾时会有停顿
- 职业化的冷静
- 示例："陈先生……我只是在完成工作。"

### 2. 情感递进设计

每段对话都要有情感目标：
- **建立信任**（前期）
- **加深羁绊**（中期）
- **情感爆发**（高潮）
- **回忆与传承**（终章）

### 3. 选择分支设计

每个重要选择都要有：
- **至少3个选项**
- **没有绝对的"对错"**
- **短期和长期后果**
- **角色反应差异**

示例：
```yarn
陈默: [应该告诉他真相吗？]
    -> 告诉他儿子已经死了
        <<set $告诉真相 = true>>
        <<set $关系_张老汉 -= 30>>
    -> 说"可能还在城里"（善意的谎言）
        <<set $善意谎言 = true>>
        <<set $关系_张老汉 += 10>>
        <<set $心理负担 += 5>>
    -> 保持沉默
        <<set $逃避 = true>>
```

### 4. 历史细节融入

对话中自然地融入历史信息：

```yarn
王掌柜: 听说*唐生智*将军撤了，说是去守*江防线*。{苦笑} 守得住吗？

陈默: [心里知道守不住，但不能说]

王掌柜: 城里还有十几万部队呢，怎么说撤就撤了……老百姓怎么办？

*历史注释：唐生智 - 1937年南京保卫战指挥官*
```

### 变量系统

游戏中的对话会影响和读取以下变量：

```javascript
// 全局变量
$current_chapter = 1           // 当前章节
$current_day = 1               // 当前游戏内日期（从腊月初二开始）
$safety_zone_arrived = false   // 是否到达安全区

// 资源变量（影响对话）
$food_level = 50               // 食物水平（0-100）
$morale = 60                   // 士气（0-100）
$safety = 50                   // 安全度（0-100）

// 关系变量（每个NPC一个）
$rel_wangfugui = 0             // 王掌柜好感度（-100 to 100）
$rel_xiaomei = 0
$rel_liwenbin = 0
$rel_vautrin = 0
$rel_takahashi = 0
// ... 其他NPC

// 剧情标记
$saved_liwenbin = false        // 是否救了李文斌
$wangfugui_sick = false        // 王掌柜是否生病
$met_another_chenmo = false    // 是否遇到另一个陈默
$takahashi_awakened = 0        // 高桥觉醒度（0-100）

// 道德选择记录
$moral_choices = []            // 记录所有道德选择
$lies_told = 0                 // 说谎次数
$lives_saved = 0               // 救人次数
$sacrifices_made = 0           // 牺牲次数

// 文化保护
$culture_score = 0             // 文化保存度
$teachings_done = 0            // 教书次数
$books_saved = 0               // 保护的书籍数量
```

## 配音指导

### 情绪标记系统

每句对话都标记情绪，用于：
- 配音演员指导
- 角色表情动画
- 音调变化

情绪标记：
```
{平静} {高兴} {悲伤} {愤怒} {恐惧}
{焦虑} {无奈} {坚定} {犹豫} {惊讶}
{绝望} {希望} {温柔} {严肃} {讽刺}
```

示例：
```yarn
王掌柜: {无奈} 人哪，命贱，就像街上的蚂蚁。[叹气] {坚定} 可是蚂蚁也得活着不是？
```
