# 《秦淮旧梦》全新章节结构设计

## 核心原则

1. **80%过去（1937）+ 20%现在（2024）**
2. **2024线作用**：创造悬念（为何失忆）+ 探索真相（通过后人了解失忆的80天）
3. **关键设定**：
   - 陈默只记得穿越后前7天（12.1-12.7）
   - 后80天（12.8-2.26）完全失忆
   - 1937线采用全知视角，读者能看到全部
   - 2024线陈默自己不知道，需通过调查拼凑真相
4. **小梅第8章见面**：虚弱，说话困难，**未提李文斌**，留下遗物后去世
5. **高桥资料来源**：小梅遗物中（照片、底片、信件）
6. **结局**：作者开始写《秦淮旧梦》

- **序章** + **22章** = 23部分
