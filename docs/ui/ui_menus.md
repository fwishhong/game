## 一、菜单系统架构

### 菜单流程图

```
开始游戏
    ↓
┌─────────────┐
│  主菜单     │
└─────────────┘
    ├─→ [新游戏] → 难度选择 → 开始序章
    ├─→ [继续游戏] → 存档列表 → 载入游戏
    ├─→ [章节选择] → 章节列表 → 选择开始
    ├─→ [设置] → 设置菜单
    ├─→ [历史资料库] → 教育内容
    ├─→ [制作名单] → 鸣谢页面
    └─→ [退出游戏]

游戏中按ESC
    ↓
┌─────────────┐
│  暂停菜单   │
└─────────────┘
    ├─→ [继续游戏]
    ├─→ [保存游戏] → 存档槽选择
    ├─→ [读取游戏] → 存档列表
    ├─→ [设置] → 设置菜单
    ├─→ [返回主菜单] → 确认对话框
    └─→ [退出游戏] → 确认对话框
```

## 六、过渡动画

### 6.1 菜单切换动画

**主菜单 → 游戏**:
1. 按钮按下效果（100ms）
2. 主菜单淡出（500ms）
3. 黑屏过渡（300ms）
4. 载入画面（显示提示）
5. 游戏场景淡入（500ms）

**游戏 → 暂停菜单**:
1. 游戏画面冻结
2. 背景模糊动画（200ms）
3. 暗化叠加（200ms）
4. 菜单淡入（300ms）

**设置页面切换**:
1. 当前页面向左滑出（200ms）
2. 新页面从右侧滑入（200ms）
