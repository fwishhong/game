# 日记界面设计文档

**文档版本**: v1.0
**最后更新**: 2025-11-05

---

## 一、日记系统理念

日记是游戏的**核心叙事机制**，玩家每天晚上必须写日记。设计要求：
- 沉浸式书写体验
- 手写日记的真实感
- 作为"保存证据"的重要性

---

## 二、日记界面布局

### 2.1 书写模式

```
┌────────────────────────────────────────────────────┐
│                                                     │
│           [日记本展开 - 左右两页]                  │
│                                                     │
│  ┌──────────────────┐   ┌──────────────────┐      │
│  │     左页         │   │     右页         │      │
│  │  (已写内容)      │   │  (今日书写)      │      │
│  │                  │   │                  │      │
│  │  民国二十六年    │   │  民国二十六年    │      │
│  │  腊月初七        │   │  腊月初八        │      │
│  │                  │   │                  │      │
│  │  今天王掌柜高烧  │   │  [光标闪烁]      │      │
│  │  不退。小梅哭得  │   │                  │      │
│  │  撕心裂肺……      │   │  今天____        │      │
│  │                  │   │                  │      │
│  │  [已完成]        │   │  [正在书写...]   │      │
│  └──────────────────┘   └──────────────────┘      │
│                                                     │
│   [<上一页]                      [下一页>]        │
│                                                     │
│   重点记录: [某人的故事] [历史细节] [个人感受]    │
│                                                     │
│             [完成书写]  [暂存草稿]                 │
└────────────────────────────────────────────────────┘
```

**设计规格**:
- 日记本尺寸: 1400×900px
- 页面尺寸: 每页 600×800px
- 背景: 老旧泛黄纸张纹理
- 字体: 站酷小薇LOGO体（手写体）, 32px
- 墨迹: 深褐色 #3D2817
- 页边距: 60px

---

### 2.2 书写流程

```
每日夜晚22:00
    ↓
强制进入日记界面
    ↓
日期自动填写
    ↓
选择今日重点（3选1）:
├─ 记录某个人的故事（提升关系）
├─ 记录历史细节（解锁资料库）
└─ 记录个人感受（影响主角心态）
    ↓
系统生成日记草稿
    ↓
玩家可以：
├─ 直接确认（使用默认内容）
├─ 手动修改（自由输入，有字数限制）
└─ 选择语气（客观/感性/悲伤/愤怒）
    ↓
书写动画（毛笔逐字浮现）
    ↓
日记完成，保存
    ↓
解锁当日成就/资料
```

## 四、自动生成内容

### 日记模板系统

根据当日事件自动生成日记内容：

**模板结构**:
```
民国二十六年{月}{日}
{天气}{温度}

{重要事件描述}

{人物互动}

{个人思考}

{明日计划}
```

**示例生成**:
```
民国二十六年腊月初八
天气阴，严寒

今天王掌柜的病情加重了。小梅一夜未眠，
守在父亲床前。我用仅有的药品给他治疗，
但药效甚微。

魏特琳女士给了我们一些木炭，让我们能
烧火取暖。她的眼神里满是疲惫，但依然
坚强。

我感到深深的无力。即使我知道历史，
即使我拼尽全力，依然有太多人我救不了。

明天必须想办法找到更多药品。
```

## 八、UI动画

### 书写动画

1. 日记本翻开（800ms）
2. 页面平铺（400ms）
3. 毛笔出现（200ms）
4. 文字逐字浮现（50ms/字）
5. 墨迹渗透效果

**资源文件**:
- `diary_open_animation.spine` (骨骼动画)
- `diary_brush.png` (毛笔)
