## 一、设计理念

### 核心目标

这是游戏的**核心玩法界面**，玩家每天都要使用。设计必须：

1. **清晰直观**: 一眼看懂当前资源状况和人员需求
2. **快速操作**: 分配流程简洁，减少点击次数
3. **信息完整**: 显示所有决策所需的信息
4. **压力感**: 通过视觉设计传达资源紧张的氛围

### 视觉风格

- **民国账本风格**: 竖排文字、毛笔字、老旧纸张
- **手绘图标**: 食物、水、药品等用手绘插画表现
- **暖黄色调**: 模拟烛光下查看账本的感觉

## 四、分配流程设计

### 4.1 标准流程

```
打开界面
    ↓
查看库存（红色提醒不足）
    ↓
选择分配模式：
├─ 快速模板 → 一键应用 → 查看预测
└─ 手动分配 → 逐个调整 → 查看预测
    ↓
预测结果满意？
├─ 是 → 确认分配 → 执行
└─ 否 → 调整方案 → 重新预测
    ↓
关闭界面，资源扣除
```

## 九、技术实现要点

### 9.1 数据结构（伪代码）

```csharp
// 资源数据
public class ResourceData
{
    public int food;
    public int water;
    public int medicine;
    public int fuel;
    public int cloth;
}

// 人员数据
public class PersonData
{
    public string name;
    public int health;      // 0-100
    public int hunger;      // 0-100
    public int morale;      // 0-100
    public bool isSick;
    public bool isPregnant;
    public int age;

    // 需求
    public ResourceData dailyNeeds;

    // 优先级
    public int priority;    // 0-3
}

// 分配结果预测
public class AllocationResult
{
    public ResourceData consumed;
    public ResourceData remaining;
    public List<string> warnings;
    public int healthChange;
    public int moraleChange;
}
```

### 9.2 智能推荐算法（简化）

```csharp
public AllocationResult SmartRecommend(ResourceData resources, List<PersonData> people)
{
    // 1. 按优先级排序
    people.Sort((a, b) => b.priority - a.priority);

    // 2. 病人优先药品
    foreach (var person in people.Where(p => p.isSick))
    {
        AllocateMedicine(person);
    }

    // 3. 健康度<30优先食物水
    foreach (var person in people.Where(p => p.health < 30))
    {
        AllocateBasic(person);
    }

    // 4. 剩余资源平均分配
    DistributeRemaining();

    // 5. 预测结果
    return CalculateResult();
}
```
