## 一、设计理念

### 核心原则

1. **沉浸优先，功能其次**
   - UI不应过度游戏化，避免破坏叙事沉浸感
   - 优先选择融入场景的UI设计，而非浮动HUD

2. **历史感与现代交融**
   - 1937年场景：民国美学（毛笔字、竖排文字、老纸张质感）
   - 2024年场景：现代简约（扁平化、清晰字体）
   - 两种风格对比强烈，强化时空穿越感

3. **情绪引导**
   - 使用视觉语言传达压抑、紧张、温暖等情绪
   - 颜色、字体、动画都服务于情感表达

4. **无障碍设计**
   - 支持色盲模式
   - 字体大小可调
   - 重要信息多重反馈（视觉+听觉+震动）

## 二、整体风格定位

### 1937年UI风格

**视觉特征**:
- 颜色：黑、白、灰主色调，黄色（灯光）、红色（强调）点缀
- 字体：仿宋、楷体、手写体
- 纹理：旧纸张、墨迹、布料
- 边框：水墨笔触、不规则边缘
- 图标：手绘风格、线条简洁

**参考**:
- 民国报纸排版
- 老照片质感
- 《刺客信条编年史：中国》UI
- 水墨画风格游戏

### 2024年UI风格

**视觉特征**:
- 颜色：高饱和度、明亮
- 字体：思源黑体、微软雅黑
- 材质：玻璃拟态（Glassmorphism）、微妙阴影
- 边框：圆角、清晰边界
- 图标：现代扁平风格

**参考**:
- iOS/Android原生UI
- 现代博物馆APP
- 纪录片UI设计

## 五、交互设计规范

### 5.1 输入方式

**键盘+鼠标（PC主要）**:
- WASD/方向键：移动
- E：互动
- Space：跳过对话/快进
- ESC：暂停菜单
- Tab：打开资源管理
- J：打开日记
- 鼠标点击：所有UI交互

**手柄（Console）**:
- 左摇杆：移动
- A键（X键）：互动/确认
- B键（○键）：取消/返回
- X键（□键）：快捷功能
- Y键（△键）：打开日记
- Start：暂停
- 方向键：UI导航

**触屏（移动端，如果适配）**:
- 虚拟摇杆：移动
- 点击：互动
- 滑动：查看
- 双指缩放：地图

### 5.2 反馈机制

**视觉反馈**:
- 按钮悬停：高亮+微妙放大（1.05倍）
- 点击：缩小动画（0.95倍）
- 不可用：灰度处理+降低透明度（50%）
- 重要提示：呼吸光效动画

**听觉反馈**:
- 按钮悬停：轻微"纸张沙沙"声（1937）/ "咔哒"声（2024）
- 确认：低沉鼓声（1937）/ 清脆提示音（2024）
- 错误：不和谐音
- 资源变化：对应实物音效（食物、水等）

**触觉反馈（手柄）**:
- 选择确认：短震动
- 重要事件：长震动
- 危险警告：间歇震动

## 六、动画与过渡

### 6.1 UI动画时长标准

| 动画类型 | 时长 | 缓动函数 | 说明 |
|---------|------|---------|------|
| 按钮悬停 | 100ms | Ease-out | 快速响应 |
| 面板打开 | 300ms | Ease-in-out | 舒适自然 |
| 面板关闭 | 200ms | Ease-in | 快速退出 |
| 过场转换 | 500ms | Ease-in-out | 重要转换 |
| 文字逐字显示 | 50ms/字 | Linear | 可跳过 |
| 提示淡入淡出 | 200ms | Ease-in-out | 不打扰 |

### 6.2 特殊转场动画

**穿越转场（2024→1937）**:
1. 画面扭曲（500ms）
2. 色彩去饱和（300ms）
3. 水墨晕染效果（400ms）
4. 过渡到黑白画面
5. 1937年场景淡入

**日记书写动画**:
1. 纸张展开（300ms）
2. 笔尖出现（200ms）
3. 文字逐字浮现（50ms/字）
4. 墨迹渲染效果

## 十、无障碍设计

### 10.1 色盲友好

**色盲模式切换**:
- 正常模式
- 红绿色盲模式（使用蓝-黄对比）
- 蓝黄色盲模式（使用亮度对比）
- 全色盲模式（纯黑白+符号区分）

**实现**:
- 不仅依赖颜色传达信息
- 重要状态附加图标/纹理
- 颜色+形状双重编码

### 10.2 字体缩放

- 支持3档字体大小：小（90%）、中（100%）、大（120%）
- UI布局自适应字体大小
- 最小字号不低于18px

### 10.3 操作简化

- 所有操作支持键盘快捷键
- 重要操作有二次确认
- 支持暂停随时保存
- QTE难度可调

## 十一、性能与优化

### 11.1 UI性能指标

- UI帧率：60fps（独立于游戏主循环）
- 面板打开延迟：<100ms
- 输入响应延迟：<50ms
- 内存占用：UI资源<200MB

### 11.2 优化策略

**资源管理**:
- UI图集打包（减少DrawCall）
- 未显示的UI面板不渲染
- 复杂UI使用RenderTexture缓存
- 字体纹理预生成常用字符

**动画优化**:
- 使用GPU加速的Shader动画
- 复杂动画使用骨骼动画而非序列帧
- 视野外UI停止更新

## 十三、开发工具与流程

### 13.1 设计工具

- **原型设计**: Figma / Adobe XD
- **图标制作**: Adobe Illustrator
- **界面美术**: Adobe Photoshop
- **动画**: After Effects → Lottie / Spine
- **字体**: FontForge（自定义字体）

### 13.2 实现工具

- **游戏引擎UI**: Unity uGUI / Unreal UMG
- **富文本**: TextMeshPro
- **动画**: DOTween / Animator
- **本地化**: I2 Localization / Custom

### 13.3 测试流程

1. **设计阶段**: 纸面原型 → 交互原型（Figma）
2. **实现阶段**: 灰盒测试 → 美术替换
3. **测试阶段**:
   - 功能测试（所有按钮可用）
   - 布局测试（多分辨率）
   - 本地化测试（文本溢出）
   - 无障碍测试（色盲模式、大字体）
   - 性能测试（帧率、内存）
4. **抛光阶段**: 动画微调 → 音效配合
