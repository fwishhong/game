## 一、HUD设计理念

### 核心原则

1. **最小化干扰**: HUD应该尽可能不遮挡游戏画面
2. **情境自适应**: 根据游戏状态显示/隐藏不同元素
3. **沉浸式整合**: 尽量融入场景，而非浮动在上方
4. **信息层级**: 关键信息突出，次要信息可隐藏

## 四、HUD状态切换

### 4.1 不同模式下的HUD显示

| 游戏模式 | 显示元素 | 隐藏元素 |
|---------|---------|---------|
| 自由探索 | 全部HUD | - |
| 对话中 | 日期、资源快显 | 角色卡、提示框、目标 |
| 剧情CG | - | 全部（黑边电影模式） |
| 资源管理界面打开 | 仅日期 | 其余全部 |
| 日记书写 | - | 全部 |
| 暂停菜单 | - | 全部（背景模糊） |
| 地图查看 | 日期、资源 | 角色卡、提示 |

### 4.2 自动隐藏机制

**条件**:
- 玩家静止超过3秒 → HUD逐渐淡出（保留10%透明度）
- 玩家移动 → HUD立即恢复
- 重要事件发生 → 强制显示HUD
- 截图模式（F11） → 完全隐藏HUD

## 七、技术实现

### 7.1 Canvas设置（Unity）

```csharp
Canvas Settings:
- Render Mode: Screen Space - Overlay
- Pixel Perfect: True
- Sort Order: 100 (最高层)
- Additional Shader Channels: TexCoord1, Normal, Tangent

Canvas Scaler:
- UI Scale Mode: Scale With Screen Size
- Reference Resolution: 1920×1080
- Screen Match Mode: Match Width Or Height
- Match: 0.5 (居中权重)
```

### 7.2 锚点设置

| UI元素 | 锚点 | 轴心 | 说明 |
|--------|------|------|------|
| 日期显示 | (0, 1) | (0, 1) | 左上角锚定 |
| 状态栏 | (1, 1) | (1, 1) | 右上角锚定 |
| 角色卡 | (0, 0) | (0, 0) | 左下角锚定 |
| 提示框 | (1, 0) | (1, 0) | 右下角锚定 |
| 目标提示 | (0.5, 1) | (0.5, 1) | 顶部居中 |
| 资源快显 | (1, 0.5) | (1, 0.5) | 右侧居中 |

### 7.3 性能优化

**优化策略**:
1. 使用图集减少DrawCall（所有HUD元素打包到2个图集）
2. 不可见元素禁用Canvas Renderer
3. 使用对象池管理临时UI（提示气泡）
4. 状态条使用Shader而非Image Fill
5. 避免每帧更新，使用事件驱动

**目标性能**:
- DrawCall: <10
- SetPass Call: <5
- 内存: <50MB
- 帧率: 60fps（UI独立渲染）
