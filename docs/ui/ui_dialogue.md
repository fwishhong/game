## 一、对话框设计

### 标准对话框布局

```
┌────────────────────────────────────────────────────┐
│                                                     │
│            [角色立绘 - 半身像]                     │
│              (左侧/右侧/居中)                       │
│                                                     │
├────────────────────────────────────────────────────┤
│  王掌柜                        民国二十六年腊月初八│
│                                                     │
│  "小陈啊，今天外面又不太平了。我听说日本兵        │
│   又在城东抓人了……咱们得小心点。"                │
│                                                     │
│  ▸ 继续阅读 [Space]                    [Skip ⏭️]  │
└────────────────────────────────────────────────────┘
```

**设计规格**:
- 对话框尺寸: 1600×400px
- 位置: 屏幕底部，边距40px
- 背景: 半透明旧纸张，Alpha 0.9
- 字体: 仿宋GB2312, 28px
- 文字颜色: #2A2A2A
- 文字逐字显示: 50ms/字

**资源文件**:
- `ui_dialogue_box_bg.png` (1600×400)
- `ui_dialogue_name_tag.png` (300×60)
- `ui_dialogue_border.png` (装饰边框)

## 二、选择分支系统

### 选项显示

```
┌────────────────────────────────────────────────────┐
│  王掌柜等待你的回答……                              │
│                                                     │
│  ► 【安慰】"别担心，我们一定能挺过去。"            │
│    影响: 士气+5, 关系+2                            │
│                                                     │
│  ► 【实话实说】"情况确实很危险，我们要做最坏打算。"│
│    影响: 信任+5, 士气-3                            │
│                                                     │
│  ► 【转移话题】"您女儿小梅在哪？"                  │
│    影响: 无                                         │
│                                                     │
│  ⏱️ 限时选择: 15秒                                │
└────────────────────────────────────────────────────┘
```

**选项类型**:
1. **情感型**: [安慰][鼓励][批评]
2. **行动型**: [帮助][拒绝][逃避]
3. **信息型**: [询问][撒谎][沉默]
4. **技能型**: [日语交涉][历史知识][医疗帮助] - 需要技能

**资源文件**:
- `ui_dialogue_choice_normal.png` (1200×80)
- `ui_dialogue_choice_hover.png` (1200×80)
- `ui_dialogue_choice_selected.png` (1200×80)
- `ui_dialogue_timer_bar.png` (400×20)

## 四、重大选择界面

### 道德困境UI

```
═══════════════════════════════════════════
          重大选择 - 抽签处决
═══════════════════════════════════════════

日本军官要求必须有10人抽签，抽到死签的人
将被处决。作为临时负责人，你必须决定：

┌────────────────────────────────────────┐
│  方案A: 让所有成年人平等抽签          │
│  · 公平，但可能失去劳动力             │
│  · 群体道德评价: 正义                 │
│  · 风险: 高                           │
└────────────────────────────────────────┘

┌────────────────────────────────────────┐
│  方案B: 让老人自愿                     │
│  · 符合原著剧情                       │
│  · 老人孙先生会主动站出来             │
│  · 获得成就 "壮士暮年"                │
│  · 群体士气: -10                      │
└────────────────────────────────────────┘

┌────────────────────────────────────────┐
│  方案C: 自己参与抽签                   │
│  · 如果抽中: Game Over                │
│  · 道德评价: 最高                     │
│  · 其他人忠诚度: +50                  │
│  · 风险: 致命                         │
└────────────────────────────────────────┘

这个选择将永久影响故事走向。

[时间冻结 - 仔细考虑]
```

**特点**:
- 全屏显示，背景暗化
- 无时间限制
- 显示详细后果
- 可以查看相关人员信息
- 有"后悔"提示（可读档重选）

## 五、快速对话模式

### 探索时对话

```
┌──────────────────────┐
│ 难民A:               │
│ "听说今天有发粥？"  │
└──────────────────────┘
     ↓ (自动消失)
```

简化版，用于非关键NPC的短对话。
