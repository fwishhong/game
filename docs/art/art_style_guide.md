## 概述

本文档定义《秦淮旧梦》的整体美术风格、色彩规范、技术标准和质量要求，是所有美术资源制作的权威指南。

### 核心设计理念

**"水墨记忆，真实伤痕"**

- **水墨写意**: 1937年场景采用中国传统水墨画风格，强调笔触感和灰度层次
- **照片写实**: 2024年场景采用照片级写实风格，强调色彩和现代感
- **对比叙事**: 通过视觉风格的强烈对比，传达时空、历史、记忆的主题
- **克制表达**: 严肃题材，避免过度装饰，让叙事本身说话

## 一、整体风格定位

### 1.1 风格关键词

| 时代 | 视觉风格 | 情感基调 | 参考艺术 |
|-----|---------|---------|---------|
| **1937年** | 水墨、克制、沉重 | 压抑、悲伤、温暖（局部） | 传统水墨画、民国老照片 |
| **2024年** | 写实、鲜艳、明亮 | 和平、希望、反思 | 纪实摄影、现代都市 |
| **转场/穿越** | 超现实、抽象 | 混乱、迷失、顿悟 | 实验电影、时间艺术 |

### 1.2 视觉语言

#### 1937年场景视觉语言

```
笔触: 可见的水墨笔触，边缘不规则，有晕染感
色彩: 黑白灰为主（占95%），强调色极少（红、黄，占5%）
对比: 高对比度，阴影深沉，高光明确
纹理: 宣纸质感、木纹、石纹，手绘感
构图: 中国画构图法，讲究留白和虚实
光影: 硬光为主，强烈明暗对比，戏剧性
```

#### 2024年场景视觉语言

```
风格: 照片级写实，细节丰富
色彩: 全彩，饱和度中等偏高
对比: 柔和对比，阴影有细节
纹理: 现代材质，金属、玻璃、混凝土
构图: 摄影构图法，对称、引导线
光影: 柔光，自然光照，真实感
```

## 二、色彩系统

### 2.1 1937年色彩规范

#### 主色板（黑白灰系统）

| 色名 | 十六进制 | RGB | 用途 | 占比 |
|-----|---------|-----|------|------|
| 纯黑 | #000000 | 0,0,0 | 最深阴影、夜空、头发 | 20% |
| 深墨灰 | #1A1A1A | 26,26,26 | 深色物体、重阴影 | 15% |
| 中深灰 | #3D3D3D | 61,61,61 | 暗部、阴影过渡 | 15% |
| 中灰 | #6B6B6B | 107,107,107 | 中间调、建筑、衣物 | 20% |
| 浅灰 | #9E9E9E | 158,158,158 | 亮部、浅色物体 | 15% |
| 淡灰 | #CFCFCF | 207,207,207 | 高光过渡、天空 | 10% |
| 近白 | #F0F0F0 | 240,240,240 | 最亮高光、雪、纸张 | 5% |

**使用规则**:
- 背景主要使用中灰到淡灰
- 角色使用中深灰到中灰，高光用浅灰
- 天空使用淡灰，阴天感觉
- 积雪、纸张用近白

---

#### 强调色（限量使用）

| 色名 | 十六进制 | RGB | 用途 | 使用限制 |
|-----|---------|-----|------|---------|
| 暗红（血） | #8B0000 | 139,0,0 | 血迹、生命危险 | 极少量，点缀 |
| 梅花红 | #DC143C | 220,20,60 | 梅花、希望象征 | 关键场景 |
| 暖黄（灯光） | #DAA520 | 218,165,32 | 油灯、灯笼、温暖 | 室内光源 |
| 冷蓝 | #4A6FA5 | 74,111,165 | 月光、忧郁时刻 | 夜晚场景 |
| 枯黄 | #B8860B | 184,134,11 | 枯草、荒凉 | 废墟场景 |

**强调色使用原则**:
- 占画面<5%面积
- 必须有剧情或情感意义
- 不能只为好看而使用
- 红色极其克制，关联生死

**示例场景色彩分配**:
```
室内（王掌柜家）:
- 背景墙: 中灰 #6B6B6B
- 木制家具: 中深灰 #3D3D3D
- 地面: 中灰 #6B6B6B
- 油灯光晕: 暖黄 #DAA520（小范围）
- 阴影: 深墨灰 #1A1A1A
- 窗外: 淡灰 #CFCFCF（微亮）
```

#### 主色板（全彩系统）

| 色域 | 代表色 | 十六进制 | 用途 |
|-----|-------|---------|------|
| 天空蓝 | 现代天空 | #87CEEB | 晴天天空 |
| 草绿 | 现代植被 | #5A8B3C | 草地、树木 |
| 砖红 | 建筑外墙 | #A0522D | 砖墙、传统建筑 |
| 混凝土灰 | 现代建筑 | #B8B8B8 | 现代楼宇 |
| 路面灰 | 地面 | #696969 | 沥青、路面 |
| 灯光暖黄 | 室内照明 | #FFE4B5 | 室内灯光 |
| 霓虹彩色 | 商业区 | 多种 | 广告牌、灯光 |

**使用规则**:
- 饱和度保持中等（40-70%）

**纪念馆特殊色板**:
```
主色调: 冷灰蓝 #6D7B8D（墙面、地面）
强调: 深灰 #2F4F4F（文字、展品）
高光: 白色冷光 #E0E8F0（灯光）
禁止: 暖色、鲜艳色
```

## 三、水墨技法指南

### 3.1 笔触表现

#### 笔触类型

| 笔触名 | 用途 | 技法 | 示例位置 |
|-------|------|------|---------|
| 大写意 | 远景山、天空、雾气 | 大笔挥洒，边缘模糊 | 背景远山 |
| 小写意 | 中景建筑、树木 | 中笔勾勒+皴擦 | 房屋、树木 |
| 工笔 | 近景人物、重要道具 | 细笔勾线+晕染 | 角色立绘 |
| 飞白 | 质感表现 | 枯笔，留白 | 粗糙墙面、木纹 |
| 泼墨 | 情绪强烈时刻 | 大量水墨倾泻 | 转场、冲击场景 |

#### 笔触制作方法

**Photoshop笔刷设置**:
```
基础笔刷: 软毛笔刷
形状动态:
  - 大小抖动: 30-50%（压感）
  - 角度抖动: 20-40%
散布: 10-20%
纹理:
  - 宣纸纹理叠加
  - 缩放: 80-120%
传递:
  - 不透明度抖动: 20-30%（压感）
```

**手绘流程**（推荐）:
1. 真实宣纸 + 墨汁手绘
2. 高分辨率扫描（600dpi）
3. Photoshop调整对比度和层次
4. 数字上色（如需要强调色）

---

### 3.2 水墨晕染技术

#### 晕染类型

| 晕染名 | 效果 | 制作方法 | 用途 |
|-------|------|---------|------|
| 湿染 | 边缘柔和，渐变自然 | 水分多，墨色扩散 | 天空、雾气、阴影 |
| 干染 | 边缘清晰，层次分明 | 水分少，层层叠加 | 山石、建筑、衣物 |
| 泼染 | 大面积，随机肌理 | 大量水墨，自然流动 | 背景氛围、特殊效果 |
| 积染 | 深色区域，多层叠加 | 反复晕染，逐渐加深 | 深阴影、夜空 |

#### 晕染制作流程

```
数字晕染流程:
1. 新建图层，柔角笔刷
2. 降低笔刷硬度（0-20%）
3. 降低流量（10-30%）
4. 多次叠加，逐步加深
5. 橡皮擦修边，模拟水迹
6. 叠加宣纸纹理
```

---

### 3.3 留白艺术

**留白原则**:
- 不填满画面，给画面"呼吸空间"
- 天空、远景大量留白
- 重要物体周围留白，突出主体
- 用留白表现雾气、雪、光

**留白比例建议**:
```
远景: 50-70%留白（天空、远山）
中景: 30-40%留白（建筑间隙、街道）
近景: 10-20%留白（人物周围）
特写: 5-10%留白（脸部特写）
```

## 四、光影系统

### 4.1 1937年光影规范

#### 光照类型

| 光源类型 | 特征 | 色温 | 对比度 | 应用场景 |
|---------|------|------|-------|---------|
| 冬日阴天（主） | 漫射光，无明确方向 | 冷白 | 中等 | 室外白天（最常见） |
| 油灯/灯笼 | 点光源，衰减快 | 暖黄 | 高 | 室内夜晚 |
| 月光 | 冷色，对比强烈 | 冷蓝 | 非常高 | 室外夜晚 |
| 火光（篝火） | 跳动，暖色，局部 | 橙黄 | 高 | 安全区庭院 |
| 窗户透光 | 定向光束，体积感 | 冷白 | 高 | 室内白天 |

#### 阴影规范

**硬阴影** (Hard Shadow):
```
使用场景: 强光源（太阳、油灯、月光）
边缘: 清晰
浓度: 80-100%不透明
颜色: 纯黑或深墨灰
```

**软阴影** (Soft Shadow):
```
使用场景: 漫射光（阴天）
边缘: 模糊渐变
浓度: 40-60%不透明
颜色: 中灰
```

**投影长度**:
```
正午太阳: 投影短（0.3-0.5倍物体高度）
傍晚: 投影长（1.5-3倍物体高度）
油灯: 投影长且变形（透视）
```

---

### 4.2 2024年光影规范

**现代光照特点**:
- 多光源：室内有多个灯具
- 柔光为主：减少硬阴影
- 真实感：遵循物理光照规律
- 环境光：反射光、间接光

**室内光照** (纪念馆):
```
主光: 顶部筒灯，冷白色，柔光
辅光: 展品射灯，定向照明
环境光: 地面、墙面反射光
阴影: 极淡，几乎不可见
```

**室外光照** (现代南京):
```
主光: 太阳光（或阴天漫射）
天空光: 蓝色环境光
人工光: 路灯、广告牌（夜晚）
阴影: 柔和，有环境光填充
```

### 4.3 光影绘制技术

#### 图层结构

```
PSD图层结构（场景）:
├─ 高光层（Overlay模式，白色）
├─ 发光层（Additive模式，光源色）
├─ 前景层（物体）
├─ 中景层（物体）
├─ 背景层（物体）
├─ 阴影层（Multiply模式，黑/灰）
└─ 底色层（环境光）
```

#### 高光绘制

**1937年高光**:
```
位置: 光源正对面
形状: 边缘清晰（硬光）或渐变（漫射）
颜色: 纯白或淡黄（灯光）
强度: 高对比，明确
技法: 硬笔刷 + 柔角橡皮擦修边
```

**2024年高光**:
```
位置: 符合物理反射
形状: 柔和渐变
颜色: 根据光源和材质
强度: 适中，真实感
技法: 渐变工具 + 图层混合
```

## 五、质感与材质

### 5.1 材质库（1937年）

#### 木材质感

| 类型 | 视觉特征 | 绘制方法 |
|-----|---------|---------|
| 新木 | 清晰木纹，浅灰色 | 细线条纹理 + 中灰底色 |
| 旧木 | 裂纹、斑驳、深色 | 不规则纹理 + 深灰底 + 损坏贴花 |
| 棺材木 | 黑漆、反光、庄重 | 深黑底 + 高光 + 少量纹理 |

**制作步骤**:
1. 底色：中灰或深灰
2. 木纹：使用木纹笔刷或手绘纹理
3. 明暗：加深暗部，提亮亮部
4. 细节：裂纹、钉子、磨损
5. 高光：反光部分加白色高光

---

#### 石材质感

| 类型 | 视觉特征 | 绘制方法 |
|-----|---------|---------|
| 青砖 | 灰色、规则、有缝隙 | 矩形排列 + 接缝阴影 |
| 石板路 | 不规则形状、磨损 | 多边形拼接 + 裂纹 |
| 井口石 | 圆形、光滑、苔藓 | 同心圆纹理 + 绿色苔斑 |

---

#### 布料质感

| 类型 | 视觉特征 | 绘制方法 |
|-----|---------|---------|
| 棉布（衣物） | 褶皱、柔软、吸光 | 柔和阴影 + 褶皱线条 |
| 麻布（粗糙） | 纹理粗、硬挺 | 粗糙纹理 + 不规则褶皱 |
| 丝绸（少见） | 光滑、反光 | 柔顺褶皱 + 明显高光 |

**褶皱绘制原则**:
- 受力点：拉伸方向褶皱少
- 堆积处：褶皱密集
- 阴影：褶皱凹处深色
- 高光：褶皱凸处亮色

---

#### 纸张质感

| 类型 | 视觉特征 | 绘制方法 |
|-----|---------|---------|
| 宣纸 | 纹理粗糙、吸墨 | 纤维纹理 + 墨迹晕染 |
| 旧纸 | 泛黄、褶皱、破损 | 黄褐色底 + 污渍 + 破洞 |
| 书页 | 整洁、文字痕迹 | 淡灰底 + 横线 + 字迹 |

**纸张纹理制作**:
1. 基础：浅灰或米黄色底
2. 纹理：叠加纤维纹理（低不透明度）
3. 污渍：随机深色斑点
4. 破损：边缘不规则，撕裂效果
5. 褶皱：线性压痕 + 阴影

---

### 5.2 材质库（2024年）

#### 现代材质

| 类型 | 视觉特征 | 绘制/处理方法 |
|-----|---------|--------------|
| 混凝土 | 灰色、光滑、细微纹理 | 照片贴图 + 细节增强 |
| 玻璃 | 透明、反射、高光 | Alpha通道 + 反射贴图 + 高光 |
| 金属（不锈钢） | 镜面反射、冷色调 | 环境反射贴图 + 镜面高光 |
| 沥青路面 | 深灰、粗糙、标线 | 照片贴图 + 法线贴图 |
| 塑料 | 半透明或不透明、轻微反光 | 统一底色 + 柔和高光 |

**制作原则**:
- 优先使用真实照片贴图
- 注重细节：污渍、磨损、反射
- 物理准确：遵循PBR材质规范
- 适度处理：保持真实感，不过度修图

## 六、构图原则

### 6.1 1937年场景构图

#### 中国画构图法

**三远法**:
- 高远：仰视，表现崇高、压迫
- 深远：平视，表现纵深、空间
- 平远：俯视，表现广阔、全景

**虚实对比**:
- 实：主体物，细节丰富，对比强
- 虚：背景，模糊，对比弱
- 原则：实不离虚，虚实相生

**留白运用**:
- 上留白：天空、精神空间
- 下留白：地面、稳定感
- 侧留白：延伸空间、方向引导

#### 黄金分割

- 重要物体放在画面黄金分割点
- 地平线位置：上1/3或下1/3
- 人物位置：偏左或偏右（不居中）

---

### 6.2 2024年场景构图

#### 摄影构图法

**三分法**:
- 画面分为3x3网格
- 重要元素放在交叉点
- 地平线沿水平线

**对称构图**:
- 用于建筑、纪念馆场景
- 强调庄严、秩序
- 中轴对称

**引导线**:
- 利用道路、栏杆、建筑线条
- 引导视线到兴趣点
- 增强纵深感

**框架构图**:
- 用门框、窗户框住主体
- 增强画面层次
- 聚焦注意力

---

### 6.3 角色立绘构图

**构图规范**:
```
全身立绘:
- 画布: 2048x2048（正方形）
- 角色占比: 画面高度的70-85%
- 头部位置: 画面上1/4处
- 脚部: 留出底部10-15%空间
- 左右: 居中或微偏（视线方向相反）
```

**表情特写**:
```
画布: 512x512
脸部占比: 60-70%
眼睛位置: 上1/3线附近
留白: 视线方向留出空间
```

## 七、角色设计规范

### 7.1 人物比例

#### 写实比例（本游戏采用）

```
成年男性:
- 总高: 7.5-8个头身
- 肩宽: 2个头宽
- 腰部: 1.2-1.5个头宽
- 腿长: 4-4.5个头身

成年女性:
- 总高: 7-7.5个头身
- 肩宽: 1.5-1.8个头宽
- 腰部: 1-1.2个头宽
- 腿长: 4-4.5个头身

老年人:
- 略微驼背，减少0.5个头身
- 肩膀下垂
- 增加皱纹细节
```

### 7.2 服装设计

#### 1937年服装规范

**男性服装**:

| 类型 | 特征 | 颜色 | 细节 |
|-----|------|------|------|
| 长衫（书生） | 立领、大襟、宽袖 | 深灰、黑色 | 布质纽扣、腰带 |
| 棉袍（工人） | 对襟、窄袖、短款 | 深灰、深蓝 | 补丁、磨损 |
| 西装（少数） | 西式、领带 | 深色 | 皱褶、灰尘 |

**女性服装**:

| 类型 | 特征 | 颜色 | 细节 |
|-----|------|------|------|
| 旗袍（少见） | 高领、盘扣、开叉 | 素色为主 | 简朴，非华丽 |
| 布衣（常见） | 对襟、窄袖 | 灰色、深蓝 | 朴素、干净 |
| 棉袄（冬季） | 厚实、层次 | 深色 | 棉絮外露 |

**服装绘制要点**:
- 时代准确：参考历史照片
- 质感表现：布料褶皱、磨损
- 破旧感：战乱时期，衣物陈旧
- 无装饰：避免华丽花纹（除特殊角色）

---

#### 2024年服装规范

**现代服装**:
- 休闲装：T恤、牛仔裤、运动鞋
- 正装：衬衫、西裤（主角教师身份）
- 老年人：简朴现代服装
- 颜色：多样化，但不过度鲜艳

**服装细节**:
- 品牌Logo（可选，不强调）
- 拉链、纽扣等细节
- 现代感：材质光泽、剪裁

---

### 7.3 面部设计

#### 面部比例（三庭五眼）

```
三庭:
- 上庭: 发际线到眉毛（额头）
- 中庭: 眉毛到鼻底
- 下庭: 鼻底到下巴

五眼:
- 脸宽 = 5个眼睛宽度
- 两眼间距 = 1个眼宽
```

#### 年龄特征

**18岁（小梅）**:
- 皮肤光滑无瑕
- 眼睛大而明亮
- 脸部轮廓柔和
- 无皱纹

**35岁（陈默、高桥）**:
- 轻微眼周细纹
- 面部轮廓清晰
- 眼神成熟

**50岁（王掌柜）**:
- 明显皱纹（额头、眼角、法令纹）
- 皮肤松弛
- 眼袋
- 花白头发

**90岁（老年小梅）**:
- 深刻皱纹（全脸）
- 皮肤斑点
- 眼睛浑浊但温柔
- 白发

---

#### 表情设计

**表情强度**:
```
微表情（日常）:
- 眉毛轻微变化
- 嘴角微动
- 眼神细微不同

中等表情（情绪明显）:
- 眉毛明显变化（上扬/皱起）
- 嘴部明显动作
- 眼睛变化（睁大/眯起）

强表情（极端情绪）:
- 夸张的眉毛动作
- 嘴部大幅变形
- 整体面部肌肉运动
```

**表情要点**:
- 眼睛是灵魂：最重要的表情部位
- 眉毛传情：喜怒哀乐首先看眉毛
- 嘴部次要：配合眉眼
- 整体协调：避免表情"僵硬"

### 8.1 文件规范

#### 源文件（PSD）

```
文件结构:
- 文件名: [类型]_[名称]_[变体].psd
- 颜色模式: RGB（8位或16位）
- 分辨率: 300 DPI（印刷级）

- 图层组织: 使用文件夹分组

```

#### 导出格式

| 用途 | 格式 | 设置 |
|-----|------|------|
| 场景背景 | PNG-24 | 最高质量 |
| 角色立绘 | PNG-32 | Alpha通道 |
| UI元素 | PNG-32 | Alpha通道 |
| 道具/装饰 | PNG-32 | Alpha通道 |
| 纹理（平铺） | PNG-8或JPG | 优化大小 |

### 8.2 分辨率标准

| 资源类型 | 基准分辨率 | 4K分辨率 | 最小分辨率 |
|---------|-----------|---------|-----------|
| 场景背景 | 1920x1080 | 3840x2160 | 1280x720 |
| 角色立绘（全身） | 2048x2048 | 4096x4096 | 1024x1024 |
| 角色立绘（半身） | 1024x1024 | 2048x2048 | 512x512 |
| 表情头像 | 512x512 | 1024x1024 | 256x256 |

| UI按钮 | 512x128 | 1024x256 | 256x64 |

**制作建议**:
- 始终以4K制作，再缩小到1080p
- 保留高分辨率源文件
- 导出多套分辨率（1080p、1440p、4K）

### 9.2 常见问题与解决

#### 问题：水墨风格太"飘"，不够稳重

**解决**:
- 增加边缘清晰度（选择性）
- 加强明暗对比
- 减少过度晕染
- 增加细节（前景物体）

#### 问题：黑白场景太单调

**解决**:
- 丰富灰度层次（使用7级灰）
- 增加光影对比
- 局部使用强调色
- 增加纹理细节

#### 问题：现代场景太"艳"，不严肃

**解决**:
- 降低饱和度（40-60%）
- 统一色调（使用LUT）
- 避免纯色大面积
- 纪念馆场景去饱和

#### 问题：角色表情不生动

**解决**:
- 强化眼神（高光、瞳孔）
- 增加眉毛变化
- 添加微表情细节
- 整体面部协调

## 十一、工作流程

### 11.1 美术资源制作流程

#### 场景制作流程

```
1. 概念设计 (Concept Art)
   - 手绘草图（3-5个方案）
   - 确定构图、色调
   - 标注重要元素
   预计：2-3天/场景

2. 线稿制作 (Line Art)
   - 精细线稿
   - 确定透视和比例
   - 标注图层
   预计：1-2天/场景

3. 黑白稿 (Grayscale)
   - 建立明暗关系
   - 确定光影
   - 7级灰层次
   预计：2-3天/场景

4. 上色（如需要）
   - 添加强调色
   - 调整色调
   - 最终润色
   预计：1天/场景

5. 细节完善
   - 添加纹理
   - 修正细节
   - 质量检查
   预计：1天/场景

总计：7-10天/场景（大型核心场景）
```

---

#### 角色制作流程

```
1. 角色设定
   - 性格分析
   - 外貌特征
   - 服装设计
   预计：1天/角色

2. Concept草图
   - 3-5个造型方案
   - 正面、侧面、背面
   预计：2天/角色

3. 定稿线稿
   - 精细线稿
   - 表情设计
   预计：2天/角色

4. 上色
   - 基础铺色
   - 阴影高光
   - 细节刻画
   预计：3-4天/角色

5. 表情包制作
   - 6-8个表情
   - 表情变体
   预计：2天/角色

6. Spine骨骼（如需要）
   - 骨骼绑定
   - 动画制作
   预计：5天/角色

总计：10-15天/主要角色（不含Spine）
```

## 十二、DoLs and Don'ts

### 12.1 风格Do's and Don'ts

#### ✅ DO（应该做）

- **DO** 保持1937/2024风格明确区分
- **DO** 使用参考照片，确保历史准确
- **DO** 克制使用强调色
- **DO** 注重细节，但不过度
- **DO** 让叙事引导美术，而非美术喧宾夺主
- **DO** 定期检查整体风格一致性
- **DO** 保留源文件，方便修改

#### ❌ DON'T（不应该做）

- **DON'T** 在1937场景使用鲜艳色彩
- **DON'T** 在2024场景使用水墨风格
- **DON'T** 过度装饰，影响严肃主题
- **DON'T** 依赖纯黑/纯白（除特殊情况）
- **DON'T** 忽视历史考据
- **DON'T** 追求"好看"而牺牲真实性
- **DON'T** 使用现代流行元素（除2024场景）

---

### 12.2 技术Do's and Don'ts

#### ✅ DO（应该做）

- **DO** 以高分辨率制作，再缩小
- **DO** 使用图层和智能对象
- **DO** 正确使用Alpha通道
- **DO** 命名规范清晰
- **DO** 定期备份源文件
- **DO** 优化文件大小
- **DO** 测试多分辨率显示效果

#### ❌ DON'T（不应该做）

- **DON'T** 只做低分辨率版本
- **DON'T** 合并所有图层（保留可编辑性）
- **DON'T** 使用有损格式（如JPG）作为中间文件
- **DON'T** 随意命名文件
- **DON'T** 过度压缩导致质量损失
- **DON'T** 不测试就交付

---

### 12.3 内容Do's and Don'ts

#### ✅ DO（应该做）

- **DO** 尊重历史和受害者
- **DO** 克制表现暴力场面
- **DO** 强调人性而非暴行
- **DO** 咨询历史顾问
- **DO** 考虑玩家情感承受度

#### ❌ DON'T（不应该做）

- **DON'T** 血腥或过度暴力的视觉表现
- **DON'T** 丑化或刻板化任何族群
- **DON'T** 展示性暴力画面
- **DON'T** 追求"震撼"而忽视尊重
- **DON'T** 美化战争或苦难
