## 概述

本文档详细列出游戏中所有场景的美术资源需求，包括背景、前景、道具、光照等。

### 美术风格
- **1937年场景**: 水墨画风格，黑白灰主色调，强调色为红（血/梅花）和黄（灯光）
- **2024年场景**: 照片级写实风格，高饱和度彩色
- **分辨率**: 基础1920x1080，支持4K扩展

## 六、技术规格

### 文件格式

- **源文件**: PSD（分层）
- **导出格式**: PNG（支持Alpha通道）
- **压缩**: 根据用途，PNG8/PNG24/PNG32
- **命名规范**: 见文档开头

### 分辨率标准

- **场景背景**: 3840x2160 (4K) 或 1920x1080 (FHD)
- **道具**: 根据屏幕占比，64x64 ~ 2048x2048
- **UI元素**: 512x512 或 1024x1024
- **纹理**: 1024x1024 或 2048x2048（可平铺）

### 图层结构（PSD）

```
场景名称.psd
├─ 前景层组
│  ├─ 可互动道具
│  └─ 前景遮挡
├─ 角色层（预留）
├─ 中景层组
│  ├─ 主要场景元素
│  └─ 光照效果
├─ 背景层组
│  ├─ 建筑/地形
│  └─ 远景
└─ 天空层
```

### 色彩管理

- **色彩空间**: sRGB
- **位深度**: 8bit（导出）/ 16bit（源文件）
- **1937场景主色板**:
  ```
  黑色: #1a1a1a
  深灰: #4a4a4a
  中灰: #8a8a8a
  浅灰: #c8c8c8
  白色: #f0f0f0
  强调红: #8b0000 (血)
  强调红: #dc143c (梅花)
  强调黄: #daa520 (灯光)
  ```
