**文档版本**: v1.0

---

## 概述

本文档详细列出游戏中所有UI界面的美术资源需求，包括按钮、图标、背景、装饰元素等。

### UI美术风格
- **1937年界面**: 水墨风格，毛笔字体，传统装饰纹样
- **2024年界面**: 现代简约，黑白灰主色调
- **通用原则**: 克制、肃穆、不喧宾夺主
- **分辨率**: 支持1920x1080至4K，使用矢量或高分辨率位图

## 十一、技术规格

### 文件格式

- **源文件**: PSD（分层）/ AI（矢量图标）
- **导出格式**: PNG（UI元素）
- **压缩**: PNG32（带Alpha）或PNG8（无半透明）
- **命名规范**: ui_[系统]_[元素]_[状态].png

### 分辨率标准

- **全屏背景**: 1920x1080（FHD）或3840x2160（4K）
- **大型面板**: 1200x900 ~ 1600x1000
- **按钮**: 200x60 ~ 600x100
- **图标**: 48x48, 64x64, 96x96, 128x128
- **装饰**: 根据用途，32x32 ~ 512x512

### UI图层结构（PSD）

```
UI元素名称.psd
├─ 装饰层组
│  ├─ 边角装饰
│  ├─ 边框
│  └─ 纹样
├─ 内容层组
│  ├─ 文字区域（预留）
│  ├─ 图标槽
│  └─ 按钮区域
├─ 背景层组
│  ├─ 主背景
│  ├─ 纹理
│  └─ 阴影/发光
└─ 参考层（不导出）
```

### 九宫格切图（可拉伸UI）

对于需要适应不同内容长度的UI（如对话框、面板），使用九宫格切图:

```
[角] [边] [角]
[边] [中] [边]
[角] [边] [角]
```

- 角: 固定尺寸，不拉伸
- 边: 单向拉伸
- 中: 双向拉伸

### 状态图命名规范

```
ui_[元素名]_[状态].png

状态标识:
_n  = normal（普通）
_h  = hover（悬停）
_p  = pressed（按下）
_d  = disabled（禁用）
_s  = selected（选中）
_f  = focused（聚焦）
```

### 色彩规范

#### 主色板
```
纯黑: #000000 (背景)
深灰: #1a1a1a (面板背景)
中灰: #4a4a4a (边框)
浅灰: #8a8a8a (文字)
纯白: #ffffff (高亮文字)
```

#### 强调色
```
金色: #d4af37 (重要元素)
红色: #8b0000 (警告/危险)
绿色: #2d5016 (确认/安全)
黄色: #daa520 (提示/警告)
```

#### 半透明度标准
```
对话框背景: 70-80%
遮罩: 50-60%
提示浮窗: 85-90%
HUD: 60-70%
```
