## 概述

本文档详细列出游戏中所有视觉特效（VFX）的需求，包括粒子效果、环境效果、UI反馈效果、转场特效等。

### VFX美术风格
- **1937年特效**: 水墨风格，灰尘、烟雾、雪花，克制的表现
- **2024年特效**: 现代写实，光影效果
- **特殊效果**: 时空穿越、超现实表现
- **总原则**: 克制、写实、服务叙事，不喧宾夺主

```
2.0s: 漩涡消退
2.5s: 画面恢复正常
```

## 十一、技术规格

### 文件格式

- **序列帧**: PNG序列，带Alpha通道
- **粒子纹理**: PNG，必须带Alpha通道
- **LUT**: PNG，1024x32或512x512（3D LUT）
- **源文件**: PSD / After Effects工程文件

### 命名规范

```
vfx_[类别]_[名称]_[变体].png

类别:
- weather（天气）
- fire（火焰）
- smoke（烟雾）
- light（光效）
- ui（UI特效）
- transition（转场）
- character（角色）
- environment（环境）
- overlay（叠加）

序列帧命名:
vfx_[类别]_[名称]_seq.png
或
vfx_[类别]_[名称]_001.png, 002.png, ...
```

### 分辨率标准

| 用途 | 推荐尺寸 |
|-----|---------|
| 小粒子 | 16x16, 32x32 |
| 中粒子 | 64x64, 128x128 |
| 大粒子 | 256x256, 512x512 |
| 序列帧特效 | 128x128 ~ 512x512 |
| 全屏特效 | 1920x1080 |
| 光晕/发光 | 256x256 ~ 512x512 |
| LUT | 1024x32（2D）或 32x32x32（3D） |

### 粒子纹理规范

- **Alpha通道**: 必须，用于透明度
- **边缘**: 柔和渐变到透明
- **中心**: 不要纯白（除非是闪光）
- **对比度**: 适中，避免过于锐利
- **可平铺**: 如果用于循环动画，考虑可平铺性

### 序列帧规范

- **帧率**: 12fps（慢速）、24fps（标准）、30fps（快速）
- **循环**: 首尾帧平滑过渡（如果是循环动画）
- **帧数**: 8/12/16/24/30帧（方便计算）
- **尺寸**: 所有帧必须完全相同

### 性能优化指南

| 优化项 | 建议 |
|-------|-----|
| 纹理压缩 | 使用PNG8（如不需半透明），PNG32（需要Alpha） |
| 粒子数量 | 单屏<500个粒子（移动平台<300） |
| 序列帧 | 优先使用代码动画，复杂的才用序列帧 |
| 大小 | 单个粒子纹理<100KB，序列帧全套<2MB |
| 图集 | 小粒子合并到图集（Atlas）中 |

## 十二、粒子系统参数库

### 雪花粒子系统

```yaml
雪花系统:
  发射器类型: 矩形区域（屏幕上方）
  发射速率: 50-200粒子/秒
  生命周期: 5-10秒
  初始位置: Y = 屏幕上方+100，X = 随机
  初始速度:
    Y: 50-100像素/秒（向下）
    X: -20~20像素/秒（横向飘）
  加速度:
    重力: 10像素/秒²
    风: 正弦波模拟（振幅20，周期3秒）
  旋转: 0.5-1.5转/秒
  大小: 0.5-1.5倍随机
  Alpha: 0.6-1.0（随机），死亡时淡出
  颜色: 纯白（#FFFFFF）
  混合模式: Alpha混合
```

### 火焰粒子系统

```yaml
火焰系统:
  发射器类型: 点发射器
  发射速率: 40-60粒子/秒
  生命周期: 0.5-1.5秒
  初始速度:
    Y: -80~-120像素/秒（向上）
    X: -10~10像素/秒（摇摆）
  加速度:
    Y: -20像素/秒²（上升减速）
  大小: 1.0→0.2（逐渐缩小）
  颜色: 黄(#FFF700) → 橙(#FF8800) → 红(#FF0000) → 黑(#000000)
  Alpha: 1.0 → 0.0
  混合模式: 加法混合（Additive）
```

### 烟雾粒子系统

```yaml
烟雾系统:
  发射器类型: 点发射器
  发射速率: 20-30粒子/秒
  生命周期: 3-5秒
  初始速度:
    Y: -20~-40像素/秒（缓慢上升）
    X: -5~5像素/秒
  大小: 0.5→2.0（逐渐膨胀）
  旋转: 0.2-0.5转/秒
  Alpha: 0.3 → 0.0（逐渐消散）
  颜色: 灰白色（#CCCCCC）
  混合模式: Alpha混合
```

## 十六、特殊注意事项

### 审核与敏感内容

1. **暴力相关**
   - 血液特效必须克制（暗红色，少量）
   - 不直接展示伤口细节
   - 死亡使用淡出，不用血腥特效

2. **闪光警告**
   - 白色闪光<3Hz频率
   - 强烈闪光持续<0.3秒
   - 提供关闭闪光选项

3. **文化敏感**
   - 时空穿越特效不能太"玄幻"
   - 避免鬼怪、灵异类视觉元素
   - 保持历史严肃性
