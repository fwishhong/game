# 日记系统玩法设计文档

**文档版本**: v1.0
**最后更新**: 2025-11-05

---

## 一、日记系统定位

日记是游戏的**核心叙事机制**，实现三个目标：
1. 强制反思每日经历
2. 玩家参与叙事创造
3. 连接1937与2024两个时空

---

## 二、每日日记流程

### 触发时机
每天22:00强制进入日记界面（无法跳过）

### 书写步骤

```
步骤1: 系统自动记录当日大事
· 发生的事件
· 互动过的人物
· 资源变化
· 天气温度

步骤2: 玩家选择记录重点（3选1）
┌────────────────────────────────┐
│ [记录某个人的故事]             │
│ 提升该人物关系+10              │
│ 解锁人物传记                   │
└────────────────────────────────┘

┌────────────────────────────────┐
│ [记录历史细节]                 │
│ 解锁历史资料库条目             │
│ 影响终章调查线索               │
└────────────────────────────────┘

┌────────────────────────────────┐
│ [记录个人感受]                 │
│ 影响主角心理状态               │
│ 解锁内心独白                   │
└────────────────────────────────┘

步骤3: 系统生成日记内容
· 基于模板自动生成
· 玩家可手动修改（可选）
· 字数限制: 200-500字

步骤4: 书写动画
· 毛笔逐字浮现效果
· 墨迹渲染
· 可按Space跳过

步骤5: 保存并解锁内容
· 日记存入档案
· 解锁对应奖励
· 进入下一天
```

## 三、日记内容生成

### 模板系统

```
模板结构:
{日期} {天气} {温度}

{重要事件1-2句概述}

{选择的重点内容（200字）}

{个人思考/明日计划}
```

### 生成示例

**选择记录人物**:
```
民国二十六年腊月初八
天气阴，严寒

今天王掌柜的病情加重了。

小梅一夜未眠，守在父亲床前。她的眼睛红肿，
但依然强撑着给父亲喂药。我看着这个十八岁的
姑娘，心中百感交集。在这样的乱世，亲情成了
最后的支撑。王掌柜虽然只是个卖棺材的小商人，
但他对女儿的爱，对邻里的义气，让我看到了
普通人的伟大。

我必须救他。不仅因为他是我的房东，
更因为小梅需要父亲。

明天想办法找到更多药品。
```

**选择记录历史**:
```
民国二十六年腊月初八
天气阴，严寒

今天目睹了日本兵第三次进入安全区搜查。

他们声称要找"隐藏的中国士兵"，实则是
借机掠夺和侵犯。魏特琳女士勇敢地站在大门口，
用她瘦弱的身躯挡住那些士兵。她用英语和
日语交替喊话，一次次拒绝他们的无理要求。
我在旁边做翻译，记录下了每一句对话。
这些都是历史的真相，必须被记住。

安全区已经不再"安全"。美国国旗也不能
保护所有人。但我们别无选择。

魏特琳女士说："只要我还站在这里，
他们就进不去。"
```

**选择记录感受**:
```
民国二十六年腊月初八
天气阴，严寒

又是寒冷的一天。

我越来越感到无力。即使我知道历史，
即使我拼尽全力，依然有太多人我救不了。
今天小李家的孩子因为发烧和饥饿死了，
才五岁。我抱着那个冰冷的小身体，
想起了在2024年见过的那些数字——"30万"。
原来每一个数字背后，都是一个鲜活的生命，
都有名字，都有笑容。

我不知道自己能坚持多久。
但我必须坚持。

为了记住他们。
为了让后世记住。
```

## 四、手动编辑功能

### 编辑选项

玩家可以：
1. **修改措辞**: 在生成内容基础上调整文字
2. **选择语气**: 客观/感性/悲伤/愤怒（影响措辞风格）
3. **添加细节**: 增加最多100字
4. **删减内容**: 删除不想要的部分

### 限制
- 不能删除日期和重点事件
- 总字数200-500字
- 必须基于真实发生的事件（不能编造）

## 五、日记奖励机制

### 记录人物的奖励

```
选择记录某人:
· 该人物关系+10
· 解锁人物传记（日记中第3次记录该人时）
· 增加终章见面时的对话内容

累积效果:
记录王掌柜5次 → 解锁完整传记
记录10次 → 终章见到老年小梅时她会提起这些
```

### 记录历史的奖励

```
每记录1个历史细节:
· 解锁历史资料库1条
· 增加"历史完整度"分数

历史完整度影响:
>90%: 终章演讲可以完整还原历史
60-90%: 部分还原
<60%: 许多细节遗失
```

### 记录感受的奖励

```
影响主角心理状态:
· 多次记录恐惧 → 主角变得谨慎（降低风险选项）
· 多次记录愤怒 → 主角变得激进（增加对抗选项）
· 多次记录希望 → 主角保持乐观（士气抗性+20%）

解锁特殊内心独白和结局变化
```

## 六、特殊日记

### 关键节点日记（自动触发）

**除夕夜日记**:
```
格式特殊，加入诗词

民国二十六年除夕
天寒地冻，万籁俱寂

今夜是除夕，却无人敢庆祝。
孙老先生带着孩子们读《论语》，
烛光下，那些稚嫩的声音显得格外珍贵。

"岁寒，然后知松柏之后凋也。"

我想，这就是我们活下去的理由。
不是为了简单地活着，
而是为了在绝境中保持人性，
为了让文化的火种不灭。

[特殊成就解锁: 文化火种]
```

**别离日记**（某人死亡后）:
```
自动生成追忆内容

民国二十七年正月初三
天气：雪

王掌柜今天走了。

我跪在他床前，握着他冰冷的手，
想起了第一次见到他时，他憨厚的笑容……

（此处根据玩家与王掌柜的互动历史生成内容）

我会照顾小梅。
这是我对您的承诺。
```

### 选择性日记（可不写）

**秘密日记**:
```
某些敏感内容玩家可以选择是否记录

事件: 目睹魏特琳女士崩溃痛哭
选项:
[记录真相] 真实记录她的脆弱（影响历史完整度）
[保护尊严] 不记录这一幕（尊重她的形象）

影响终章对她的描述
```

## 七、日记回顾功能

### 查看模式

```
任何时候按[J]键打开日记本

功能:
· 翻阅所有已写日记
· 按时间/人物/事件筛选
· 标记重要日记（★）
· 导出分享（截图模式）
```

### 时间轴模式

```
显示关键事件时间线:

12/13 日军进城 ★
12/15 抵达安全区
12/17 第一次搜查
12/28 抽签处决 ★
01/31 除夕夜 ★

点击可跳转到对应日记
```

## 八、终章应用

### 日记作为证据

```
2024年，纪念馆研究室

你打开穿越时留下的日记……

系统统计:
✓ 记录人物传记: 12/15
✓ 记录历史事件: 28/40
✓ 记录文化细节: 8/10

完整度: 80%

根据日记内容解锁:
· 小梅老人的具体地址
· 高桥后代留下的线索
· 幸存儿童成为的知名学者
```

### 日记朗读

```
终章演讲环节

玩家在纪念馆演讲，
系统从日记中提取关键段落，
以旁白形式朗读（配音）

例:
"我在日记中写道：
'民国二十六年腊月初八，今天王掌柜的病情加重了……'

这不是虚构的故事，
这是我亲眼见证的历史。"
```
