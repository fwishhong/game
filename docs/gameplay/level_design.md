## 序章：2024年·穿越

**时长**: 20分钟
**玩法**: 步行模拟 + 互动叙事

### 场景：南京大屠杀纪念馆

**流程**:
1. 开场动画：主角陈默来到纪念馆（配音独白）
2. 自由探索展厅（教学移动操作）
3. 互动点：查看史料、照片、文物
4. 遇难者名字墙（核心场景）
5. 触碰"陈默"的名字 → 穿越

**关卡目标**:
- 熟悉操作
- 建立历史背景认知
- 铺垫穿越动机

## 第一章：民国二十六年·初遇

**时长**: 1-1.5小时
**玩法**: 教学关卡，日常生存入门

### 关卡结构

```
12月1日: 穿越降落，迷茫
12月2日: 遇到王掌柜，租房
12月3日: 教学资源管理
12月4日: 听到城外枪声（预警）
12月5日: 结识小梅、李文斌
```

**核心机制教学**:
- 对话系统
- 资源查看
- 人物关系
- 日记书写

**关卡目标**: 建立初始人际关系，学会基础系统

## 第二至四章：逃往安全区

**时长**: 2-3小时
**玩法**: 线性叙事 + 护送任务

### 第二章（12月13日）

**关卡**: 日军进城

```
场景: 王掌柜棺材铺 → 街道 → 废墟

流程:
06:00 - 城外炮声 → 决定逃离
08:00 - 收拾物资（选择带什么）
10:00 - 【QTE】 躲避日军巡逻
12:00 - 目击暴行（强制观看，建立情绪）
14:00 - 遇到其他难民（救or不救）
18:00 - 在废墟中过夜
```

**关卡目标**:
- 生存压力感建立
- QTE教学
- 道德选择初体验

### 第三章（12月14日）

**关卡**: 继续逃难

```
场景: 废墟 → 秦淮河岸 → 夫子庙

流程:
· 路线选择: 大路（快但危险）vs 小巷（慢但安全）
· 随机遭遇: 日本兵/其他难民/伤员
· 【QTE】 过桥时的枪战
· 资源搜集: 废弃商铺

关键事件: 小梅差点被侵犯，主角救下（+30关系）
```

### 第四章（12月15日）

**关卡**: 抵达安全区

```
场景: 夫子庙 → 金陵女子学院大门

流程:
· 抵达安全区外，巨大人群
· 第一次见魏特琳（剧情CG）
· 登记入区（填表，历史细节）
· 分配住处（宿舍）
· 第一次见到100+难民（规模感）

结算:
· 路上损失的资源
· 队伍成员状态
· 关系变化
```

**章节目标**: 安全到达，人员0伤亡（困难）

## 第八章：抽签处决

**时长**: 1小时
**玩法**: 道德困境 + 强制剧情

### 关卡结构

```
12/28 傍晚:
· 日本军官通知（剧情）
· 讨论时间（2小时游戏内时间）
· 与NPC对话（了解各自想法）

12/28 夜晚:
· 【重大选择】决定方案
· 多种选项，无正确答案

12/29 上午:
· 执行（剧情CG，不可跳过）
· 见证死亡
· 众人哀悼

12/29 下午-夜晚:
· 处理后续（安抚、士气暴跌）
· 特殊日记（自动）
```

**关卡目标**:
- 让玩家感受无能为力
- 道德选择无对错
- 深化角色情感连接

## 第十二章：另一个陈默

**时长**: 1.5小时
**玩法**: 历史宿命体验

### 关卡结构

```
01/13: 遇到另一个陈默
· 震惊：同名同姓
· 他要去城外找母亲

01/14: 尝试阻止
选项A: 说服他留下（失败，他偷跑）
选项B: 陪他一起去（危险）
选项C: 替他去（Game Over）

01/15: 宿命应验
· 无论如何，他都会死
· 死法可能不同
· 尸体找回，安葬

01/16: 反思
· 特殊日记
· 主角质疑"能否改变历史"
```

**关卡目标**:
- 体验宿命主题
- 强化无能为力感
- 为后续剧情铺垫

## 终章：2024年·传承

**时长**: 1-2小时
**玩法**: 调查游戏 + 叙事总结

### 关卡结构

```
2024/12/14: 苏醒
· 回到现代纪念馆
· 发现日记还在（变成实体）

12/14 下午: 查阅日记
· 回顾关键选择
· 统计数据展示
· 根据日记完整度解锁线索

12/15: 调查
根据1937年的行为解锁不同调查对象:
· 小梅老人（如果存活）
· 王掌柜后代
· 高桥孙子（在日本）
· 幸存儿童后代

12/16: 纪念馆演讲
· 最终环节
· 玩家讲述见证的历史
· 内容根据玩家经历生成
· 多重结局

结局演讲后:
· 致谢名单（制作组）
· 真实历史人物照片
· 玩家统计数据
· 成就回顾
```
