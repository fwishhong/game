# 人物关系系统设计文档

**文档版本**: v1.0
**最后更新**: 2025-11-05

---

## 一、关系系统概述

关系系统是游戏的**情感核心**，通过建立与NPC的联系，让玩家真正关心这些历史中的人物。

---

## 二、关系值机制

### 数值范围与等级

```
关系值: 0-100

等级划分:
0-20:   陌生人（灰色）
21-40:  相识（白色）
41-60:  朋友（绿色）
61-80:  挚友（蓝色）
81-100: 生死之交（金色）
```

### 关系提升方式

| 行为 | 关系变化 | 条件 | 备注 |
|------|---------|------|------|
| 日常对话 | +1 | 每日 | 缓慢增长 |
| 帮助请求 | +5 | 完成任务 | 标准提升 |
| 赠送物资 | +3~+15 | 根据稀缺度 | 药品最高 |
| 完成支线 | +10 | 特定任务 | 大幅提升 |
| 救命 | +30 | 关键时刻 | 转折点 |
| 共同经历危险 | +20 | 事件后 | 患难见真情 |
| 倾听烦恼 | +3 | 选择倾听 | 情感支持 |

### 关系下降方式

| 行为 | 关系变化 | 后果 |
|------|---------|------|
| 拒绝帮助 | -5 | 信任降低 |
| 忽视需求 | -3/天 | 持续疏远 |
| 欺骗被识破 | -20 | 信任破裂 |
| 背叛 | -50 | 关系破裂 |
| 导致其亲友受伤/死亡 | -80 | 不可挽回 |

## 三、主要NPC关系线

### 3.1 王福生（王掌柜）线

**关系发展轨迹**:

```
阶段1: 陌生房东（关系0-20）
· 第1章: 初次见面
· 事件: "租房对话"
· 可选: 主动帮忙搬棺材（+5）

阶段2: 互帮互助（关系21-50）
· 第2-4章: 逃难路上
· 事件: "保护王掌柜不被抓"（+15）
· 事件: "分享食物"（+5 × 次数）

阶段3: 如同家人（关系51-80）
· 第5-10章: 共同生存
· 事件: "王掌柜生病，全力救治"（+20）
· 事件: "除夕夜长谈"（+10）
· 解锁: 可以称呼"掌柜大哥"

阶段4: 生死之交（关系81-100）
· 第11章+: 深度信任
· 事件: "王掌柜托付女儿"（关系>80触发）
· 对话: 解锁深度人生对话
· 特殊: 可以共享所有资源
```

**关系奖励**:
- 关系>40: 每周额外提供食物×2
- 关系>60: 教授制作技能（家具维修）
- 关系>80: 临终托付支线（如果他死亡）

**关系影响结局**:
- 关系高且存活: 终章见到其后代
- 关系低: 分道扬镳，无后续联系

---

### 3.2 小梅线

**关系发展**:

```
阶段1: 害羞少女（关系0-30）
· 初期不太说话
· 事件: "保护她不被日本兵侵犯"（+30，强制）

阶段2: 姐弟/兄妹情（关系31-60）
· 日常照顾王掌柜
· 事件: "教她识字"（+5 × 次数）
· 事件: "安慰她的恐惧"（+10）

阶段3: 如同亲人（关系61-90）
· 关系>60: 称呼"陈大哥"
· 事件: "小梅怀孕"（婚后3个月）
· 事件: "守护她生产"（+20）

阶段4: 唯一见证（关系91-100）
· 她是最终活到2024年的见证者
· 终章必见到她（如果她存活）
```

**特殊机制**:
小梅的生死对终章影响最大！
- 存活: 可以在2024年见到90岁的她
- 死亡: 只能凭日记追忆

---

### 3.3 李文斌线

**关系特点**: 从胆怯到勇敢的成长

```
初始: 关系20（因为救命之恩）
· 第5章: "QTE救李文斌"（强制事件）

成长线:
· 事件: "鼓励他站出来教书"（关系+10）
· 事件: "给他信心"（选择影响）
· 关系>50: 他变得勇敢，主动保护小梅

危机线:
· 第12章: "李文斌可能被抓"
· 玩家选择: 冒险救他 vs 保全大局
· 影响: 小梅的后续剧情
```

**结局影响**:
- 他存活 + 小梅存活: 终章得知他们的后代
- 他死亡: 小梅终身未嫁（历史线）

---

### 3.4 魏特琳女士线

**关系定位**: 精神导师，无法拯救的悲剧

```
阶段1: 崇敬（关系30-50）
· 初见即崇敬
· 她是安全区的支柱

阶段2: 合作（关系51-70）
· 协助她管理难民
· 事件: "帮忙登记难民"（+5 × 次数）
· 事件: "阻止暴力事件"（+15）

阶段3: 心灵相通（关系71-90）
· 深夜长谈
· 她吐露疲惫与坚持
· 玩家无法减轻她的负担（历史宿命）

阶段4: 无法挽回（关系91-100）
· 第16章: 她精神状态恶化
· 玩家可以延缓，但无法阻止
· 战后她依然会自杀（历史真实）
```

**历史宿命**:
游戏明确告诉玩家：有些人无法拯救，只能见证和铭记。

---

### 3.5 高桥线（复杂关系）

**关系机制**: 非传统好感度，是"理解度"

```
理解度: 0-100

初始: 0（敌对阵营）

提升方式:
· 用日语对话（需技能LV5+）
· 展示历史知识，让他反思
· 不直接批判，而是引导

阶段1: 敌人（0-20）
· 他是侵略者的一员

阶段2: 疑惑（21-50）
· 开始质疑战争
· 事件: "目睹同僚暴行后的动摇"

阶段3: 觉醒（51-80）
· 主动帮助主角（给药品等）
· 冒险拍摄真相照片

阶段4: 赎罪（81-100）
· 决心写真相之书
· 战后终身忏悔
```

**结局影响**:
- 理解度>80: 他写了揭露真相的书，传到后代
- 理解度<50: 他选择遗忘，后半生痛苦

## 四、关系网络

### 4.1 人物间关系

```
王掌柜 ←→ 小梅（父女，80）
小梅 ←→ 李文斌（夫妻，100）
魏特琳 ←→ 所有人（母亲般，60+）
赵护士 ←→ 魏特琳（师徒，75）
孙老先生 ←→ 儿童们（师生，70）
```

**网络影响**:
如果A和B关系都好，A去世后B会找玩家倾诉（特殊剧情）

### 4.2 群体关系

```
群体凝聚力: 0-100

影响因素:
· 公平分配资源: +2/次
· 共度节日: +10
· 成功抵御危险: +15
· 有人死亡: -20
· 资源严重不足: -5/天

凝聚力影响:
>80: 互相帮助，效率+20%
50-80: 正常
30-50: 小团体出现
<30: 可能内讧、有人离开
```

## 五、关系事件

### 5.1 日常互动事件

**触发**: 自由活动时间（18:00-22:00）

```
事件示例1: 王掌柜找你聊天
"小陈，过来陪老头子说说话..."
选项:
A. [陪伴] 坐下聊天（+3关系，了解他的过往）
B. [拒绝] "我还有事..."（-2关系）

事件示例2: 小梅想学认字
"陈大哥，能教我写自己的名字吗？"
选项:
A. [教学] 耐心教她（+5关系，消耗1小时）
B. [推迟] "明天再说"（+0）

事件示例3: 李文斌很沮丧
"我...我是不是很没用..."
选项:
A. [鼓励] "你已经很勇敢了"（+5关系，士气+10）
B. [实话] "确实需要更勇敢"（-2关系，但他会成长）
C. [沉默] （+0）
```

### 5.2 关系突破事件

**触发**: 关系值达到特定阈值

```
王掌柜关系>60:
"陈默，我把你当亲儿子一样..."
解锁: 深度对话，了解他年轻时的故事

小梅关系>70:
"如果...如果我爸爸有什么意外，陈大哥你要保护他..."
解锁: 托付任务

魏特琳关系>80:
"陈默，有时候我真的很累...但我不能倒下..."
解锁: 见证她的脆弱面
```

## 七、关系系统与剧情

### 选择影响关系

```
第8章: 抽签处决事件
如果选择让老人自愿:
· 老人相关人员: 关系-10（悲痛）
· 年轻人: 关系+5（感激）
· 总体: 士气-15

如果选择公平抽签:
· 所有人: 关系-5（但接受）
· 抽中者家属: 关系-30
· 总体: 士气-20
```
