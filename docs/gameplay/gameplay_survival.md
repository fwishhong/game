## 一、生存系统总览

### 核心循环

```
每日循环:
06:00 起床 → 查看资源 → 分配早餐
08:00 工作分配（搜集/医疗/教学/制作）
12:00 随机事件发生
18:00 分配晚餐 → 自由活动
22:00 写日记 → 睡觉 → 进入下一天
```

## 二、资源类型详解

### 2.1 食物（最重要）

**来源**:
- 日常搜集: 派人去废墟搜寻（60%成功率，获得2-4单位）
- 魏特琳施粥: 每3天提供5单位
- 冒险搜集: 去危险区域（80%获得5-8单位，20%遭遇危险）
- 交易: 用贵重物品换取
- 特殊事件: 剧情赠送

**消耗**: 见数值文档

**储存限制**: 最多储存50单位（防止囤积）

---

### 2.2 饮用水

**来源**:
- 水井（安全区内）: 每日稳定供应10单位
- 雨水收集: 雨天+5单位
- 雪水融化: 冬季+3单位（需燃料）

**重要性**: 比食物更致命，缺水3天必死

---

### 2.3 药品（稀缺资源）

**来源**:
- 医务室配给: 每周2单位
- 搜集: 低概率（15%）
- 高桥: 特殊剧情可获得
- 魏特琳: 关系高时可求助

**用途**: 治疗疾病、外伤

---

### 2.4 燃料

**来源**:
- 拆除木制家具: 3单位/件（不可再生）
- 搜集木柴: 2-3单位
- 配给: 每周5单位

**用途**:
- 冬季取暖（必需）
- 煮食（节约可生食）
- 消毒水（医疗用）

---

### 2.5 布料

**来源**:
- 搜集旧衣物
- 配给

**用途**:
- 制作绷带（治疗外伤）
- 制作保暖衣物（冬季）
- 修补衣物

## 三、工作分配系统

### 3.1 可分配工作

| 工作类型 | 时长 | 人数需求 | 产出 | 备注 |
|---------|------|---------|------|------|
| 搜集资源 | 4小时 | 1-2人 | 食物2-4 | 体力消耗 |
| 医疗护理 | 全天 | 1人 | 治疗病人 | 需技能 |
| 教育儿童 | 4小时 | 1人 | 文化+5 | 长期价值 |
| 制作物品 | 3小时 | 1人 | 绷带/工具 | 消耗资源 |
| 修理维护 | 2小时 | 1人 | 设施维持 | 必要工作 |
| 站岗警戒 | 全天 | 1人 | 安全+10% | 减少突袭 |

### 3.2 工作效率计算

```
效率 = 基础效率 × 健康系数 × 士气系数 × 技能加成

健康系数:
· 健康>70: 1.0
· 健康50-70: 0.8
· 健康30-50: 0.5
· 健康<30: 0.2（建议休息）

士气系数:
· 士气>70: 1.1
· 士气50-70: 1.0
· 士气30-50: 0.8
· 士气<30: 0.5

技能加成:
· 对应技能: +10% × 等级
```

### 3.3 工作安排策略

**建议配置（9人情况）**:
- 搜集×2人（获取食物）
- 医疗×1人（照顾病人）
- 教育×1人（保存文化）
- 站岗×1人（安全）
- 休息×4人（老弱病孕）

## 四、疾病与治疗

### 4.1 疾病类型

| 病症 | 成因 | 症状 | 治疗 | 后果 |
|------|------|------|------|------|
| 轻微发烧 | 受寒 | 健康-10/天 | 药品×1 | 3天治愈 |
| 重度发烧 | 严重受寒+饥饿 | 健康-25/天 | 药品×2 | 5天治愈 |
| 营养不良 | 长期饥饿 | 健康-5/天 | 持续供食 | 慢性 |
| 外伤 | 事件/意外 | 健康-20 | 绷带+药品 | 立即 |
| 冻伤 | 低温暴露 | 健康-15/天 | 温暖+药品 | 3天 |
| 痢疾 | 不洁饮食 | 健康-15/天 | 药品×1 | 4天 |

### 4.2 治疗系统

```
治疗判定:
成功率 = 50% + 医疗技能×5% + 药品质量
成功: 病情减轻/治愈
失败: 药品浪费，病情延长1天
暴击成功(10%): 立即治愈
暴击失败(5%): 病情恶化

无法治疗后果:
· 病情持续恶化
· 健康度<10: 病危
· 健康度=0: 死亡
```

## 五、死亡与失去

### 5.1 死亡机制

**死亡条件**:
1. 健康度归0且无药品治疗
2. 连续3天完全断食断水
3. 特定剧情事件（强制）
4. QTE致命失败

**死亡影响**:
- 群体士气: -20 ~ -50（根据关系）
- 相关角色: 关系+悲痛debuff
- 资源: 继承其所有物品
- 剧情: 可能改变后续走向

### 5.2 非死亡失去

**离开安全区**:
- 士气<10且有外部机会
- 与主角关系<20
- 后果: 人员减少，可能获得遗物

**被抓走**:
- 特定事件
- 后续可能营救或确认死亡

## 六、季节与环境

### 6.1 冬季机制（腊月-正月）

**温度系统**:
```
基础温度: -5°C ~ 5°C
暴雪: -15°C

温暖度计算:
室内有燃料: +40
室内无燃料: +10
室外: -30

低温影响:
<30温暖度: 健康-5/天
<10温暖度: 健康-15/天 + 冻伤风险50%
```

**食物保存**:
- 优点: 不易腐烂
- 缺点: 需加热消耗燃料

### 6.2 其他季节

**春季（二月-四月）**:
- 疾病高发（流感）
- 食物产出增加
- 气温回升

**夏季（五月-七月）**:
- 饮水需求增加×1.5
- 食物易腐（3天过期）
- 卫生问题

## 七、特殊生存挑战

### 7.1 日本兵搜查事件

**频率**: 每周1-2次（随机）

**应对策略**:
1. 藏匿男性（防止被抓）
2. 贿赂（食物×5，50%成功）
3. 魏特琳交涉（60%成功）
4. 主角用日语（70%成功，需技能LV3+）

**失败后果**:
- 人员被抓
- 资源被抢（-30%）
- 暴力事件

### 7.2 资源严重不足

**触发**: 食物<人数且持续3天

**强制选择**:
```
【道德困境事件】
食物只剩3份，但有9人...

选项:
A. 给老人和孩子（保护弱者）
B. 给年轻劳动力（实用主义）
C. 平均分配（公平但都挨饿）
D. 抽签决定（运气）

后果各不相同
```

## 八、长期生存目标

### 8.1 章节生存目标

| 章节 | 天数 | 主要挑战 | 目标 |
|------|------|---------|------|
| 1-4章 | 15天 | 建立秩序 | 0死亡 |
| 5-9章 | 30天 | 冬季生存 | 保暖+食物 |
| 10-15章 | 45天 | 维持希望 | 士气>50 |
| 16-17章 | 10天 | 离别与见证 | 完成剧情 |

### 8.2 隐藏目标

**文化保存度**:
- 持续教育儿童: +5/次
- 保护书籍文物: +10
- 传承诗词歌赋: +3
- 目标: 达到100（完美）

**救助人数**:
- 基础人员: 20人
- 额外救助: 0-10人
- 目标: 让更多人活下来
