## 一、核心数值体系

### 1.1 人物属性

#### 主要属性

| 属性 | 范围 | 说明 | 基础值 |
|------|------|------|--------|
| 健康度 | 0-100 | 身体健康状况 | 80 |
| 饥饿度 | 0-100 | 空腹程度（越高越饿） | 30 |
| 士气 | 0-100 | 精神状态 | 60 |
| 温暖度 | 0-100 | 体温（冬季重要） | 50 |

#### 每日自然变化

```
每日变化（基础）:
健康度: 无变化（受其他因素影响）
饥饿度: +40 / 天（成人）
       +25 / 天（儿童）
       +50 / 天（孕妇）
士气: -2 / 天（环境压力）
温暖度: -30 / 天（冬季）
        -10 / 天（其他季节）
```

---

### 1.2 资源消耗公式

#### 食物消耗

```
每人每日基础需求 = 1单位

特殊情况:
· 儿童（<12岁）: 0.5单位
· 孕妇: 2单位
· 病人（发烧）: 1.5单位
· 重体力劳动: 1.5单位

饥饿度影响:
· 获得食物: 饥饿度 -50
· 半份食物: 饥饿度 -25
· 无食物: 饥饿度 +0（继续累积）

饥饿度对健康影响:
· 饥饿度 > 70 持续2天: 健康度 -10 / 天
· 饥饿度 > 90 持续1天: 健康度 -20 / 天
· 饥饿度 = 100 持续3天: 死亡风险
```

#### 饮用水消耗

```
每人每日基础需求 = 1单位

特殊情况:
· 儿童: 0.5单位
· 发烧病人: 2单位
· 夏季: 1.5单位

缺水影响（比缺食物更致命）:
· 1天缺水: 健康度 -15
· 2天缺水: 健康度 -40
· 3天缺水: 死亡
```

#### 药品使用

```
药品类型:
· 基础药品: 治疗常见病，+30健康度
· 高级药品: 治疗重症，+50健康度
· 绷带: 治疗外伤，+20健康度

病症治疗需求:
· 轻微发烧: 药品×1，3天治愈
· 重度发烧: 药品×2，5天治愈
· 外伤: 绷带×1，药品×1
· 慢性病: 药品×1 / 周（维持）
```

#### 燃料使用

```
冬季（腊月-正月）:
· 每日基础: 2单位 / 5人
· 用途: 取暖、煮食、消毒

温暖度计算:
· 有充足燃料: 温暖度 +40 / 天
· 燃料不足: 温暖度 +10 / 天
· 无燃料: 温暖度 -30 / 天

低温影响:
· 温暖度 < 30: 健康度 -5 / 天
· 温暖度 < 10: 健康度 -15 / 天，生病概率+50%
```

## 二、关系系统数值

### 2.1 关系值

```
关系等级:
0-20:   陌生人
21-40:  相识
41-60:  朋友
61-80:  挚友
81-100: 生死之交

关系增减因素:
正面行为:
· 给予食物/药品: +3 ~ +10（根据稀缺程度）
· 帮助完成任务: +5
· 保护对方: +15
· 救命之恩: +30

负面行为:
· 拒绝帮助: -5
· 欺骗: -15
· 背叛: -50
· 间接导致死亡: -100（关系破裂）

每日自然变化:
· 关系>60: +1 / 天（友情深化）
· 关系<20: -1 / 天（疏远）
```

### 2.2 信任度系统

```
信任度（独立于关系值）:
0-100

影响因素:
· 承诺兑现: +10
· 承诺失败: -20
· 说出真相（困难时）: +15
· 善意的谎言（被揭穿）: -30

信任度影响:
· 高信任（>80）: 愿意分享资源、提供情报
· 低信任（<30）: 拒绝合作、可能背叛
```

## 三、技能系统

### 3.1 主角技能

#### 历史知识

```
等级: 1-10
经验获取: 触发历史事件、正确预判

效果:
LV1-3: 知道大致走向
LV4-6: 能预判关键事件日期
LV7-9: 详细了解事件过程
LV10:  如同亲历（最高）

游戏影响:
· 提前1-3天收到事件预警
· 解锁特殊准备选项
· 但无法改变大历史
```

#### 日语能力

```
等级: 1-10
经验获取: 与日本人交涉、学习

效果:
LV1-3: 基础对话
LV4-6: 流利交流
LV7-10: 翻译水平

实际影响:
· 与日本兵交涉成功率: 10% × 等级
· 与高桥对话解锁深度选项（需LV5+）
· 被误认为汉奸风险（负面）
```

#### 医疗知识

```
等级: 1-10
经验获取: 治疗病人、协助赵护士

效果:
· 治疗成功率: 50% + (等级×5%)
· 药品节约: 等级/10 概率节约1单位
· 诊断准确: 等级>5 可诊断病因

治疗公式:
成功率 = 基础50% + 医疗等级×5% + 药品质量加成
失败惩罚 = 浪费药品，病情延长
```

#### 资源搜集

```
等级: 1-10
经验获取: 搜集行动

效果:
· 搜集效率: 100% + (等级×10%)
· 发现隐藏物品概率: 等级×5%
· 搜集时间: 4小时 - (等级×10分钟)

搜集公式:
获得资源数 = 基础产出 × (1 + 等级×0.1) × 运气系数
```

## 四、战斗/QTE数值

### 4.1 QTE系统

```
QTE难度设定:
简单: 时间窗口 2.0秒
普通: 时间窗口 1.0秒
困难: 时间窗口 0.5秒

成功/失败后果:
成功: 事件朝有利方向发展
失败:
  · 轻微: 健康-10, 资源损失
  · 严重: 角色受伤、被抓
  · 致命: Game Over

示例（逃跑QTE）:
成功: 安全逃脱
失败: 被抓，触发审讯事件
致命失败: 主角死亡
```

## 五、经济系统

### 5.1 交易比率

```
资源价值（以食物为基准=1）:
食物: 1
水: 0.8
药品: 5
燃料: 2（冬季3）
布料: 1.5
贵重物品: 10-50

与魏特琳交易:
· 贡献人手劳动 → 获得资源
· 1人工作1天 = 食物×2

与高桥交易（风险）:
· 用情报换资源
· 可能被利用

黑市交易（危险）:
· 价格×3
· 有被骗/被抓风险
```

## 六、生存难度计算

### 6.1 难度系数

```
故事模式:
· 资源产出: ×1.5
· 消耗: ×0.7
· QTE时间: ×1.5
· 死亡: 无真实死亡

历史模式（推荐）:
· 资源产出: ×1.0
· 消耗: ×1.0
· QTE时间: ×1.0
· 死亡: 部分NPC可能死亡

困难模式:
· 资源产出: ×0.7
· 消耗: ×1.3
· QTE时间: ×0.7
· 死亡: NPC大量死亡风险
```

### 6.2 压力系统

```
群体压力值: 0-100

影响因素:
· 人员死亡: +30
· 资源匮乏持续3天: +10 / 天
· 日本兵搜查: +15
· 暴行目击: +20
· 节日（除夕等）: -10

压力影响:
· 压力 > 70: 士气自然下降加倍
· 压力 > 85: 可能有人精神崩溃
· 压力 > 95: 群体暴动风险
```

```
陌生→相识: 关系值21（3-5次互动）

朋友→挚友: 关系值61（长期相处+关键事件）
```

## 十一、公式速查

### 伤害/治疗公式

```
治疗效果 = 药品基础值 × (1 + 医疗等级×0.05) × 随机系数(0.9-1.1)

健康自然恢复 = 2 / 天（健康>50且无饥饿）

疾病伤害 = 基础伤害 × 病情系数 × (1 - 治疗加成)
```

### 士气计算

```
群体士气 = Σ(个人士气) / 人数

士气影响:
· 工作效率 = 基础效率 × (士气 / 100)
· 士气<30: 可能拒绝工作
· 士气<10: 离开安全区风险
```
