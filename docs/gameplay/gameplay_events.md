## 一、事件系统架构

### 事件类型

1. **强制剧情事件**: 推进主线，必然发生
2. **随机日常事件**: 增加变数和重玩性
3. **条件触发事件**: 满足特定条件后触发
4. **关系事件**: 基于NPC好感度
5. **道德困境事件**: 重大选择，无正确答案

## 四、道德困境事件设计

### 困境1: 抽签处决（E030-E032）

```
情境: 必须10人抽签，1人死

方案A: 所有成年人平等抽签
· 公平但可能失去劳动力
· 道德: 正义
· 风险: 高

方案B: 老人自愿
· 符合原著
· 获得成就"壮士暮年"
· 士气: -10

方案C: 主角参与
· 道德评价最高
· 抽中=Game Over
· 其他人忠诚+50

方案D: 贿赂逃避
· 需要食物×10
· 成功率50%
· 道德: 低
```

### 困境2: 医药分配

```
情境: 只有1剂药，2人需要

病人A: 孩子，高烧，不治疗会死
病人B: 老人，慢性病，不治疗会痛苦但暂时不死

选择:
· 给孩子: 代表未来，但老人会很痛苦
· 给老人: 仁慈，但孩子可能死
· 分成两份: 都治不好，都受罪
```

### 困境3: 告密与保护

```
情境: 日本军官要求指认"败兵"，否则所有人危险

选项:
· 指认真正的士兵: 救多数，出卖同胞
· 拒绝: 坚守道德，集体危险
· 指认自己: 自我牺牲
· 撒谎: 指认无辜者（游戏不允许）
```

## 五、条件触发事件

### 关系触发

```
王掌柜关系>60 + 第10章:
→ 触发"托付女儿"对话

小梅关系>70 + 李文斌死亡:
→ 触发"小梅悲痛"事件链

魏特琳关系>80 + 第15章:
→ 触发"深夜长谈"特殊事件
```

### 资源触发

```
食物<5 持续3天:
→ 触发"饥荒危机"事件

药品=0 且有病人:
→ 触发"绝望治疗"选择（用土方/放弃）
```

### 技能触发

```
日语LV5 + 日军检查事件:
→ 解锁"直接用日语交涉"选项

医疗LV7 + 重症病人:
→ 解锁"高难度手术"选项（无药品也能治）
```

## 六、事件影响系统

### 蝴蝶效应

```
第5章救李文斌成功:
→ 第12章他会帮你保护小梅
→ 第16章他愿意跟你去见高桥

第5章救李文斌失败:
→ 小梅后续剧情改变
→ 可能触发复仇线
```

### 事件记忆

游戏记录玩家所有选择:
- 每个事件的选项
- 结果
- 影响的NPC
- 获得/失去的资源

终章根据这些生成个性化结局。
