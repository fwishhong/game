# 第12章：告别

**时间**：2024年12月22日-12月28日
**地点**：南京
**字数**：15,000字
**核心主题**：告别、木盒、日记、开始写作
**情感基调**：哀伤、释怀、决心

## 一、木盒（5000字）

### 场景1：打开木盒（2500字）

**时间**：12月22日，下午

**环境描写重点**：
- 小梅去世后的第二天
- 陈默回到自己的公寓
- 看到那个木盒

**回忆木盒的来历**：
- 12月21日，在医院
- 小梅最后见面时
- 李晓华递给他一个木盒
- "这是母亲让我交给您的。"
- "她说，如果她走了，就把这个给您。"
- 那时陈默还没打开

**木盒的样子**：
- 陈默拿起木盒
- 很旧的木盒，但保存得很好
- 上面有雕刻：简单的梅花图案
- 陈默认出来了
- 这是王福生做的
- 他记得，1937年冬天，王福生做过几个这样的盒子

**打开木盒**：
- 陈默深吸一口气
- 打开盒子
- 里面的东西让他愣住了

**盒子里的东西**：
1. 一本旧日记（很厚）
2. 一张照片（陈默、王福生、小梅三人，在安全区）
3. 一封信（写给陈默的）
4. 一个小布包
5. 一支旧钢笔

**照片**：
- 陈默拿起照片
- 黑白照片，有些发黄
- 他记得这张照片
- 1938年1月，高桥武志拍的
- 那时王福生还活着
- 小梅笑得很开心
- 陈默站在他们旁边
- 像一家人

**信**：
- 陈默拿起信
- 信封上写着：给陈大哥
- 是小梅的字迹
- 陈默颤抖着打开

**信的内容**：
```
陈大哥：

如果您看到这封信，说明我已经走了。

也说明您回来了。

87年，很长。
但我等到了。

12月21日见到您，我很高兴。
虽然只有几个小时，但够了。
您回来了，这就够了。

这个木盒里有几样东西：

第一，我的日记。
您教会我写日记，说记录是为了不遗忘。
我从1938年1月10日（爹去世那天）开始写，
写了87年。
我把关于您、关于爹、关于那个时代的记忆，
都写在里面了。

第二，我们的照片。
高桥先生拍的。
这是我最珍贵的照片。

第三，一支笔。
这是您在1937年用的笔。
2月26日您消失后，留在桌上。
我一直保存着。

第四，一条围巾。
我在1938年2月开始织的。
您消失后，我继续织完了。
本想12月21日给您，但您已经穿着了。
那是我托女儿在几年前交给纪念馆的。
看到您戴着，我很高兴。

陈大哥，谢谢您回来。
谢谢您没有忘记我们。

我知道，您一定会写下那段历史。
因为那是您的使命。

请写下爹。
请写下那些死去的人。
请写下那些活下来的人。

让世界记住他们。

我等您很久了。
现在，我可以安心地走了。

如果有来生，我们还做朋友。

小梅
2024年12月10日
（病床上，用女儿的笔写）
```

**陈默的泪水**：
- 读完信，陈默泪流满面
- 他握着信纸
- 手在颤抖
- "小梅...谢谢你..."

### 场景2：读日记（2500字）

**时间**：12月22日，下午3点

**环境描写重点**：
- 陈默坐在书桌前
- 小心翼翼地翻开小梅的日记
- 很厚的一本日记

**第一页**：
日期：1938年1月10日
```
今天，爹去世了。

他说他很冷。
我给他盖被子，但他还是很冷。

陈大哥一直守着他。
三天三夜没睡。

爹去世前，拉着陈大哥的手说：
"照顾好小梅。"

陈大哥哭着说："我会的。"

我也哭了。

陈大哥说要给爹做棺材。
他不会做，但他说要学。
因为爹是做棺材的，不能没有棺材。

我看着他做。
他做得很笨拙。
锯木头的时候，手划破了。
钉钉子的时候，砸到了手指。

但他没有放弃。

三天后，棺材做好了。
很简陋，但很结实。

我们把爹放进去。

陈大哥说："对不起，我没能保护他。"

我说："不怪您。是这个时代。"

今天开始，我要写日记。
陈大哥说，记录是为了不遗忘。

我要记住爹。
记住陈大哥。
记住这个时代。
```

**陈默的心痛**：
- 读着这段，陈默的心被揪紧
- 他记得那三天
- 他记得王福生冰冷的手
- 他记得自己做棺材时的笨拙
- 他记得小梅的眼泪

**继续翻**：
陈默继续翻日记，看到了很多内容：

1938年1月15日：
```
陈大哥开始教难民识字。
他说，多读书，多一个活下去的机会。
我也去听课。
```

1938年2月10日：
```
李文斌向我求婚了。
我很害怕，不知道该怎么办。
问陈大哥。
陈大哥说："如果你喜欢他，就答应。"
我说："可是爹刚走..."
陈大哥说："王福生一定希望你幸福。"
```

1938年2月15日：
```
我答应了李文斌。
陈大哥很高兴，说要当证婚人。
```

**关键的一页**：
1938年2月26日：
```
今天，陈大哥消失了。

早上还在教室上课。
中午去找他，就不见了。

我们找遍了整个安全区。
没有他。

魏特琳女士很担心。
拉贝先生派人去找。
都没找到。

他就这样消失了。

但我不相信他走了。
他答应过爹，会照顾我。
他答应过我，会参加我的婚礼。

我相信他会回来。

我会等他。
不管多久，我都会等。
```

**陈默的愧疚**：
- 读到这里，陈默再也控制不住
- 他趴在桌上，痛哭失声
- "对不起...对不起..."

**后面的日记**：
陈默翻到后面的日记，看到小梅记录了她的一生：

1938年3月：结婚
1940年：女儿出生
1949年：南京解放
1980年代：开始作证，讲述大屠杀
2000年：李文斌去世
2020年代：年老体衰，但仍在等待

最后一页：
2024年12月20日（在医院）：
```
明天，我要见陈大哥了。

女儿说，有个叫陈默的人要来。
我知道，是他。
他回来了。

我等了87年。
终于等到了。

我准备好了。

不管他要带我去哪里，
我都准备好了。
```

## 三、葬礼（5000字）

### 场景5：葬礼开始（1500字）

**时间**：12月28日，上午10:00

**环境描写重点**：
- 南京市公墓
- 天空阴沉，下着小雨
- 冬天的南京，很冷

**参加葬礼的人**：
- 李晓华和家人
- 幸存者后代（几十人）
- 纪念馆的工作人员
- 历史学者
- 还有一些陌生人（看到新闻来的）

**陈默的状态**：
- 陈默穿着黑色西装
- 围着小梅织的围巾
- 手里拿着一束白菊花
- 表情平静，但眼中有深深的悲伤

**棺材**：
- 小梅的棺材很简单
- 木质，没有装饰
- 上面放着她的照片：107岁时的照片，她在笑
- 还有一束茉莉花（陈默12月21日带去的）

**仪式开始**：
- 主持人："今天，我们送别王梅老人。"
- "南京大屠杀幸存者。"
- "她在1937年经历了地狱，但活了107年。"
- "她的人生，是一部活着的历史。"

### 场景6：陈默的悼词（2000字）

**时间**：上午10:30

**关键情节点**：
- 轮到陈默上台
- 他走到台前
- 看着台下的人，看着小梅的棺材

**陈默的悼词**：
```
各位，

我叫陈默。

你们可能觉得很奇怪，
为什么一个三十多岁的人，
会出现在一个107岁老人的葬礼上，
并声称自己认识她87年。

但这是真的。

1937年12月1日，
我穿越到那个时代。

那天下午，我遇见了王福生先生和他的女儿王梅。
她那年18岁。

他们收留了我，一个陌生人。
在那个人人自危的时代，
他们选择了善良。

接下来的87天，
我和他们一起经历了地狱。

南京大屠杀。
三十万人死亡。
城市变成废墟。

王福生先生在1938年1月10日去世。
死于肺炎和营养不良。
我给他做了一口棺材。
那是我人生中做的第一口棺材。
也是最重要的一口。

小梅失去了父亲。
但她没有放弃。

她在废墟中坚强地活下来。
她结婚、生子。
她看着南京重建，看着中国强大。
她活了107年。

但她也等了我87年。

1938年2月26日，我突然消失了。
没有告别，没有解释。
就这样不见了。

小梅开始等我。

她等了87年。

12月21日，我回来了。
虽然迟到了87年。

我们见面了。
只有几个小时的相聚。

她很虚弱，说不了几句话。
但她说："值得。"

今天，她走了。

但她走得很安详。
因为她等到了。

小梅，谢谢你等我。
谢谢你记住了那段历史。
谢谢你记住了你父亲，记住了那些人。
谢谢你教会了我，等待的意义。

你说过，等待也是一种幸福，因为有希望。

你是对的。

我答应你，我会写下那段历史。
我会写下王福生，写下那些人。
让世界记住他们。

这是我的使命。
也是我对你的承诺。

安息吧，小梅。

如果有来生，
我们还做朋友。

再见。
```

**全场的反应**：
- 说完，陈默深深鞠躬
- 全场寂静
- 然后，掌声响起
- 很多人在哭

## 五、写作注意事项

### 1. 核心改变

**删除所有"不记得"的内容**：
- ❌ "虽然他自己不完全记得"
- ❌ 通过他人的故事展现陈默不记得的事
- ✅ 陈默记得一切，读日记只是从小梅的视角回顾

**删除高桥照片调查情节**：
- ❌ 书桌上摆着高桥的照片、历史档案
- ✅ 只有小梅的木盒、日记、围巾

**木盒的来源**：
- ✅ 小梅在第8章通过李晓华给的
- ✅ 陈默在小梅去世后打开
- ✅ 里面有日记、照片、信、围巾（备份）、钢笔

### 2. 日记的作用

**不是帮陈默找回记忆**：
- 陈默已经记得所有事
- 日记是小梅的视角
- 让陈默看到小梅如何度过这87年
- 增加情感深度

### 3. 情感基调

**告别不是悲伤的结束**：
- 小梅走得安详
- 陈默释怀
- 重点在传承和开始

### 4. 元小说结构

**陈默开始写的书就是这本书**：
- 第12章结尾：陈默开始写《秦淮旧梦》
- 我们读的就是陈默写的这本书
- 形成闭环

### 5. 与其他章节的联系

**承接第8章**：
- 第8章：小梅通过李晓华给木盒
- 第12章：打开木盒，读日记

**引出后续**：
- 陈默开始写作
- 可能还会联系高桥后人
- 完善历史记录

### 6. 金句设计

**第12章应包含的金句**：

1. "她等了87年，我也会用余生完成这个承诺。"
2. "等待也是一种幸福，因为有希望。"
3. "三十万人，不是数字，是三十万个名字、故事、生命。"
4. "历史不会被遗忘，因为有人在记录，有人在等待，有人在传承。"

### 7. 节奏

**第12章节奏**：
- 打开木盒（情感高潮）→ 读日记（回顾）→ 葬礼（告别）→ 开始写作（新的开始）
- 从悲伤到释怀，从告别到传承

### 8. 字数调整

**从18,000压缩到15,000**：
- 删除不必要的调查情节
- 删除多余的后代聚会场景
- 聚焦核心：木盒、日记、葬礼、写作
