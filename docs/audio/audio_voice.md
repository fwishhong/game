## 一、配音设计理念

### 核心原则

1. **情感优先**: 配音演员必须能传达复杂情绪
2. **历史感**: 1937年部分使用民国腔调（适度）
3. **可选功能**: 配音为可选，核心体验为文字+配音
4. **多语言支持**: 中文、英文、日文配音

## 三、配音内容类型

### 剧情对话

```
示例（王掌柜）:
"小陈啊，今天外面又不太平了。
我听说日本兵又在城东抓人了……
咱们得小心点。"

要求:
· 情感: 担忧、压低声音
· 语速: 中速，略带疲惫
· 口音: 轻微南京口音
```

### 内心独白（主角）

```
示例（陈默）:
"我越来越感到无力。即使我知道历史，
即使我拼尽全力，依然有太多人我救不了……"

要求:
· 情感: 压抑、自责
· 语速: 慢速，沉重
· 处理: 加混响，表现内心
```

### 日记旁白（主角）

```
示例:
"民国二十六年腊月初八。
今天王掌柜的病情加重了……"

要求:
· 情感: 沉静、回忆
· 语速: 缓慢
· 处理: 老照片质感滤镜效果
```

### 情绪呼声

```
类型:
· 惊吓: "啊！"
· 痛苦: "呜……"
· 叹息: "唉……"
· 咳嗽: （病人）
· 哭泣: （悲伤时）

变体: 每种至少5个变体
```

## 四、多语言配音

### 中文配音（主要）

**方言处理**:
- 主角: 标准普通话（现代穿越者）
- 王掌柜等本地人: 轻微南京口音（不能太重）
- 魏特琳: 标准普通话带外国人口音
- 高桥: 标准普通话带日本口音

**录音演员要求**:
- 主角：一线配音演员，能驾驭复杂情感
- 王掌柜：中老年资深配音，有生活感
- 小梅：年轻女声，清纯+坚强并存

### 英文配音（可选）

**台词翻译原则**:
- 保持情感准确
- 适应英文语法
- 历史名词保留中文发音

**演员要求**:
- 魏特琳：必须美式英语母语者
- 其他角色：可有轻微中国口音（符合设定）

### 日文配音（可选）

**范围**: 仅高桥及日本军官

**演员要求**:
- 日语母语者
- 能表现复杂内心戏

## 五、配音录制规格

### 技术标准

| 项目 | 规格 | 说明 |
|------|------|------|
| 格式 | WAV | 未压缩 |
| 采样率 | 48kHz | 游戏标准 |
| 位深度 | 24bit | 高质量 |
| 声道 | 单声道 | 对话音轨 |
| 导出格式 | OGG Vorbis | 压缩后集成 |
| 码率 | 128kbps | 语音质量足够 |

### 录音环境要求

- 专业录音棚
- 隔音良好（背景噪音<-60dB）
- 话筒：Neumann U87或同级别
- 录音软件：Pro Tools / Cubase

## 六、后期处理

### 标准处理流程

```
1. 降噪（去除底噪）
2. 均衡（EQ）：
   - 减少低频隆隆声（<80Hz）
   - 提升清晰度（2-5kHz）
3. 压缩（Compression）：
   - 动态范围控制
   - Ratio: 3:1
4. 限制（Limiting）：
   - 峰值控制 -3dBFS
5. 归一化（Normalization）：
   - 响度 -23 LUFS
```

### 特殊处理

**内心独白**:
- 加混响（模拟内心）
- 轻微失真（情绪化）

**日记旁白**:
- 暖色调EQ（怀旧感）
- 轻微磁带噪音（历史感）

**电话/广播**:
- 带通滤波器（300Hz-3kHz）
- 失真+噪音

**魏特琳（外国人）**:
- 保留口音特征
- 稍慢语速

## 八、配音脚本示例

### 脚本格式

```
【场景】第一章 - 初遇王掌柜
【角色】王福生（王掌柜）
【情绪】憨厚、热情
【台词】
"哎呦，您就是那位要租房的先生吧？
来来来，里面请。这乱世，能有个落脚的地方不容易啊。"

【配音导演备注】
· 南京口音轻微体现
· "哎呦"要自然
· 最后一句略带叹息
```

### 关键台词（情感高光）

**王掌柜临终（如果死亡线）**:
```
【情绪】虚弱、不舍、托付
【台词】
"小陈……答应我……照顾好小梅……
她……她还小……什么都不懂……
我这条老命……不值钱……
但……但她是我的全部啊……"

【配音导演备注】
· 断断续续，虚弱
· "全部"二字加重
· 最后渐弱
```

**小梅崩溃**:
```
【情绪】悲痛欲绝
【台词】
"爹！爹！你别走……别丢下我……
我不要你走……呜呜呜……"

【配音导演备注】
· 撕心裂肺的哭喊
· 渐入抽泣
· 真实情感，不要演得太戏剧化
```

**陈默内心**:
```
【情绪】无力、自责
【台词】
"我本以为知道历史就能改变什么……
但我错了。
我只是个无力的旁观者。"

【配音导演备注】
· 压抑，克制
· 不要过于煽情
· 自省的平静
```

## 九、配音实现

### 游戏内调用

```csharp
// 配音管理器
public class VoiceManager
{
    // 播放配音（带字幕同步）
    public void PlayDialogue(string voiceID, string subtitleText)
    {
        AudioClip voice = LoadVoice(voiceID);
        audioSource.Play(voice);
        ShowSubtitle(subtitleText);
    }

    // 支持跳过
    public void SkipDialogue()
    {
        audioSource.Stop();
        HideSubtitle();
    }
}
```

### 字幕同步

- 使用LRC格式或自定义时间轴
- 字幕逐字显示与配音同步
- 支持多语言字幕切换
