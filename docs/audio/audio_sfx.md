# 音效资源设计文档

**文档版本**: v1.0
**最后更新**: 2025-11-05

---

## 一、音效设计原则

1. **真实感**: 使用真实录音，不过度卡通化
2. **历史感**: 1937年音效去除现代元素
3. **情感强化**: 音效服务于情绪传达
4. **空间感**: 使用3D音效增强沉浸

## 十、音效制作规格

### 技术标准

| 项目 | 规格 | 说明 |
|------|------|------|
| 格式 | WAV (源) | 未压缩 |
| 采样率 | 48kHz | 游戏标准 |
| 位深度 | 24bit | 高质量 |
| 声道 | 单声道/立体声 | 根据用途 |
| 导出格式 | WAV/OGG | 短音效WAV，长环境音OGG |

### 3D音效设置

```
空间化音效:
· 枪声: 200米衰减
· 脚步: 10米衰减
· 对话: 5米衰减
· 环境音: 50米衰减

混响设置:
· 室内: 中混响
· 街道: 短混响
· 废墟: 长混响
```

## 十二、录音需求

### 现场录音

**需要录制**:
- 真实环境音（废墟、水流）
- Foley（脚步、布料、木门）
- 人群声（群演配合）

**录音设备**:
- 指向性话筒（对话）
- 全向话筒（环境音）
- 录音机（便携）

### 拟音（Foley）

- 脚步声：不同材质地板
- 布料：不同质地摩擦
- 物品：真实道具录音

## 十三、实现技术

### Unity音频系统

```csharp
// 音效管理器
public class SFXManager
{
    // 播放3D音效
    public void PlaySFX3D(string sfxID, Vector3 position);

    // 播放2D音效（UI）
    public void PlaySFX2D(string sfxID);

    // 环境音控制
    public void SetAmbience(string ambienceID);
}
```

### 音效混音器设置

```
Master
├─ Music (音乐)
├─ SFX (音效)
│  ├─ UI (UI音效)
│  ├─ Ambience (环境音)
│  ├─ Foley (角色动作)
│  └─ Events (事件音效)
└─ Voice (语音)
```
