## 一、音乐设计理念

### 核心原则

1. **情绪引导**: 音乐服务于叙事，强化情感体验
2. **历史氛围**: 1937年用传统乐器，2024年用现代配器
3. **动态音乐**: 根据游戏状态变化（战斗/安全/悲伤）
4. **文化融合**: 中国传统+西方古典混合

### 动态音乐系统

#### 分层音乐（Layered Music）

```
《安全区的日常》分为3层:
Layer 1 (Base): 古筝旋律（始终播放）
Layer 2 (Tension): 低沉弦乐（压力>50时加入）
Layer 3 (Crisis): 大鼓节奏（危险事件时加入）

根据游戏状态实时混音
```

#### 情绪转换

```
场景转换音乐自动衔接:
日常 → 危险: 淡出(3秒) → 淡入(2秒)
危险 → 安全: 缓慢淡出(5秒)
剧情 → 音乐: 无缝接入关键音符
```

## 四、音乐制作规格

### 技术要求

| 项目 | 规格 | 说明 |
|------|------|------|
| 格式 | WAV (源文件) | 未压缩 |
| 采样率 | 48kHz | 标准游戏音频 |
| 位深度 | 24bit | 高质量 |
| 声道 | 立体声 | 2.0 |
| 导出格式 | OGG Vorbis | 压缩后集成 |
| 码率 | 192kbps | 质量与大小平衡 |

### 音量标准

```
峰值电平: -3dBFS
平均响度: -23 LUFS (游戏标准)
动态范围: 15-20 LU
```

## 九、实现要点

### 游戏内音乐管理

```csharp
// 伪代码
public class MusicManager
{
    // 根据场景/事件/压力值动态切换
    public void UpdateMusic(GameState state)
    {
        if (state.inDanger) PlayDangerMusic();
        else if (state.pressure > 70) AddTensionLayer();
        else PlayDailyMusic();
    }

    // 平滑过渡
    public void CrossFade(AudioClip from, AudioClip to, float duration);
}
```
