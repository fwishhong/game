# 第12章：告别

**时间**：2024年12月22日-12月28日
**地点**：南京
**字数**：18,000字
**核心主题**：告别、传承、开始写作
**情感基调**：哀伤、释怀、决心

---

## 一、12月22-27日：准备葬礼（6000字）

### 场景1：葬礼筹备（2000字）

**时间**：12月22日

**环境描写重点**：
- 小梅去世后的第二天
- 陈默协助李晓华筹备葬礼
- 南京的冬天，很冷

**李晓华的坚强**：
- 李晓华虽然悲伤
- 但很坚强
- "母亲走得很安详。"
- "她等到了她想等的人。"

**葬礼的安排**：
- 李晓华："葬礼定在12月28日。"
- "母亲说过，如果她去世，希望简单一点。"
- 陈默："我想...在葬礼上说几句话，可以吗？"
- 李晓华："当然。母亲会很高兴的。"

**陈默准备悼词**：
- 陈默回到家
- 开始写悼词
- 但他不知道该说什么
- 八十七年的等待
- 几个小时的重逢
- 他该怎么总结？

### 场景2：整理小梅的遗物（2000字）

**时间**：12月23日

**关键情节点**：
- 李晓华请陈默帮忙整理母亲的遗物
- 陈默来到小梅生前住的房间

**房间的样子**：
- 简陋而整洁
- 一张床、一个柜子、一张桌子
- 墙上贴着一些老照片

**老照片**：
- 陈默看到墙上的照片
- 第一张：十八岁的小梅（1937年）
- 第二张：小梅和李文斌的结婚照（1938年）
- 第三张：小梅和女儿李晓华（1950年代）
- 第四张：小梅老年时的照片（2020年）

**一本日记**：
- 李晓华拿出一个旧本子
- "这是母亲的日记。"
- "她从1938年开始写，写了一辈子。"
- 陈默接过日记，手在颤抖

**翻开日记**：
- 陈默翻开第一页
- 日期：1938年1月10日
- 内容：就是小梅在第11章写的那篇
- 陈默的眼泪流下来

**李晓华的话**：
- "母亲说，是您教她写日记的。"
- "她说，记录是为了不遗忘。"
- 陈默："是的...我教过她..."

**日记里关于陈默的部分**：
- 李晓华翻到一页："您看这里。"
- 日期：1938年2月26日
```
今天，陈大哥消失了。

早上还在，中午就不见了。
我们找遍了整个安全区，没有他。

我不相信他走了。
他答应过爹，会照顾我。
他答应过我，会一直在。

他一定会回来的。

我会等他。
不管多久，我都会等。
```

**陈默的崩溃**：
- 读完这段，陈默再也控制不住
- 他趴在桌上痛哭
- 李晓华在旁边默默递纸巾

### 场景3：与其他幸存者后代的会面（2000字）

**时间**：12月25日

**关键情节点**：
- 李晓华组织了一个小型聚会
- 邀请了几个幸存者的后代
- 大家都想见见这个"传说中的陈默"

**聚会地点**：
- 一个茶馆
- 五六个人
- 都是幸存者的后代

**自我介绍**：
- 李晓华："这位就是陈默先生。"
- 大家都震惊地看着陈默
- "您真的是...1937年的陈默？"

**后代们的故事**：
- 第一个人："我的奶奶在安全区被您救过。"
- "她说，有个会说日语的年轻人，阻止日军抓她。"
- "那个人叫陈默。"

- 第二个人："我的外公是安全区的工作人员。"
- "他说，陈默是守门人，保护了很多人。"

- 第三个人："我的母亲在您的识字班学过字。"
- "她说，陈默老师很温柔。"

**陈默的感动**：
- 听着这些故事
- 陈默才意识到
- 他真的做了很多事
- 虽然他不记得
- 但这些人记得

**他们的请求**：
- "陈先生，您能告诉我们，1937年是什么样的吗？"
- 陈默沉默片刻："很难用语言形容。"
- "那是地狱。但也有希望。"
- "你们的祖辈，都是英雄。"

## 二、12月28日：葬礼（8000字）

### 场景4：葬礼开始（2000字）

**时间**：12月28日，上午10:00

**环境描写重点**：
- 南京市公墓
- 天空阴沉
- 下着小雨
- 很多人来送小梅最后一程

**参加葬礼的人**：
- 李晓华和家人
- 幸存者后代
- 纪念馆的工作人员
- 历史学者
- 还有一些陌生人（看到新闻来的）

**陈默的状态**：
- 陈默穿着黑色西装
- 围着小梅的围巾
- 手里拿着一束白菊花
- 表情平静，但眼中有悲伤

**棺材**：
- 小梅的棺材很简单
- 上面放着她的照片
- 107岁时的照片
- 她在笑

**仪式开始**：
- 主持人："今天，我们送别王梅老人。"
- "南京大屠杀最后一批幸存者之一。"
- "她在1937年经历了地狱，但活了107年。"
- "她的人生，是一部活着的历史。"

### 场景5：悼词（2500字）

**时间**：上午10:30

**关键情节点**：
- 轮到陈默上台
- 他走到台前
- 看着台下的人

**陈默的悼词**：
```
各位，

我叫陈默。

你们可能觉得很奇怪，
为什么一个三十多岁的人，
会出现在一个107岁老人的葬礼上，
并声称自己认识她八十七年。

但这是真的。

1937年12月1日，
我穿越到那个时代。
遇见了十八岁的王梅，
还有她的父亲王福生。

他们收留了我，一个陌生人。
在那个人人自危的时代，
他们选择了善良。

王福生先生教会了我，
什么是善良，什么是尊严。
他在1938年1月去世，
死于肺炎。

小梅失去了父亲，
但她没有放弃。

她在废墟中坚强地活下来。
她结婚、生子、看着中国一天天强大。
她活了107年。

但她也等了我87年。

1938年2月26日，我突然消失了。
没有告别，没有解释。
只是突然不见了。

小梅开始等我。

她等了87年。

12月21日，我回来了。
虽然迟到了87年。

我见到了她。
我们只有几个小时的相聚。
但她说，值得。

今天，她走了。

但她走得很安详。
因为她等到了。

小梅，谢谢你等我。
谢谢你记住了那段历史。
谢谢你记住了你父亲，记住了那些人。
谢谢你教会了我，等待的意义。

你说，等待也是一种幸福，因为有希望。

你是对的。

安息吧，小梅。

如果有来生，
我们还做朋友。

不，不用等来生。

因为你活在我的记忆里。
活在所有记得那段历史的人的心里。

你永远不会消失。

再见。
```

**全场的反应**：
- 说完，陈默鞠躬
- 全场寂静
- 然后，掌声响起
- 很多人在哭

### 场景6：下葬（1500字）

**时间**：上午11:00

**环境描写重点**：
- 棺材缓缓下降
- 进入墓穴
- 雨还在下

**墓碑**：
- 墓碑上刻着：
```
王梅之墓
1919-2024
南京大屠杀幸存者
等待了87年的人
```

**献花**：
- 大家排队献花
- 陈默是最后一个
- 他把白菊花放在墓前
- 跪下，深深鞠躬

**最后的告别**：
- 陈默在心里说：
```
小梅，

我要走了。

但我不会忘记你。
我会写一本书，记录我们的故事。
记录1937年的一切。

我答应你的，我会做到。

谢谢你。

再见。

不，不是再见。

如果有来生，我们还做朋友。
```

### 场景7：葬礼后的聚会（2000字）

**时间**：中午12:00

**环境描写重点**：
- 葬礼后，大家聚在一个餐厅
- 追思小梅
- 气氛虽然悲伤，但也有温暖

**分享回忆**：
- 李晓华："母亲生前最喜欢的事，就是讲1937年的故事。"
- "她说，那些人不应该被遗忘。"

**其他人的分享**：
- 有人分享小梅做的公益
- 有人分享小梅的善良
- 有人分享小梅的坚强

**陈默的观察**：
- 陈默听着这些故事
- 他意识到
- 小梅不只是等了他87年
- 她还活出了精彩的一生
- 她影响了很多人

**决心**：
- 陈默对李晓华说："我要写一本书。"
- "记录您母亲的故事，记录1937年。"
- 李晓华："谢谢您。母亲会很高兴的。"

## 三、12月28日晚：开始写作（4000字）

### 场景8：回到家（1000字）

**时间**：晚上8:00

**环境描写重点**：
- 陈默回到公寓
- 脱下西装
- 坐在书桌前

**环视书房**：
- 书桌上摆着所有资料：
  - 高桥的照片
  - 历史档案
  - 自己的笔记本
  - 小梅的围巾
  - 小梅的信

**准备开始**：
- 陈默打开电脑
- 创建一个新文档
- 标题已经有了：《秦淮旧梦》

### 场景9：写作开始（2000字）

**时间**：晚上9:00

**关键情节点**：
- 陈默开始写第一页
- 但他不知道从哪里开始

**尝试几种开头**：

**第一次尝试**：
```
1937年12月13日，南京沦陷。
接下来的六周，三十万人死亡。
```
- 陈默删掉了
- 太学术，太冰冷

**第二次尝试**：
```
我叫陈默。
2024年12月13日，我穿越到1937年。
```
- 陈默也删掉了
- 太像小说

**第三次尝试**：
```
这是一个关于等待的故事。

一个女孩，等了一个男人87年。

她叫王梅。
```
- 陈默停下来
- 看着这几行字
- 觉得可以

**继续写**：
```
这也是一个关于见证的故事。

一个历史学家，穿越到1937年，
见证了人类历史上最黑暗的一页。

他叫陈默。
就是我。

这更是一个关于记忆的故事。

三十万人，
不是数字，
是三十万个名字，
三十万个故事，
三十万条生命。

我要记录他们。
```

**写下第一章**：
- 陈默继续写
- 写12月1日那天
- 写王福生
- 写小梅
- 写那个简陋的棺材铺

**写到深夜**：
- 陈默写了三个小时
- 写了五千字
- 第一章的雏形
- 他看着屏幕
- 感到一种满足

### 场景10：第12章结尾（1000字）

**时间**：深夜11:30

**环境描写重点**：
- 陈默停下来
- 站起来，走到窗边
- 看着南京的夜景

**思考**：
```
小梅，

我开始写了。

我会写下我们的故事。
写下王福生，写下那个时代。
写下那三十万人。

我不知道会写多久。
可能一年，可能更久。

但我会写完。

这是我对你的承诺。
这是我对历史的责任。

你等了我87年。
我也会用一生，来完成这个承诺。

谢谢你，小梅。

再见。

不，不是再见。

我们会在书里再相遇。

在那里，你永远是18岁。
王福生永远在做棺材。
高桥永远在拍照。
魏特琳永远在保护难民。

在那里，历史不会被遗忘。

这就是我的使命。
```

**保存文档**：
- 陈默回到电脑前
- 保存文档
- 文件名：《秦淮旧梦》第一章

**最后一个动作**：
- 陈默拿起小梅的围巾
- 围在脖子上
- 虽然已经很旧
- 但还是温暖

**第12章最后一句**：
- "2024年12月28日，小梅的葬礼。"
- "陈默开始写作，完成他的承诺。"
- "历史不会被遗忘，因为有人在记录，有人在等待，有人在传承。"
