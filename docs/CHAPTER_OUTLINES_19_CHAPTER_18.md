# 第18章：消失

**时间**：1938年2月26日
**地点**：南京安全区
**字数**：25,000字
**核心主题**：告别、消失、等待的开始
**情感基调**：平静中的悲伤、美丽中的残酷、告别中的希望

---

## 一、清晨：今天就是今天（5000字）

### 场景1：醒来（2000字）

**时间**：1938年2月26日，清晨5:30

**环境描写重点**：
- 陈默睁开眼睛
- 天还没亮
- 但他知道：就是今天

**身体的感觉**：
- 陈默看着自己的手
- 在晨光中，明显有些透明
- 不是幻觉了
- 是真的
- 他能看到手掌后面的床单

**平静的接受**：
- 陈默没有惊慌
- 他早就知道这一天会来
- 只是没想到是今天
- 但...也好
- 该做的都做了
- 该托付的都托付了

**最后的准备**：
- 陈默起床
- 洗脸
- 穿上干净的衣服
- 围上小梅织的围巾（红色，已经很旧）
- 看着镜子里的自己
- "陈默，你做得够好了。"

### 场景2：写最后的日记（1500字）

**时间**：清晨6:00

**环境描写重点**：
- 陈默坐在书桌前
- 翻开笔记本
- 写最后一篇日记

**日记内容**：
```
1938年2月26日

今天可能是我在1937年的最后一天。

我感觉到了。
身体正在变得透明。
也许今天，也许今晚，我会消失。

这87天，我做了我能做的事：
- 保护了一些人（虽然还有更多人我保护不了）
- 记录了真相（虽然不知道会不会被看到）
- 让王福生安心离开（虽然我没能救他）
- 把小梅托付给了李文斌（我相信他们会幸福）

如果我能回到2024年，我会：
- 把这些都写下来
- 让世界知道这段历史
- 让世界记住王福生、小梅、魏特琳、拉贝、高桥...
- 让世界记住那三十万人

小梅，对不起。
我答应过你父亲会照顾你。
但我要走了。

李文斌，拜托了。

再见。
不，不是再见。
是...87年后见。

陈默
```

**合上笔记本**：
- 陈默写完
- 合上笔记本
- 放在桌上最显眼的位置
- 压在笔记本上面的，是给小梅、魏特琳、拉贝的信

### 场景3：最后的早餐（1500字）

**时间**：早上7:00

**环境描写重点**：
- 食堂
- 陈默和往常一样来吃早餐
- 但心情不一样

**遇到小梅**：
- 小梅看到陈默
- "陈大哥，早。"
- 陈默微笑："早。一起吃？"

**小梅的不安**：
- 吃饭的时候
- 小梅一直看着陈默
- "陈大哥，您...您怎么了？"
- 陈默："怎么？"
- 小梅："我也不知道...就是感觉...感觉您好像要走很远..."

**陈默的安慰**：
- 陈默笑着摸摸小梅的头
- "傻丫头，我能去哪？"
- 小梅："我只是...有点害怕。"
- 陈默："别怕。你有李文斌了。"

**最后的嘱咐**：
- 陈默认真看着小梅
- "小梅，答应我几件事。"
- 小梅："什么？"
- 陈默：
  - "第一，好好活下去。"
  - "第二，和李文斌幸福。"
  - "第三，记录这段历史。"
  - "第四，如果有一天我不在了...不要太难过。"
- 小梅眼圈红了："陈大哥..."

**拥抱**：
- 陈默轻轻抱了抱小梅（像哥哥抱妹妹）
- "傻丫头，别哭。"
- "我会一直记得你的。"
- 小梅："我也会记得您的，一辈子。"

## 二、上午：最后的守门（6000字）

### 场景4：门口（2500字）

**时间**：上午8:00

**环境描写重点**：
- 陈默照常来到安全区门口
- 站在岗位上
- 最后一次守门

**春天的迹象**：
- 2月底了
- 虽然还冷，但有春天的感觉
- 远处的柳树，似乎有点绿了
- 陈默想：我看不到春天了

**身体越来越透明**：
- 陈默看着自己的手
- 透明度越来越高
- 现在已经能清楚看到手背后的东西
- 估计到傍晚，就会完全消失

**难民们**：
- 难民们经过
- 有的跟陈默打招呼
- "陈先生，早。"
- 陈默微笑回应
- 心想：这可能是最后一次见面了

### 场景5：最后一次阻挡（2000字）

**时间**：上午10:00

**关键情节点**：
- 日军士兵又来了
- 要进安全区

**陈默挡住**：
- 陈默站在门口："不能进。"
- 士兵："又是你！让开！"
- 陈默："这是国际安全区。"

**对峙**：
- 士兵拔刀
- 陈默不退
- 士兵："你不怕死吗？"
- 陈默平静："怕。但有些事比死更重要。"

**魏特琳出现**：
- 魏特琳赶来
- 和士兵交涉
- 士兵最终离开
- 但威胁说："总有一天会收拾你。"

**陈默的笑**：
- 陈默看着士兵离开的背影
- 轻声说："没有那一天了。"

### 场景6：和魏特琳的告别（1500字）

**时间**：上午11:00

**环境描写重点**：
- 魏特琳和陈默站在门口
- 聊天

**魏特琳的感谢**：
- "陈默，谢谢你这段时间的帮助。"
- 陈默："应该是我谢谢您。您救了这么多人。"

**陈默的请求**：
- "魏特琳女士，如果我有一天不在了..."
- 魏特琳打断："别说傻话。"
- 陈默认真："我是说如果。"
- "请您照顾小梅。"
- "还有，我的笔记本，请帮我保存好。"

**魏特琳的承诺**：
- 魏特琳看着陈默，似乎明白了什么
- 眼中有泪："我答应你。"
- 陈默微笑："谢谢。"

**握手**：
- 两人握手
- 魏特琳："陈默，你是个好人。上帝会保佑你的。"
- 陈默："希望上帝保佑您，保佑所有人。"

## 三、中午：和拉贝的告别（4000字）

### 场景7：拉贝的办公室（2000字）

**时间**：中午12:00

**环境描写重点**：
- 陈默来到拉贝的办公室
- 拉贝正在写日记

**交出证据**：
- 陈默拿出一个文件袋
- "拉贝先生，这是我和高桥收集的所有证据。"
- "照片、证言、记录。"
- 拉贝接过，很重："我会带回德国，告诉世界真相。"

**陈默的请求**：
- "还有一个请求。"
- "如果可以，请把这些证据复制一份给美国、英国。"
- "越多人知道越好。"
- 拉贝："我会的。"

**陈默的感谢**：
- "拉贝先生，谢谢您。"
- "您救了几万人的命。"
- "历史会记住您的。"
- 拉贝感动："陈默，你也一样。"

### 场景8：最后的谈话（2000字）

**时间**：中午12:30

**环境描写重点**：
- 两人坐下
- 喝茶
- 聊天

**拉贝的疑惑**：
- "陈默，你今天怎么了？"
- "总感觉你在告别。"
- 陈默沉默片刻："拉贝先生，您相信时间旅行吗？"

**坦白**：
- 拉贝愣住："时间旅行？"
- 陈默："我其实不是1937年的人。"
- "我来自2024年。"
- 拉贝震惊

**陈默的故事**：
- 陈默简短地说了自己的来历
- 拉贝听完，久久无语
- "我...我不知道该不该相信。"
- 陈默："您不必相信。但这是真的。"
- "而且，我可能今天就要回去了。"

**拉贝的反应**：
- 拉贝看着陈默
- 看到他透明的手
- 倒吸一口气："这..."
- 陈默："所以，我在告别。"

**拉贝的祝福**：
- 拉贝握着陈默的手（虽然有些透明）
- "陈默，不管你来自哪里。"
- "你是个英雄。"
- "我会记住你的。"
- 陈默眼眶有些湿："谢谢。"

**时间**：下午3:00

**环境描写重点**：
- 陈默找到小梅
- 院子里
- 有阳光

**小梅的直觉**：
- 小梅看到陈默

- 陈默愣住："你怎么知道？"
- 小梅："我感觉到了。而且...而且您的手..."

**陈默的透明**：
- 陈默举起手
- 现在已经非常透明了

**最后的拥抱**：
- 陈默抱住小梅

- "我答应过你爹照顾你，但我要走了。"

- "我会回来的。"

## 七、写作注意事项

### 1. 情感处理

**克制的煽情**：
- 不要过度煽情
- 陈默的告别是平静的、温柔的
- 小梅的崩溃要真实，但不夸张
- 重点在细节，不在大哭大喊

**美感**：
- 消失的场景要写得美
- 金色的光、夕阳、光点飘散
- 像一场美丽的告别

### 2. 时间节奏

**慢下来**：
- 这一章只有一天
- 但要写得很细
- 每个告别都要仔细描写
- 让读者感受到时间的流逝

### 3. 对话

**简短而有力**：
- 告别的话不要太多
- 但每一句都要有分量
- 陈默的话：平静、温柔、坚定
- 小梅的话：不舍、承诺、坚强

### 4. 消失的描写

**视觉化**：
- 身体变透明的过程
- 发光的瞬间
- 化作光点
- 飘散
- 只留下围巾

**诗意**：
- 用美的语言
- 用诗意的画面
- 让这个告别成为经典场景

### 5. 与2024线的呼应

**伏笔和呼应**：
- 围巾（2024年小梅还保存着）
- 87年的等待（2024年12月21日见面）
- 笔记本（记录的传承）
- 小梅的日记（木盒里的日记）

### 6. 主题升华

**等待的意义**：
- 小梅开始等待
- 这个等待不是被动的
- 而是主动的承诺
- 是爱，是希望，是信念

### 7. 金句设计

**第18章应包含的金句**：

1. "我会回来的。我不知道要多久，但我一定会回来。"
2. "这条围巾，你帮我保管。等我回来，还给我。"
3. "有些事比死更重要。"
