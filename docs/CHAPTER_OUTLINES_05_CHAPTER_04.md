# 第4章：寻找

**时间**：2024年12月14日-12月19日
**地点**：南京，陈默的公寓、医院
**字数**：8,000字
**核心主题**：寻找小梅，与时间赛跑
**情感基调**：焦急、期盼、担忧

---

## 一、搜索（2500字）

### 场景1：出院后（1000字）

**时间**：2024年12月14日，上午10:00

**环境描写重点**：
- 陈默办完出院手续
- 拒绝了医生继续观察的建议
- 他必须尽快找到小梅

**回到公寓**：
- 陈默回到自己的公寓
- 这里一切如常，但他感觉像隔世
- 5个小时前离开这里去纪念馆
- 但他经历了87天

**打开电脑**：
- 陈默坐在电脑前
- 深吸一口气
- 开始搜索："王梅 南京大屠杀幸存者"

**搜索结果**：
第一条：
```
南京大屠杀幸存者王梅老人病危
来源：现代快报
日期：2024年12月10日

南京大屠杀幸存者、107岁的王梅老人近日病情加重，
目前在南京市第一人民医院接受治疗。
医生表示，老人身体机能衰竭，情况不乐观。

王梅老人是为数不多的仍然在世的大屠杀幸存者之一。
她曾在多个场合讲述当年在安全区避难的经历...
```

**陈默的心紧了一下**：
- 病危
- 12月10日的新闻
- 今天是14日
- 她...还好吗？

### 场景2：更多信息（1000字）

**时间**：上午10:30

**继续搜索**：
- 陈默搜索更多关于小梅的信息
- 一条条新闻跳出来

**第二条新闻**：
```
南京幸存者王梅：我在等一个人
来源：南京晨报
日期：2024年12月13日

昨日是国家公祭日，记者探访了病床上的王梅老人。
虽然身体虚弱，但老人意识清醒。

当被问到有什么心愿时，老人说："我在等一个人。"

记者："等谁？"
老人："陈大哥。他说他会回来的。"
记者："陈大哥是谁？"
老人："他是...1937年在安全区救了我们的人。"
老人："他答应我，会回来。我要等到他。"

老人的女儿李晓华说，母亲常年念叨这个"陈大哥"，
说他1938年2月突然消失了，但一定会回来...
```

**陈默看着这段话，眼泪涌了出来**：
- 小梅...
- 你还在等我
- 87年了
- 你还在等

**第三条新闻**：
```
王梅老人家属：母亲可能撑不过这个月
来源：扬子晚报
日期：2024年12月13日

王梅老人的女儿李晓华接受采访时表示，
母亲近日病情恶化，医生说可能只剩几天时间。

"母亲一直在等一个人，说那个人会回来。"李晓华说，
"我不知道她等的人是谁，也许早就不在了。"
"但我希望，如果那个人还活着，能来见见我母亲。"
"让她了却心愿。"
```

**陈默立即站起来**：
- 只剩几天
- 我必须马上去
- 不能再晚了

### 场景3：联系医院（500字）

**时间**：上午11:00

**打电话给医院**：
- 陈默拨通南京市第一人民医院的电话
- "您好，我想探望王梅老人。"
- 护士："您是家属吗？"
- 陈默犹豫："我...我是她的朋友。"

**护士的回答**：
- "王梅老人目前在重症监护室。"
- "只有直系家属可以探视。"
- "而且老人身体很虚弱，不宜见太多人。"

**陈默的请求**：
- "能帮我转告她的家人吗？"
- "就说...陈默想见她。"
- "她会知道我是谁的。"
- 护士："好的，我会转告。请留下您的联系方式。"

**等待**：
- 陈默留下手机号
- 挂断电话
- 开始等待
- 手心在出汗

## 二、联系上了（2500字）

### 场景4：电话（1000字）

**时间**：12月14日，下午3:00

**手机响了**：
- 陈默看到陌生号码
- 立刻接起
- "您好？"

**对方**：
- "您是陈默先生吗？"
- 声音是个中年女性
- "我是王梅的女儿，李晓华。"

**陈默的心跳加速**：
- "李女士，您好。"
- 李晓华："医院护士说，您想见我母亲？"
- 陈默："是的。请问...方便吗？"

**李晓华的疑惑和激动**：
- "陈默...您真的是陈默？"
- "我母亲等的那个陈默？"
- 陈默沉默了一秒："是的。"
- 李晓华的声音颤抖了："这...怎么可能..."

**解释（部分）**：
- 陈默："我知道这听起来不可思议。"
- "但我真的认识令堂。"
- "我认识王福生先生，认识小梅。"
- "我记得1937年12月，在安全区..."

**李晓华打断**：
- "您等一下，您说您认识我外公？"
- "您...今年多大？"
- 陈默："我今年35岁。但这很难解释..."
- 李晓华："这不可能。我母亲说的陈大哥应该120多岁了..."

**关键对话**：
- 陈默："李女士，我知道这难以置信。"
- "但请您相信我，我就是您母亲等的人。"
- "我可以告诉您一些...只有当事人才知道的事。"

**李晓华犹豫**：
- "好吧。您说。"

### 场景5：证明身份（1000字）

**时间**：下午3:15

**陈默开始讲述**：
- "1937年12月1日，我遇到了王福生先生和小梅。"
- "当时他们住在城南的一个院子里。"
- "王福生先生是做棺材的，手艺很好。"
- "小梅18岁，很懂事，照顾父亲。"

**具体细节**：
- "12月9日，我们一起进入金陵女子大学安全区。"
- "小梅很害怕日本人，每次警报都会躲在角落。"
- "王福生先生在安全区帮忙做木工活。"
- "他教过我怎么做棺材。"

**关键信息**：
- "1938年1月10日，王福生先生去世了。"
- "我给他做了一口棺材，虽然做得很笨拙。"
- "小梅一直在哭，我安慰她，说会照顾她。"

**李晓华沉默了很久**：
- "您...您说的这些..."
- "我外公的忌日确实是1月10日。"
- "我母亲确实说过，陈大哥给外公做了棺材。"
- "但是...您怎么可能..."

**陈默的请求**：
- "李女士，我知道这难以解释。"
- "但我真的很想见您母亲。"
- "哪怕只有几分钟。"
- "我有很多话想对她说。"

**李晓华的决定**：
- 长久的沉默
- 李晓华深吸一口气："好吧。"
- "明天下午2点，您来医院。"
- "不管您是谁，不管这是怎么回事..."
- "我母亲一生都在等您。"
- "她应该见您一面。"

**陈默的感激**：
- "谢谢。谢谢您。"
- "我明天一定到。"

## 三、见面前夜（3000字）

### 场景7：回忆（1500字）

**时间**：12月14日深夜

**环境描写重点**：
- 陈默无法入睡
- 躺在床上
- 回忆涌上心头

**回忆第一次见面**：
- 1937年12月1日
- 那个寒冷的下午
- 他突然出现在南京城南的小院子里
- 王福生警惕地看着他
- 小梅躲在父亲身后，怯生生的

**王福生的第一句话**：
- "你是谁？"
- 陈默当时说："我叫陈默，我...迷路了。"
- 王福生："城里到处都是鬼子，你一个人？"
- 陈默："是的。能...能借宿一晚吗？"

**小梅的第一句话**：
- 小梅小声说："爹，他看起来不像坏人。"
- 王福生看了陈默一会儿，叹气："进来吧。"

**一起的日子**：
- 陈默记得在安全区的每一天
- 王福生教他做木工
- 小梅给他补衣服
- 三个人挤在一间小屋里
- 像一家人

**王福生去世那天**：
- 陈默记得很清楚
- 1月10日，清晨
- 王福生握着他的手说："陈默，照顾好小梅。"
- "她只有你了。"
- 陈默哭着说："我会的，我保证。"

**2月26日消失**：
- 陈默记得那天早上
- 他感觉身体很奇怪
- 像是在飘浮
- 他找到小梅，说："小梅，我可能要走了。"
- 小梅："去哪？"
- 陈默："很远的地方。但我会回来。我保证。"
- 然后...他就消失了

**小梅的等待**：
- 87年
- 她一直在等
- 从18岁等到107岁
- 等到生命的最后时刻

**陈默的眼泪**：
- 躺在黑暗中
- 眼泪流进枕头
- "对不起，小梅。"
- "我来晚了。"

### 场景8：准备礼物（1000字）

**时间**：12月15日，上午

**陈默想起一件事**：
- 他要带点什么给小梅
- 但带什么呢？

**想到了**：
- 陈默打开衣柜
- 找出一个小盒子
- 里面是一块旧手表
- 很普通的手表，但对他意义重大

**这块表的来历**（在1937年）：
- 这是陈默穿越时戴的表
- 2024年买的普通手表
- 在1937年，这是"未来的东西"
- 陈默一直戴着
- 但2月26日消失时，表留下了？
- 不，应该带回来了

（**作者注**：这里需要确认逻辑。如果陈默穿越回来，身上的东西应该都回来了。所以手表应该还在。那小梅手里不应该有。换一个思路：陈默想带一个新的礼物。）

**更改**：
- 陈默想了想
- 他去附近的花店
- 买了一束茉莉花
- 小梅喜欢茉莉花

**花店老板**：
- "先生,现在茉莉花不是应季的，我们只有干花。"
- 陈默："没关系，干花也好。"
- 老板包好花："送给长辈吗？"
- 陈默："嗯，一个...很重要的人。"

**还买了什么**：
- 陈默还买了一包秦淮的桂花糕
- 小梅在1937年说过，她最喜欢吃桂花糕
- 那时候吃不到
- 现在，他想带给她

**时间**：12月15日，下午1:30

**环境描写重点**：
- 陈默穿戴整齐

**为什么带笔记本**：

**路上**：
- 陈默看着窗外

- 他想：小梅看着这座城市重生
- 她的心情是怎样的？

**到达医院**：
- 下午1:50
- 陈默站在医院门口
- 深吸一口气
- 准备进去

## 四、写作注意事项

### 1. 核心改变

**删除所有"失忆调查"内容**：
- ❌ 不需要看高桥的照片来证明自己存在
- ❌ 不需要去档案馆查自己的档案
- ❌ 不需要找笔记本证明经历过
- ✅ 陈默记得一切，只是需要找到小梅

**简化剧情**：
- 出院 → 搜索小梅 → 联系医院 → 联系家属 → 证明身份 → 准备见面
- 从12,000字压缩到8,000字
- 重点放在"与时间赛跑"的紧迫感上

### 2. 情感基调

**焦急和期盼**：
- 陈默知道小梅在等他
- 他必须尽快见到她
- 时间不多了

**愧疚**：
- 消失了87年
- 让小梅等了一辈子
- 他来晚了

**珍惜**：
- 还有机会见到她
- 还能对她说"我回来了"
- 这是最后的机会

### 3. 与其他章节的联系

**承接第2章**：
- 第2章结尾：陈默决定去见小梅
- 第4章：寻找小梅，联系上家属，准备见面

**引出第8章**：
- 第4章结尾：陈默到达医院
- 第8章：真正的见面（第5/7章是1937年线）

### 4. 伏笔

**李晓华的疑惑**：
- 她不理解陈默怎么可能是母亲等的人
- 但她还是同意见面
- 这为后续情节留下空间

**笔记本**：
- 陈默带着笔记本
- 这将在第8章发挥作用（也许给小梅看）

**小梅的等待**：
- 通过新闻展现小梅一直在等
- 增加情感重量

### 5. 金句设计

**第4章应包含的金句**：

1. "她一直在等我。87年了，她还在等。"
2. "我来晚了。但还不算太晚，她还活着。"
3. "对不起，小梅。我来晚了。"
4. "明天，我要见到等了我一辈子的人。"

### 6. 节奏

**第4章节奏**：紧凑，有紧迫感
- 搜索 → 发现病危 → 联系 → 证明身份 → 准备 → 出发
- 每个环节都在推进
- 不拖沓

### 7. 细节真实性

**搜索引擎的使用**：
- 真实的搜索过程
- 新闻报道的格式
- 医院电话的流程

**李晓华的反应**：
- 疑惑（怎么可能）
- 谨慎（要求证明）
- 最终同意（为了母亲）

### 8. 回忆的运用

**回忆作为情感载体**：
- 陈默回忆1937年的经历
- 不是因为失忆后恢复
- 而是因为即将见到小梅，自然想起往事
- 增加情感深度
