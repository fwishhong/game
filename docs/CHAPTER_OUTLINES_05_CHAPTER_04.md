# 第4章：寻找

**时间**：2024年12月14日-12月18日
**地点**：南京，陈默的公寓、图书馆、档案馆
**字数**：12,000字
**核心主题**：寻找失去的记忆，拼凑历史碎片
**情感基调**：执着、焦虑、逐渐清晰、接近真相

---

## 一、高桥的照片（3500字）

### 场景1：邮件到达（1000字）

**时间**：2024年12月15日，上午9:00

**环境描写重点**：
- 陈默一夜未眠
- 坐在电脑前刷新邮箱
- 窗外是冬日的阳光，但他感觉不到温暖
- 咖啡杯里的咖啡已经凉了

**邮件提示音**：
- "叮"
- 高桥健的回复来了
- 陈默深吸一口气，点开

**邮件内容**：
```
陈教授：

附件中是我祖父拍摄的关于"陈默"的照片，共12张。

这些照片是祖父在1937年12月至1938年2月期间拍摄的。
当时他秘密记录南京的情况，包括安全区的生活。

照片中的陈默先生看起来是一个很有特点的人。
祖父在日记中多次提到他，称他为"神秘的朋友"。

我也扫描了祖父日记中关于陈默的部分，一并发送给您。

另外，如果您真的对这段历史感兴趣，
我可以邀请您来东京，查看完整的底片和日记原件。

期待您的回复。

高桥健
```

**陈默的手在颤抖**：
- 他点开附件
- 12张照片开始下载
- 他的心跳加速
- 这些照片里...会有我吗？

### 场景2：看到自己（1500字）

**第一张照片**：
- 照片加载完毕
- 黑白照片，有些模糊
- 场景：安全区，一群难民在排队领粮食
- 人群中，有一个年轻男子的侧影
- 陈默放大照片
- 心脏几乎停止跳动

**那是我**：
- 照片中的人，穿着长衫
- 短发，侧脸轮廓
- 陈默对着镜子看自己
- 再看照片
- 一模一样
- 那就是我

**情感冲击**：
- 陈默盯着照片，泪水模糊了视线
- 这不是想象
- 这不是梦
- 我真的在1937年
- 我真的存在于那段历史中
- 证据就在眼前

**第二张照片**：
- 陈默擦干眼泪，打开第二张
- 场景：安全区办公室
- 魏特琳在和几个人说话
- 其中一个是陈默
- 他在翻译
- 表情很认真

**第三张照片**：
- 场景：安全区门口
- 陈默和一个日本人并肩站着
- 那个日本人...应该就是高桥武志
- 两人似乎在交谈
- 表情友好

**更多照片**：
- 第四张：陈默在教室里，教孩子们识字
- 第五张：陈默在难民中间，分发食物
- 第六张：陈默站在一群人前面，似乎在说什么
- 第七张：陈默和一个老人握手（模糊，看不清老人是谁）
- 第八张：陈默背对镜头，看着窗外

**关键的第九张照片**：
- 陈默打开第九张
- 心脏猛地一跳
- 照片中：陈默、王福生、小梅，三个人
- 王福生笑着，虽然消瘦
- 小梅靠在父亲身边，也在笑
- 陈默站在旁边，手放在王福生肩上
- 这是一张"全家福"

**无法控制的情感**：
- 陈默盯着这张照片
- 眼泪终于控制不住地流下来
- "老王...小梅..."
- 他们真的存在过
- 我们真的在一起过
- 但我不记得了

### 场景3：日记片段（1000字）

**打开日记扫描件**：
- 陈默平复情绪，打开高桥的日记扫描件
- 繁体中文，有些日文
- 陈默开始阅读

**日记选段一**：
```
1937年12月15日

今天在安全区遇到一个奇怪的中国人，叫陈默。
他会说流利的英语和日语，很有学问。
但他总是很忧郁，眼神里有一种说不出的悲伤。

我问他从哪里来，他说从"很远的地方"。
我问他为什么不逃离南京，他说"我有必须在这里的理由"。

这个人，有秘密。
但我相信，他是个好人。
```

**日记选段二**：
```
1937年12月20日

陈默今天救了一个女孩，从日本士兵手中救出来的。
他用日语和那个士兵交涉，最后成功了。
那个士兵走后，陈默吐了。

我问他怎么了，他说："对不起，我只是...受不了。"
我明白他的意思。
即使救了人，但这个过程太残忍了。

陈默说："我只是一个人，我救不了所有人。"
他哭了。
我第一次看到一个男人这样哭。
```

**日记选段三**：
```
1938年1月10日

陈默的朋友王福生病了，很严重。
陈默一直守在他身边，三天三夜没睡。
我给了他一些药，但没什么用。

今天早上，王福生去世了。
陈默抱着他的尸体，一声不吭。
他的女儿王梅哭得昏了过去。

葬礼很简陋，但陈默给王福生做了一口棺材。
他说："老王是做棺材的，不能没有棺材。"
他亲手做的，用了三天。

葬礼上，陈默说："对不起，我没能保护你。"
```

**陈默的崩溃**：
- 读完这段，陈默再也控制不住
- 他趴在桌上，痛哭失声
- "老王...对不起...对不起..."
- "我真的没能保护你..."

## 二、档案馆调查（3500字）

### 场景4：南京市档案馆（1500字）

**时间**：12月16日，下午

**环境描写重点**：
- 陈默来到南京市档案馆
- 这是一栋庄重的建筑
- 他出示教授证件，申请查阅1937-1938年的档案

**档案管理员**：
- 管理员："陈教授，您要查什么？"
- 陈默："南京安全区的相关记录。特别是工作人员名单。"
- 管理员："好的，请稍等。"

**等待**：
- 陈默坐在阅览室
- 周围很安静
- 只有翻书的声音
- 他的手心在出汗

**档案送来**：
- 管理员推来一车档案盒
- "这些是1937-1938年安全区的档案。"
- "有工作人员名单、日常记录、物资清单等。"
- 陈默："谢谢。"

**开始查阅**：
- 陈默戴上手套（档案要求）
- 打开第一个档案盒
- 里面是发黄的纸张
- 繁体字，钢笔书写

**找到工作人员名单**：
- 翻了半个小时
- 陈默找到了《安全区工作人员名册》
- 他深吸一口气，翻开

**名单内容**：
```
金陵女子大学安全区工作人员名册
（1937年12月-1938年3月）

国际人员：
约翰·拉贝（主席）
明妮·魏特琳（金陵女大校长）
贝德士（金陵大学教授）
威尔逊医生
...

中国员工：
陈默（翻译，1937.12.9-1938.2.26）
李文斌（教师，1937.12.9-1938.3）
张大为（厨师）
...

备注：
陈默于1938年2月26日失踪，原因不明。
```

**证据确凿**：
- 陈默的手指划过自己的名字
- 白纸黑字
- 我的名字在历史档案中
- 不是复印件，是原件
- 这是真的

**工作日志**：
- 陈默继续翻阅

**记录片段一**：

1937年12月18日
今日工作：
- 登记新难民562人

- 记录：陈默的日语很流利，帮助很大
```

**记录片段二**：
```
1938年1月15日
今日工作：
- 陈默开办识字班，教授难民儿童读书
- 参加人数：35人
- 陈默还教授英语和日语，认为"多一门语言，多一个活下去的机会"

**记录片段三**：
```
1938年2月20日
今日工作：
- 陈默情绪低落，王福生先生去世对他打击很大
- 魏特琳女士找陈默谈话，安慰他

**记录片段四**：

1938年2月26日
突发事件：
- 陈默失踪
- 上午还在教室授课，中午消失
- 寻找无果
- 魏特琳女士很担心，担心他被日军抓走

**陈默的心情**：
- 读着这些记录
- 陈默感觉在读别人的故事
- 但那个人是自己
- 我做了这些事
- 我经历了这些
- 但我不记得

### 场景6：物证（1000字）

**继续查阅**：
- 陈默继续翻
- 突然，一个信封掉出来
- 信封上写着：**陈默的遗物**

**打开信封**：
- 陈默的手在颤抖

- 里面有几样东西：
  1. 一张小照片（就是高桥拍的那张"全家福"）
  2. 一个小本子（笔记本）
  3. 一支笔（看起来很旧）

**笔记本**：
- 陈默拿起笔记本
- 封面已经发黄
- 打开第一页
- 他的字迹！
- 这是他的笔记本！

**笔记内容**：
```
1937年12月10日
今天进入安全区。王福生、小梅都还好。
我必须记录一切。我必须见证。

12月13日
南京陷落了。我看到了...我看到了地狱。
我不想写下细节，太残忍了。
但我必须记住。
王福生说他很害怕，小梅一直在哭。
我答应他们，我会保护他们。

12月15日
今天遇到高桥武志。一个有良知的日本人。
我们可能会成为朋友。

12月20日
今天救了一个女孩。但有无数个女孩我救不了。
我吐了，哭了。
我很无力。

（中间很多页）

1938年1月10日
老王走了。
我没能保护他。
我答应过他，但我没做到。
对不起。

1月11日
今天给老王做棺材。
他教过我怎么做。
我做得很笨拙，但尽力了。
小梅一直在哭。
我该怎么办？

（后面还有很多页，但很多字迹模糊）

2月25日
我感觉不太对劲。

不，是幻觉吗？

**最后一页是空白的**：
- 2月26日之后，没有记录了

## 三、拼图逐渐完整（3500字）

### 场景7：采访幸存者后代（1500字）

**时间**：12月17日

**关键情节点**：
- 陈默通过纪念馆联系到几位幸存者的后代
- 想了解更多关于"陈默"的信息

**第一个采访对象**：
- 李文斌的女儿，李晓华，75岁
- 见面地点：李晓华家中

**对话**：
- 李晓华："陈教授，您说想了解陈默先生？"
- 陈默："是的。他和您父亲认识。"
- 李晓华："我父亲生前经常提起他。"
- 停顿："说他是个很奇怪的人，但也是个很好的人。"

**李文斌的回忆（通过女儿转述）**：
- 李晓华："我父亲说，陈默很有学问。"
- "他教了很多人识字，包括我父亲。"
- "我父亲说，如果没有陈默，他可能活不下来。"
- "有一次，日本人要抓我父亲，陈默用日语说服了他们。"

**关于小梅的信息**：
- 陈默："您父亲...和王梅女士..."
- 李晓华笑了："您是说我母亲？"
- 陈默震惊："王梅是您母亲？"
- 李晓华："是的。我父亲和母亲在安全区认识，1938年2月结婚。"
- 停顿："陈默先生是证婚人。"

**关键信息**：
- 李晓华："我母亲生前一直在等陈默先生回来。"
- "她说，陈默答应过她，他会回来。"
- "但1938年2月26日，他突然消失了。"
- "母亲等了八十七年。"
- 陈默低下头："我知道...我看到她的证言了。"

**李晓华拿出一样东西**：
- "陈教授，我这里有样东西。"
- "是母亲留给陈默先生的。"
- "她说，如果陈默回来了，就把这个给他。"

**那是什么**：
- 一个小布包
- 李晓华递给陈默："打开看看。"
- 陈默打开
- 里面是一条手织的围巾
- 很旧，但保存得很好

**附带的纸条**：
- 围巾里有一张纸条
- 小梅的字迹：
```
陈大哥：

如果你回来了，这条围巾送给你。
这是我亲手织的。

1938年2月，我开始织。
你失踪后，我继续织完了。

我等了你很久。
如果你回来，请来看我。

如果我已经不在了，
请记得：
我们曾经在最黑暗的时代，
依然相信光明。

小梅
1938年3月
```

**陈默的眼泪**：
- 陈默握着围巾，无法说话
- 眼泪滴在围巾上
- 李晓华轻声说："母亲等了您很久。"
- 陈默哽咽："我知道...对不起...我来晚了。"

### 场景8：图书馆研究（1000字）

**时间**：12月17日下午

**环境描写重点**：
- 陈默来到南京大学图书馆
- 他要查找更多关于1937-1938年的资料
- 他要拼凑出完整的拼图

**查阅资料**：
- 陈默找出所有关于南京大屠杀的学术著作
- 他开始一页一页地翻
- 寻找任何关于"陈默"的记录

**发现的零散记录**：
- 魏特琳日记（出版版）：提到陈默十三次
- 拉贝日记（出版版）：提到陈默八次
- 贝德士的信件集：提到陈默五次
- 其他幸存者证言：提到陈默的有六人

**综合分析**：
- 陈默把所有信息列在笔记本上
- 时间线逐渐清晰：
  - 12月1日：到达1937年
  - 12月9日：进入安全区，成为翻译
  - 12月13日-1月：见证大屠杀，救助难民
  - 1月10日：王福生去世
  - 1月-2月：继续工作，教识字班
  - 2月：小梅和李文斌结婚
  - 2月26日：突然消失

**但还有疑问**：
- 为什么会消失？
- 怎么消失的？
- 消失前发生了什么？
- 为什么会失忆？

### 场景9：与同事讨论（1000字）

**时间**：12月18日

**环境描写重点**：
- 陈默约李教授在学校咖啡厅见面
- 他需要一个可以讨论的人
- 虽然不能说全部真相

**对话**：
- 李教授："陈默，你这几天怎么了？看起来很憔悴。"
- 陈默："我在研究那个1937年的陈默。"
- 李教授："你的'前世'？有什么发现？"

**陈默的"研究成果"**：
- 陈默把收集到的资料给李教授看
- 照片、日记摘录、档案记录
- 李教授："哇，你找到这么多？"
- 陈默："嗯。我想写一篇论文，或者...一本书。"

**李教授的建议**：
- 李教授："这个题材很好。以个人视角写大屠杀，很有价值。"
- "那个陈默的经历很典型：普通的知识分子，在灾难中选择留下来，帮助他人。"
- "可惜他失踪了，不然可以留下更多记录。"

**陈默的感慨**：
- 陈默："我在想，他为什么会失踪？"
- 李教授："可能被日军抓走了，也可能...殉难了。"
- 停顿："那个年代，太多人莫名其妙就消失了。"
- 陈默："如果...我是说如果，他还活着呢？"
- 李教授笑了："活着？那他现在得120多岁了。不可能吧。"

**陈默的苦笑**：
- 陈默也笑了："是啊，不可能。"
- 但他心里想：
- 我就是那个陈默
- 我活着，只是失去了记忆
- 我回到了2024年，但来晚了

## 四、第4章收尾：决定（1500字）

### 场景10：深夜决定（1000字）

**时间**：12月18日深夜

**环境描写重点**：
- 陈默坐在书房
- 桌上摆满了资料：照片、日记、档案复印件、围巾
- 他看着这些，陷入沉思

**内心独白**：
```
我找到了很多答案：
- 我确实穿越到了1937年
- 我在安全区当翻译，救了很多人
- 我见证了大屠杀
- 王福生1月去世，我给他做了棺材
- 小梅和李文斌结婚，我是证婚人
- 2月26日，我突然消失

但还有更多问题：
- 我为什么会失忆？
- 我还能回去吗？
- 如果能回去，我该做什么？
- 那些失去的记忆，在我的潜意识里吗？

还有一个最重要的问题：
- 王梅等了我八十七年
- 她在12月28日去世
- 今天是12月18日
- 还有十天

等等...

她还活着？！
```

**关键认知**：
- 陈默猛地站起来
- 他意识到一个错误
- 第2章中，纪念馆工作人员说王梅"几天前去世"
- 但那是站在12月13日的视角
- 王梅是12月28日去世的
- 现在是12月18日
- 她还活着！

**计算时间**：
