# 第17章：最后的任务

**时间**：1938年2月21日-2月25日
**地点**：南京安全区及周边
**字数**：35,000字
**核心主题**：最后的使命、告别的准备、生命的预兆
**情感基调**：紧张、悲壮、不舍、温柔

---

## 一、2月21日：异常（7000字）

### 场景1：身体的异常（2000字）

**时间**：2月21日，清晨

**环境描写重点**：
- 陈默醒来，感觉身体很奇怪
- 手有些透明？不，是幻觉
- 但确实有种"不真实"的感觉

**陈默的困惑**：
- 看着自己的手
- 在阳光下，似乎能看到一点点光透过
- 揉眼睛，再看，又正常了
- "是我太累了吗？"

**回忆穿越**：
- 陈默想起12月1日醒来的时候
- 那时也有这种感觉
- 像是...不完全属于这个世界
- 难道...

**不确定的预感**：
- 陈默心里一紧
- 也许，我的时间不多了
- 但不知道是哪天
- 可能明天，可能下周，可能下个月
- 但我感觉...应该快了

**决定**：
- 不管还有多少时间
- 我要做完该做的事
- 保护小梅
- 把她托付给值得信任的人
- 记录好这一切

### 场景2：最后的守门（2500字）

**时间**：2月21日，上午

**环境描写重点**：
- 陈默来到安全区门口
- 照常守门
- 但心情复杂

**日军士兵**：
- 今天来的日军士兵陈默不认识
- 很凶恶
- 要进安全区抓"慰安妇"

**对峙**：
- 陈默站在门口："不能进。"
- 士兵："让开，支那人。"
- 陈默用日语："这是国际安全区，有国际法保护。"
- 士兵："国际法？我的刀就是法。"

**冲突**：
- 士兵推搡陈默
- 陈默站稳，不退
- 士兵拔刀
- 陈默："你敢杀我，明天全世界都会知道。"

**魏特琳出现**：
- 魏特琳赶来
- 用英语和日语交涉
- 最终士兵退走
- 但威胁说："会回来的。"

**魏特琳的担心**：
- 魏特琳对陈默说："你太冒险了。"
- 陈默："我不能让他们进来。"
- 魏特琳："我知道。但你要保护好自己。"
- 陈默沉默片刻："魏特琳女士，如果有一天我不在了..."
- 魏特琳打断："别说傻话。你会平安的。"

### 场景3：李文斌的请求（2500字）

**时间**：2月21日，下午

**环境描写重点**：
- 李文斌找到陈默
- 表情紧张

**李文斌的话**：
- "陈大哥，有件事想请教您。"
- 陈默："什么事？"
- 李文斌犹豫："关于...小梅。"

**表白的决定**：
- 李文斌："我...我喜欢小梅。"
- "想向她表白，但不知道该怎么说。"
- 陈默看着他，沉默
- 李文斌紧张："如果您不同意..."
- 陈默："我同意。"

**陈默的祝福**：
- 陈默："文斌，小梅是个好女孩。"
- "她失去了父亲，很孤单。"
- "如果你真心喜欢她，就要照顾她一辈子。"
- 李文斌认真点头："我会的。"

**教李文斌表白**：
- 陈默："真诚就好。"
- "告诉她你的心意。"
- "告诉她，你会保护她。"
- 李文斌："好。"

**陈默的心情**：
- 看着李文斌离开
- 陈默心里五味杂陈
- 小梅要有自己的生活了
- 这很好
- 但我...可能看不到她幸福的样子了

## 二、2月22日：营救计划（8000字）

### 场景4：消息（2000字）

**时间**：2月22日，早上

**环境描写重点**：
- 一个难民偷偷跑进安全区
- 浑身是伤

**难民的消息**：
- "城外...城外还有人..."
- "很多人，被困在燕子矶..."
- "日本人要...要杀他们..."
- "求求你们，救救他们..."

**数量**：
- 难民说，大概有200多人
- 都是躲在燕子矶的山洞里
- 食物没了，快撑不住了
- 日军发现了他们的踪迹

**时间紧迫**：
- 难民："最多还有两天。"
- "两天后，日本人就会找到山洞。"
- "到时候...到时候就全完了。"

**陈默的决定**：
- 听完，陈默立即找到拉贝
- "我要去救他们。"
- 拉贝："太危险了！"
- 陈默："如果不去，他们会死。"

### 场景5：计划（3000字）

**时间**：2月22日，上午

**关键情节点**：
- 陈默、拉贝、魏特琳、李文斌商量
- 如何救出200多人

**困难**：
1. 燕子矶在城外，路上都是日军
2. 200多人，怎么转移？
3. 安全区能容纳吗？
4. 如果被发现，后果不堪设想

**陈默的方案**：
- 分批转移
- 用红十字会的车
- 伪装成运送伤员
- 利用夜色掩护

**拉贝的顾虑**：
- "如果日军发现，他们会攻击安全区。"
- "到时候，几万难民都有危险。"
- 陈默："我知道风险。但如果我们不救，那200人必死无疑。"

**魏特琳的支持**：
- "我同意陈默。我们不能见死不救。"
- "这是我们的责任。"

**李文斌自愿**：
- "我也去。"
- 陈默："太危险。"
- 李文斌："我会日语，可以帮忙。而且...如果您出事，小梅会伤心一辈子。"
- 陈默看着他，点头："好。"

**最终计划**：
- 2月23日晚上出发
- 用3辆卡车
- 陈默、李文斌、还有5个志愿者
- 分两批运送
- 一定要在24日黎明前回来

### 场景6：准备（3000字）

**时间**：2月22日，下午-晚上

**准备工作**：
- 检查车辆
- 准备红十字标志
- 准备食物和水
- 准备医疗用品

**陈默写信**：
- 陈默坐在宿舍里
- 写了几封信

**给小梅的信**：
```
小梅：

如果你看到这封信，说明我可能出事了。

不要难过。我做的是对的事。

记住：
1. 李文斌是个好人，可以托付终身。
2. 活下去，好好活下去。
3. 记录这段历史，不要让人遗忘。
4. 如果有机会，帮我照顾好其他难民。

你是个坚强的女孩。
你会幸福的。

陈默
1938.2.22
```

**给魏特琳的信**：
简短，主要是感谢和托付小梅。

**给拉贝的信**：
托付证据和资料。

**藏好信**：
- 陈默把信分别放好
- 希望用不上
- 但万一...

**小梅来了**：
- 小梅敲门："陈大哥，您在吗？"
- 陈默赶紧藏好信："进来。"
- 小梅："听说您明天要出城？"
- 陈默："嗯，去救人。"
- 小梅紧张："危险吗？"
- 陈默笑："不危险。很快回来。"

**小梅的担心**：
- 小梅看着陈默
- 眼中有泪："陈大哥，您...您会回来的，对吗？"
- 陈默认真点头："会的。我保证。"
- 小梅："那...那我等您。"

## 三、2月23-24日：营救行动（12000字）

### 场景7：出发（2500字）

**时间**：2月23日，晚上10:00

**环境描写重点**：
- 夜色浓重
- 三辆卡车准备就绪
- 车上挂着红十字旗

**出发前**：
- 陈默检查装备
- 拉贝握着陈默的手："一定要活着回来。"
- 魏特琳："上帝保佑你们。"
- 小梅站在远处，眼中含泪

**车队出发**：
- 发动机响起
- 驶出安全区
- 进入黑暗的南京城

### 场景8：路上（3000字）

**时间**：2月23日晚-2月24日凌晨

**环境描写重点**：
- 南京城一片死寂
- 偶尔有火光
- 尸体、废墟、恐怖

**第一个检查站**：
- 日军哨卡
- 陈默用日语："红十字会，运送伤员。"
- 士兵检查车辆（还是空的）
- 士兵："这么晚去哪？"
- 陈默："下关医院，接伤员。"
- 士兵犹豫，但看到红十字标志，放行

**恐怖的城市**：
- 车开过一条街
- 到处是尸体
- 李文斌压低声音："天啊..."
- 陈默："别看。专心开车。"

**到达燕子矶**：
- 凌晨2点
- 到达山脚
- 熄火，下车
- 爬山

### 场景9：山洞（3500字）

**时间**：2月24日，凌晨3:00

**环境描写重点**：
- 陈默等人摸黑爬山
- 找到山洞
- 山洞里挤满了人

**难民的状态**：
- 200多人，男女老少都有
- 衣衫褴褛，面黄肌瘦
- 有的已经奄奄一息
- 孩子在哭

**陈默的到来**：
- 陈默："我们是安全区的，来救你们。"
- 难民们激动："真的？"
- "我们得救了！"
- 有人当场跪下磕头

**组织撤离**：
- 陈默："安静！听我说。"
- "时间有限，必须快速撤离。"
- "分两批。第一批：老人、妇女、儿童、重伤员。"
- "第二批：青壮年男子。"

**第一批转移**：
- 120人上车
- 挤得像沙丁鱼罐头
- 但没人抱怨
- 陈默："开车，快去快回。"

**等待**：
- 陈默、李文斌、另外两个志愿者留下
- 和剩下的80人等待
- 时间每一秒都很煎熬

### 场景10：意外（3000字）

**时间**：2月24日，早上5:30

**环境描写重点**：
- 天快亮了
- 第一批车还没回来
- 陈默很焦急

**日军出现**：
- 突然，山下传来脚步声
- 是日军巡逻队！
- 大约20个士兵
- 陈默心一沉："被发现了。"

**藏起来**：
- 陈默让所有人躲进山洞深处
- 不许出声
- 日军越来越近

**被发现**：
- 一个日军士兵发现了山洞入口
- "这里有人！"
- 其他士兵围过来

**陈默走出去**：
- 陈默对李文斌说："你保护他们。"
- 李文斌："陈大哥！"
- 陈默："听我的。"
- 陈默走出山洞，面对日军

**对峙**：
- 日军军官："你是谁？"
- 陈默用日语："红十字会。"
- 军官："胡说！红十字会为什么在这？"
- 陈默："救伤员。"
- 军官狞笑："伤员？我看是藏匿的支那人。"

**陈默的策略**：
- 陈默："长官，这些都是平民。"
- "根据日内瓦公约，不能杀害平民。"
- 军官："公约？哈哈哈！"
- "在这里，我就是公约。"

**车回来了**：
- 这时，卡车回来了！
- 从山下开上来
- 日军转头看

**李文斌的行动**：
- 李文斌趁机带难民从山洞另一侧撤离
- 悄悄下山

**陈默拖延时间**：
- 陈默继续和军官周旋
- "长官，如果杀了我，国际社会不会放过你们。"
- 军官生气："威胁我？"
- 拔刀

**冲突**：
- 军官砍向陈默
- 陈默躲开，但肩膀被划伤
- 血流出来
- 军官要再砍

**车到了**：
- 司机看到情况
- 猛踩油门冲向日军
- 日军躲避
- 陈默趁机上车
- "开车！"

**逃离**：
- 卡车冲下山
- 日军开枪射击
- 子弹打在车身上
- 陈默回头，看到李文斌带着难民也下山了
- 另一辆车接应他们

**成功**：
- 两辆车会合
- 全速返回安全区
- 日军追了一段，放弃了
- 所有人都得救了

## 五、写作注意事项

### 1. 情感基调

**复杂的情感**：
- 陈默知道快要离开了（但不知道具体哪天）
- 既想做更多，又必须安排后事
- 既不舍，又必须放手
- 既悲伤，又欣慰（小梅有人照顾了）

### 2. 营救场景

**克制原则**：
- 不过度描写暴力
- 重点在营救过程和人性
- 陈默的勇敢和智慧
- 难民的绝望和希望

### 3. 告别的准备

**不煽情**：
- 陈默的告别是克制的
- 不明说，但暗示
- 通过行动（写信、托付、教歌）
- 不是生离死别的大哭，而是温柔的准备

### 4. 李文斌和小梅

**自然的爱情**：
- 不是突然的
- 是长期相处的结果
- 陈默的祝福很重要
- 让读者放心（小梅会幸福）

### 5. 伏笔

**为第18章铺垫**：
- 身体透明的感觉（穿越的预兆）
- 陈默的预感（快要离开了）
- 写好的信（遗书）
- 托付小梅给李文斌
- 教唱《茉莉花》（象征传承）

### 6. 节奏

**第17章节奏**：
- 异常（预兆）→ 营救计划 → 惊险行动 → 受伤归来 → 告别准备
- 紧张 → 更紧张 → 高潮 → 舒缓 → 温柔

### 7. 金句设计

**第17章应包含的金句**：

1. "也许，我的时间不多了。但不管还有多少时间，我要做完该做的事。"
2. "如果不去救，那200人必死无疑。我们不能见死不救。"
3. "小梅，要幸福。这是我最大的心愿。"
4. "这首歌，在未来会传遍世界。你要记住。"
5. "我只是做了该做的事。"

### 8. 与第18章的衔接

**最后一句**：
